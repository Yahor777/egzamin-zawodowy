# Аудит страниц (Фаза A)

Дата: 2026-11-25. Инструмент: Playwright (Chromium) поверх `npx vite --port 5188`, скрипт обходит все маршруты ниже в трёх режимах.

## Чек-лист на каждый маршрут и режим
1. Ошибки страницы (`pageerror`), `console.error`, упавшие запросы.
2. Горизонтальная прокрутка страницы (`scrollWidth > clientWidth`).
3. Элементы шире экрана (вне прокручиваемых контейнеров).
4. Цели касания меньше 40 px (кнопки, ссылки вне абзаца, вкладки, поля, `summary`; отключённые чекбоксы списков-памяток не считаются).
5. Текст меньше 14 px на телефоне.
6. Скриншот и просмотр глазами (iPhone 14: главная, путь, модуль, шаги, листы, тест, экзамен, теория, словарь, команды, практика, симуляторы, настройки).
7. Сохранение: даты экзамена и минуты в день (localStorage), прогресс после перезагрузки, код переноса туда и обратно, кнопка «Сообщить об ошибке».

Режимы: **iPhone 14** (390×844, dpr 3, touch, mobile UA); **1280** (ПК 1280×800); **zoom** (viewport 780, touch, `html.style.zoom=2`, класс `phone`; эффективная ширина 390).

## Итог
- Ошибок страницы, ошибок консоли и упавших запросов: **0** на всех 28 маршрутах × 3 режима.
- Горизонтальной прокрутки и элементов шире экрана: **0** (ПК, iPhone, zoom).
- ПК: замечаний не было с первого прогона.
- iPhone, первый прогон: на 28 из 28 маршрутов были мелкие цели касания (32–38 px: логотип, «Назад», текстовые кнопки, `btn small`, кружки номеров в экзамене 32 px, чипы команд) и текст меньше 14 px (подписи вкладок, `small`, бейджи, коды, статусы, порт-метки стола). **Исправлено** CSS-блоком «phone floor» в `src/index.css` (только `html.phone`).
- Найдено глазами: на главной подписи счётчиков «до письменного/практического» вылезали за карточки на 390 px. **Исправлено** (число над подписью).
- Сетка номеров пробного экзамена: 10 колонок давали ячейки 32 px, теперь 8 колонок по 40 px.
- zoom: те же исправления; «мелкий текст» в этом режиме по факту вдвое крупнее (zoom 2), остаётся только терминал (см. ниже).

## Исключения и открытые вопросы
- **Терминал Linux (`/sim/linux`, листы с Linux): шрифт 11,5 px на телефоне** (задан в `linux.css` под 56 колонок на 390 px). Это осознанный компромисс: при 14 px в строке помещается ~41 символ, длинные команды netplan переносятся. Не менял; если читать тяжело, поднять до 13 px.
- Метки портов/светодиоды на «столе» и простые подписи внутри симулируемых экранов (Windows, веб-панели роутера) имеют собственный масштаб. Метки портов на столе подняты до 14 px, остальное внутри экранов устройств не менялось.
- Вкладки в листе/домене не помещаются в 390 px целиком (последняя вкладка обрезана), но полоса прокручивается по горизонтали.
- Чекбоксы-памятки в разборах листов отключены (не кликаются), 13 px: сознательно не считаются целями касания.
- Проверка на реальном iPhone/Safari не выполнялась: только эмуляция Chromium (`isMobile`, `hasTouch`).
- Кнопка «Сообщить об ошибке» открывает GitHub в новой вкладке; для создания issue нужен аккаунт GitHub (есть кнопка «Скопировать текст»). Скриншот автоматически не прикрепляется (URL-форма GitHub не принимает файлы).
