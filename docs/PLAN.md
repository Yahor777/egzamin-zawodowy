# План проекта INF.02 Trener

Цель: подготовка к INF.02 (сессия ZIMA 2027: теория 7–13 января, практика 15–19 января) — бесплатно, на ПК и телефоне, без нагрузки на свой компьютер.

## Экзамен
- Теория: 40 вопросов, 60 мин, порог 50% (20 пкт), в системе SIOEZ.
- Практика: 150 мин, порог 75%. Роутер/свитч (WAN, LAN, DHCP, Wi‑Fi, VLAN), Windows Server (AD, DNS, IIS, GPO, принтер, права), Linux (сеть, DHCP, пользователи, chmod, скрипты, tar, mount), клиент Windows, обжим кабеля, замена RAM, диагностика.

## Архитектура (0 zł)
- Статический PWA на GitHub Pages. Прогресс — в браузере, перенос кодом.
- Нейросеть (OpenAI‑совместимый API) — через Cloudflare Worker: ключ только на сервере, лимит на человека, вход по коду класса.
- Практика: Linux — браузерные сценарии (Killercoda) с автопроверкой; Windows Server — школьная VM 2019 + скрипт‑проверка на PowerShell; роутер/свитч — симулятор на сайте + эмуляторы TP-Link.

## Этапы
1. ✅ База вопросов из официальных листов CKE + учёба / экзамен / ошибки / темы + тренажёры (подсети, системы счисления, chmod).
2. Переводы вопросов на RU и объяснения к каждому вопросу (PL/RU). OCR ~12 старых сканированных листов.
3. Конспекты по 11 разделам программы INF.02.1–11 + словарь PL↔RU.
4. Практика: разбор arkuszy INF.02 2021–2026 по шагам с критериями оценки CKE (`_zo`), Linux‑лабы, скрипт‑проверка для Windows Server.
5. Симулятор роутера/свитча, генератор пробной практики на 150 минут.
6. ИИ‑помощник: «объясни иначе», проверка bash‑скриптов.
