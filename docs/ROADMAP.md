# План: тренажёр INF.02 — что нужно, в каком порядке, как проверяем

Экзамен — летняя сессия 2027 (письменная и практическая часть в июне; точные даты CKE публикует заранее).
Срок большой, но план не растягиваем: всё, что делает сайт полезным, закрываем в ближайшие недели,
дальше — только учёба по пути и исправление найденных ошибок.

## 1. Цель (одна фраза)

Каждый день открыть сайт → получить задание на сегодня → сделать его самому на реалистичном
оборудовании (роутер, свитч, Linux, Windows 11, Windows Server) → проверка как у экзаменатора → к экзамену
пройти все типы заданий из листов CKE 2022–2026 на ≥ 75 % без подсказок.

## 3. Готовые решения — используем, а не пишем сами

| Что | Готовое решение | Как используем |
|---|---|---|
| Точный вид веб-панелей роутера/свитча | Официальные эмуляторы TP-Link: https://www.tp-link.com/support/emulator/ | Ссылка из каждого задания с роутером/свитчом «посмотреть оригинал»; по ним сверяем наш интерфейс |
| Настоящий Windows Server | Бесплатная 180-дневная версия Windows Server (Evaluation Center) в VirtualBox — в школе или на ПК раз в неделю | Раз в 1–2 недели прогонять на нём те же шаги, что в симуляторе (контрольные точки пути) |
| Настоящий Ubuntu с systemd и сетью | Killercoda (бесплатно, без карты, сессия ~1 ч) | Опционально: 5–6 сценариев (DHCP, Samba, Apache, диски) для проверки «на живом» перед экзаменом |
| Вопросы письменной части | Наш банк из листов CKE + ee-informatyk.pl | Хватает; новые вопросы не пишем |
| Повторение | Наш интервальный повтор (как Anki) | Уже встроено |

Свои «настоящие ВМ» в браузере больше не развиваем: на iPhone это технически невозможно,
а на ПК есть VirtualBox/Killercoda.

## 4. Фазы работ (с критериями «готово»)

### Фаза A — стабилизация (сейчас, 1–2 дня)
1. Даты экзамена настраиваются в «Настройках» (по умолчанию — июнь 2027); путь пересчитывается
   на весь срок: сначала основы, потом практика, последние 6 недель — полные листы на время.
2. Аудит каждой страницы на iPhone 14 и ПК по чек-листу (вёрстка, ошибки, сохранение прогресса);
   все найденные баги исправлены.
3. Перенос прогресса (код в «Настройках») включает путь обучения.
4. Кнопка «Сообщить об ошибке» на каждом задании (текст + скрин уходят мне через GitHub issue).

**Готово, когда:** чек-лист пройден без замечаний, автотесты зелёные, путь показывает план до июня.

### Фаза B — недостающее с высокой ценностью на экзамене (≈ 1 неделя)
По частоте в 52 листах:
1. Windows Server: общие папки + права NTFS/udostępniania, `\\serwer\udział`, `net use`, квоты FSRM.
2. Роутер: VLAN-интерфейсы и статические маршруты → +7 листов CKE в симулятор.
3. Linux-клиент по DHCP получает адрес от роутера/сервера; связь по Wi-Fi.
4. Решение по каждому заданию полного листа (3-я ступень подсказки), а не общий разбор.
5. Самооценка «физических» пунктов по критериям CKE (кабель, монтаж, BHP, kosztorys на бумаге).

**Готово, когда:** все 52 листа покрыты (симулятор или чек-лист самооценки), у каждого задания есть решение.

### Фаза C — сверка с реальностью (≈ 1 неделя, нужна твоя помощь)
1. Сверить интерфейсы с оригиналами: эмуляторы TP-Link, скриншоты Windows Server / Windows 11 из школы
   (присылаешь — я правлю расхождения).
2. Польские тексты меню и сообщений — по реальной системе (польская Windows в школе).
3. Прогон 3 полных листов на настоящем оборудовании в школе → сравнить, где симулятор врёт.

**Статус (2026-11-25):** пункты 1–2 выполнены частично автоматически — см. `docs/FIDELITY.md` (эмулятор WR841N v10, руководства WR840N V4–V7 и Easy Smart Switch, Microsoft Learn pl-pl, публичные уроки ZSE Rzeszów). Исправлены подписи/тексты роутера и коммутатора, польская терминология Windows Server (DHCP «Zastrzeżenia», страница WINS, GPMC, AD DS). Не сделано: пункт 3 (прогон на железе), сверка раскладки по реальным скриншотам Windows, коммутатор/роутер школы (DrayTek + управляемый коммутатор — не TL-SG108E).

**Готово, когда:** список расхождений пуст.

### Фаза D — режим подготовки (до экзамена)
- Ты идёшь по пути каждый день; я только чиню ошибки из «Сообщить об ошибке» и добавляю
  задания, если в новых листах CKE (зимняя сессия 2027) появятся новые темы.
- Раз в месяц — полный пробный экзамен (письменный + 1 лист на 150 минут), разбор слабых тем.

## 5. Правила, чтобы не ходить по кругу
1. Новая функция делается, только если она даёт баллы на экзамене (по частоте в листах) — иначе в список «потом».
2. Каждая доработка: автотест + проверка на iPhone и ПК перед публикацией.
3. Не меняем то, что работает, ради «красоты» — только по конкретному замечанию.
4. Один план (этот файл); всё новое сначала попадает сюда с местом в очереди.

## 6. Как устроен сайт (кратко)
- Статический PWA на GitHub Pages (бесплатно, офлайн, iPhone + ПК). Сервер не нужен.
- Всё оборудование — симуляторы в браузере с общей моделью сети (кабели, IP, VLAN, DHCP, DNS, домен).
- Контент — данные (JSON/Markdown): вопросы, путь, задания, документация; движок один.
- Проверка заданий — по итоговому состоянию устройств, как у экзаменатора (любой правильный способ засчитывается).
- Прогресс — в браузере; перенос между устройствами кодом.
