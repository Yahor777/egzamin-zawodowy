# ИИ-помощник для класса через Cloudflare Worker (бесплатно)

Зачем: чтобы одноклассники пользовались ИИ в приложении, но не видели твой API-ключ.
Worker — это маленький прокси: приложение шлёт вопрос ему, он добавляет ключ и пересылает в API.

## Настройка (10 минут, один раз)

1. Зарегистрируйся на https://dash.cloudflare.com (бесплатно, карта не нужна).
2. **Workers & Pages → Create → Create Worker** → назови, например, `inf02-ai` → **Deploy**.
3. **Edit code** → вставь содержимое файла `worker/index.js` → **Deploy**.
4. **Settings → Variables and Secrets**:
   - `API_URL` — адрес OpenAI-совместимого API твоего провайдера (TokenHarbor), заканчивается на `/v1`;
   - `API_KEY` — твой ключ (тип **Secret**);
   - `MODEL` — модель, например `gpt-4o-mini` или та, что есть у провайдера;
   - `CLASS_CODE` — любой пароль для класса (например `zse2-3ti`).
5. (Необязательно) лимит запросов: **Storage & Databases → KV → Create namespace** `LIMITS`,
   затем в Worker **Settings → Bindings → KV namespace**: имя переменной `LIMITS`.
   Переменная `DAILY_LIMIT` = сколько вопросов в день на одного человека (по умолчанию 40).

## В приложении

**Настройки → ИИ-помощник**:
- Адрес API: `https://inf02-ai.<твой-аккаунт>.workers.dev/v1`
- Ключ API: значение `CLASS_CODE`
- Модель: можно оставить пустым (возьмётся `MODEL` из Worker)

Одноклассникам даёшь адрес и код класса. Ключ остаётся только в Cloudflare.

Если хочешь пользоваться сам без Worker — укажи в настройках прямой адрес API провайдера и свой ключ
(он хранится только в твоём браузере). Работает, если провайдер разрешает запросы из браузера (CORS).
