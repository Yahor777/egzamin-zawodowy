Настоящий Linux Debian в браузере

Это настоящий Debian Linux (Debian 12, 32-bit), а не наш симулятор, собранный как сервер на экзамене: обычные bash, useradd, passwd, chmod, chown, setfacl, tar, nano, vim, mc, find, grep, ps, man и т.д. Работает прямо в браузере через WebAssembly (движок CheerpX); ничего устанавливать не надо.

  • Сервер serwer, ты вошёл как administrator, пароль ZAQ!2wsx (как на экзамене). Команды администратора — через sudo (спросит этот пароль); у root тот же пароль: su -.
  • Уже установлено всё, что встречается на INF.02: isc-dhcp-server, samba + smbclient, apache2, bind9, openssh-server, nfs-kernel-server, cron, acl, quota, parted, fdisk, net-tools, dnsutils, htop, tree…
  • Интернета внутри нет. sudo apt update и sudo apt install samba работают «как настоящие» — пакеты экзамена лежат во встроенном офлайн-репозитории (даже после apt purge их можно поставить снова). Любой другой пакет: E: Unable to locate package.
  • Службы эмулируются: настоящего systemd здесь нет, демоны не слушают сеть. Но systemctl start/restart/status, service, journalctl -xeu … по-настоящему проверяют конфиги (dhcpd -t, apache2ctl configtest, testparm, named-checkconf, sshd -t) и падают с настоящими ошибками, как на экзамене. enable/disable тоже работают; после обновления страницы («перезагрузка») включённые службы стартуют заново.
  • Сеть эмулируется: две «сетевые карты» как в VirtualBox — enp0s3 (NAT, DHCP) и enp0s8 (не настроена). Настраивай /etc/netplan/50-cloud-init.yaml → sudo netplan apply (YAML проверяется, ошибки как в настоящем netplan), смотри ip a, ip r, ifconfig, resolvectl status, hostname -I. DHCP-сервер проверяет, что подсеть в dhcpd.conf совпадает с адресом интерфейса из INTERFACESv4. Настоящих пакетов нет: ping отвечает только сам себе (в лабораторных — по таблице задания); связь между машинами тренируй в симуляторе.
  • Изменения (файлы, пользователи, права) сохраняются в этом браузере (IndexedDB). Кнопка «Сбросить» возвращает чистую систему.
  • Первый запуск — до минуты: система подгружается частями с сайта. Нужен свежий браузер (Chrome, Edge, Firefox, Safari). Если вверху написано «Debian 10 (WebVM, запасной)» — наш диск не загрузился и работает публичный Debian без пакетов экзамена (вход root).

На телефоне: снизу есть клавиши Tab, Ctrl, Esc, стрелки. Ctrl нажимается, потом буква (Ctrl → c = прервать команду).
