Настоящий Linux Debian в браузере

Это настоящий Debian Linux (32-bit, Debian 10), а не наш симулятор: обычные bash, useradd, groupadd, passwd, chmod, chown, tar, nano, vim, find, grep, ps и т.д. Он работает прямо в браузере через WebAssembly (движок CheerpX); ничего устанавливать не надо.

  • Ты вошёл как root. Есть обычный пользователь user (пароль password): su - user, выход — exit.
  • Изменения (файлы, пользователи, права) сохраняются в этом браузере (IndexedDB). Кнопка «Сбросить» возвращает чистую систему.
  • Интернета внутри нет: apt install, ping, curl не сработают.
  • Сеть и службы (netplan, ip addr, isc-dhcp-server, systemctl) здесь не работают как на сервере — их тренируй в симуляторе Linux-сервера на сайте.
  • Первый запуск — до минуты: система подгружается частями с сервера. Нужен свежий браузер (Chrome, Edge, Firefox, Safari). Если не запускается — открой webvm.io (тот же Debian).

На телефоне: снизу есть клавиши Tab, Ctrl, Esc, стрелки. Ctrl нажимается, потом буква (Ctrl → c = прервать команду).
