# INF.02-05-26.01-SG: VLAN-trunk «router on a stick», CrystalDiskInfo и FTP-сервер в IIS

Сценарий: три VLAN (1, 2, 3) с маршрутизацией на роутере — интерфейсы VLAN тегированы на порту 2 роутера, коммутатор передаёт их по trunk-порту 4 и раздаёт на порты доступа 1, 2, 3. В станцию ставится запасной диск, его параметры снимаются CrystalDiskInfo. Windows Server (два интерфейса в разных VLAN) получает роль IIS с FTP-сайтом `FTP_egzamin`, Windows-станция из VLAN 3 заходит на FTP и создаёт папку. Отдельно оценивается прямой патч-корд T568B.

## Порядок работы (план на 150 минут)

1. 0–15 мин — патч-корд T568B + тест (Задание 1).
2. 15–30 мин — монтаж диска, CrystalDiskInfo (Задания 5–6).
3. 30–65 мин — VLAN на роутере и коммутаторе, подключение (Задания 2–4). Самая рискованная часть — не торопись.
4. 65–110 мин — сервер: сеть, пользователь, IIS FTP (Задание 7).
5. 110–135 мин — станция, проверка FTP, пинги (Задания 8–9).
6. 135–150 мин — проверка.

## Задание 1. Патч-корд T568B

**Что требуется** — прямой U/UTP, 8P8C с двух сторон, T568B, кабель «linka».

**Как сделать** — снять оболочку, порядок **бело-оранжевый, оранжевый, бело-зелёный, синий, бело-синий, зелёный, бело-коричневый, коричневый**, ровно подрезать, оболочка под фиксатором, обжать оба конца; поднять руку, тест при экзаменаторе.

**За что дают баллы** — T568B с обеих сторон; фиксатор на оболочке; тест пройден; «linka»; подключение по схеме.

## Задание 2. Роутер: VLAN-интерфейсы

**Что требуется**
- DHCP выключен.
- VLAN ID 1 (имя `VLAN1`) — порт 2 tagged (trunk), IP `10.10.1.1/24`.
- VLAN ID 2 (`VLAN2`) — порт 2 tagged, IP `10.10.2.1/25` (маска `255.255.255.128`).
- VLAN ID 3 (`VLAN3`) — порт 2 tagged, IP `10.10.3.1/26` (маска `255.255.255.192`).
- Включена маршрутизация между VLAN.

**Как сделать** (названия меню зависят от модели)
1. Зайди на роутер, смени пароль при требовании; `DHCP → Disable` → Save.
2. Раздел `Network → VLAN` / `LAN → VLAN` / `Interfaces → VLAN`: создай VLAN ID 1, 2, 3 с именами `VLAN1`, `VLAN2`, `VLAN3`; для каждого порт **2 = Tagged**.
3. Для каждого VLAN-интерфейса задай IP и маску (`10.10.1.1/24`, `10.10.2.1/25`, `10.10.3.1/26`). На роутерах, где VLAN 1 = основной LAN, адрес `10.10.1.1` задаётся в `Network → LAN`.
4. Включи `Inter-VLAN routing` (если есть отдельный флажок) → Save.

**Как проверить** — список интерфейсов показывает три VLAN с адресами; позднее станция в VLAN 3 пингует сервер в VLAN 1 и 2.

**За что дают баллы** — DHCP выключен; по 1 баллу за каждый VLAN с тегом на порту 2 и правильным IP.

**Частые ошибки** — смена адреса LAN раньше, чем создан доступ к роутеру (теряешь управление) — делай IP последним шагом и переподключайся.

## Задание 3. Коммутатор: VLAN 802.1Q

**Что требуется**
- IP `10.10.1.123/24` (L3 — на интерфейсе VLAN 1), шлюз `10.10.1.1`.
- VLAN 1: порт 1 untagged, порт 4 tagged. VLAN 2: порт 2 untagged, порт 4 tagged. VLAN 3: порт 3 untagged, порт 4 tagged.

**Как сделать**
1. `System → IP Setting` → Static: `10.10.1.123`, `255.255.255.0`, Gateway `10.10.1.1` → Apply.
2. `VLAN → 802.1Q VLAN` → Enable.
3. VLAN 1: порт 1 Untagged, порт 4 Tagged, порты 2 и 3 — **Not Member** (убери их из VLAN 1).
4. Создай VLAN 2 (`VLAN2`): порт 2 Untagged, порт 4 Tagged. VLAN 3 (`VLAN3`): порт 3 Untagged, порт 4 Tagged.
5. `802.1Q PVID Setting`: порт 1 → PVID 1, порт 2 → PVID 2, порт 3 → PVID 3, порт 4 → PVID 1.
6. Save Config. Управление коммутатором остаётся в VLAN 1 (через порт 1).

**За что дают баллы** — IP/шлюз; VLAN 2 (порт 2 U, порт 4 T); VLAN 3 (порт 3 U, порт 4 T).

**Частые ошибки** — PVID портов 2/3 оставлен 1; порт 4 сделан untagged.

## Задание 4. Подключение по схеме

Порт 2 роутера ↔ порт 4 коммутатора (trunk); сервер LAN1 → порт 1, сервер LAN2 → порт 2, станция → порт 3 (сверь со схемой).

## Задание 5. Монтаж запасного диска

Выключи станцию, **отключи кабель питания**, браслет. Закрепи диск минимум одним винтом с каждой стороны, подключи SATA-кабель данных и питание. Подними руку.
**За что дают баллы** — диск закреплён без люфта; подключены данные и питание.

## Задание 6. CrystalDiskInfo

**Что требуется** — установить CrystalDiskInfo из `DIAGNOSTYKA` на носителе; для запасного диска в таблицу 1: серийный номер, режим интерфейса, температура °C, время работы в часах. Скриншот `paramerty_dysku.jpg` (имя как в листе) в папку `identyfikacja` на флешке `Egzamin-x`.

**Как сделать**
1. Установи и запусти программу, выбери **запасной** диск вверху (вкладки дисков).
2. Перепиши: `Numer seryjny`, `Tryb transferu` (напр. `SATA/600 | SATA/600`), `Temperatura`, `Czas pracy` (в часах).
3. Скриншот (`Win+Shift+S`) → Paint → `Zapisz jako → JPEG` → `E:\identyfikacja\paramerty_dysku.jpg`.

**За что дают баллы** — программа установлена; 4 параметра совпадают со скриншотом.

**Частые ошибки** — сняли параметры системного диска вместо запасного.

## Задание 7. Windows Server: сеть, пользователь, FTP

**Что требуется**
- `LAN1` (порт 1): `10.10.1.10/24`, шлюз `10.10.1.1`, DNS `8.8.8.8`, `1.1.1.1`.
- `LAN2` (порт 2): `10.10.2.20/25`, шлюз `10.10.2.1`, DNS `8.8.8.8`, `1.1.1.1`.
- `C:\ftp\egzamin.txt` с текстом `EGZAMIN ZAWODOWY INF.02`.
- Пользователь `Egzamin`, пароль `Zdajacy!@#`, «Użytkownik nie może zmienić hasła» и «Hasło nigdy nie wygasa».
- IIS + FTP: сайт `FTP_egzamin`, путь `C:\ftp`, IP LAN2 (`10.10.2.20`), порт 21, без SSL; аутентификация, авторизация: `Egzamin` — чтение и запись, анонимные — чтение.

**Как сделать**
1. `ncpa.cpl` → переименуй адаптеры `LAN1`/`LAN2`, задай IPv4 (на двух интерфейсах будет предупреждение о двух шлюзах — это нормально).
2. `lusrmgr.msc → Nowy użytkownik` → `Egzamin`, сними «musi zmienić hasło», отметь «nie może zmienić hasła» и «Hasło nigdy nie wygasa».
3. `Menedżer serwera → Zarządzaj → Dodaj role i funkcje → Serwer sieci Web (IIS)` → в службах роли отметь `Serwer FTP → Usługa FTP`.
4. Менеджер IIS → `Witryny` → ПКМ `Dodaj witrynę FTP…` → nazwa `FTP_egzamin`, ścieżka `C:\ftp` → Powiązanie: adres IP `10.10.2.20`, port `21`, SSL: **Bez SSL** → Uwierzytelnianie: **Anonimowe** и **Podstawowe**; Autoryzacja: `Określeni użytkownicy` → `Egzamin`, Uprawnienia: Odczyt + Zapis → Zakończ.
5. В сайте `FTP_egzamin` → `Reguły autoryzacji FTP → Dodaj regułę zezwalającą` → `Wszyscy użytkownicy anonimowi` → Odczyt.
6. NTFS: `C:\ftp → Właściwości → Zabezpieczenia → Edytuj → Dodaj` → `Egzamin` → **Modyfikacja** (без этого папку на FTP не создать).

```powershell
Rename-NetAdapter -Name "Ethernet" -NewName "LAN1"
Rename-NetAdapter -Name "Ethernet 2" -NewName "LAN2"
New-NetIPAddress -InterfaceAlias "LAN1" -IPAddress 10.10.1.10 -PrefixLength 24 -DefaultGateway 10.10.1.1
New-NetIPAddress -InterfaceAlias "LAN2" -IPAddress 10.10.2.20 -PrefixLength 25 -DefaultGateway 10.10.2.1
Set-DnsClientServerAddress -InterfaceAlias "LAN1","LAN2" -ServerAddresses 8.8.8.8,1.1.1.1
New-Item C:\ftp -ItemType Directory
Set-Content C:\ftp\egzamin.txt "EGZAMIN ZAWODOWY INF.02"
New-LocalUser -Name "Egzamin" -Password (ConvertTo-SecureString "Zdajacy!@#" -AsPlainText -Force) `
  -UserMayNotChangePassword -PasswordNeverExpires
Install-WindowsFeature Web-Server, Web-Ftp-Server -IncludeManagementTools
icacls C:\ftp /grant "Egzamin:(OI)(CI)M"
Enable-NetFirewallRule -Name FPS-ICMP4-ERQ-In      # ответ на ping
```

**Как проверить** — в IIS у сайта видна привязка `10.10.2.20:21`, сайт запущен; `ipconfig /all`.

**За что дают баллы** — LAN1; LAN2 (маска 255.255.255.128); папка и файл; пользователь с двумя опциями; роль IIS с FTP; имя и путь сайта; IP 10.10.2.20; авторизация Egzamin RW + анонимы R.

**Частые ошибки** — оставлен SSL «Wymagaj» — Проводник не подключится; нет NTFS-права записи для Egzamin.

## Задание 8. Windows-станция

**Что требуется** — `LAN3`: `10.10.3.44/26` (маска `255.255.255.192`), шлюз `10.10.3.1`, DNS `8.8.8.8`, `1.1.1.1`; в Проводнике войти на FTP как `Egzamin` и создать папку `INF.02`.

**Как сделать**
```powershell
Rename-NetAdapter -Name "Ethernet" -NewName "LAN3"
New-NetIPAddress -InterfaceAlias "LAN3" -IPAddress 10.10.3.44 -PrefixLength 26 -DefaultGateway 10.10.3.1
Set-DnsClientServerAddress -InterfaceAlias "LAN3" -ServerAddresses 8.8.8.8,1.1.1.1
```
Проводник → в адресной строке `ftp://10.10.2.20` → ПКМ на пустом месте → `Zaloguj jako…` → `Egzamin` / `Zdajacy!@#` → ПКМ `Nowy → Folder` → `INF.02`.

**За что дают баллы** — имя LAN3; IP/маска/шлюз/DNS; по адресу ftp://10.10.2.20 видны `egzamin.txt` и папка `INF.02`.

## Задание 9. Тест связи со станции

```powershell
ping 10.10.1.10      # LAN1 сервера
ping 10.10.2.20      # LAN2 сервера
ping 10.10.1.123     # коммутатор
```
Если сервер не отвечает — включи на нём правило ICMP (см. Задание 7). Подними руку, повтори при экзаменаторе.
