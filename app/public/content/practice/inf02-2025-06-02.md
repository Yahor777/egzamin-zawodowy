# INF.02-02-25.06-SG: RAM в Linux (dmidecode), NIC Teaming, домен AD с перемещаемым профилем

Сценарий: в рабочую станцию (на диске Windows и Linux) ставится запасной модуль RAM, его параметры снимаются в Linux. Роутер — статический WAN без DHCP, коммутатор — VLAN 200 на портах 1–4. Windows Server объединяет две сетевые карты в команду `LAN12` (NIC Teaming), становится контроллером домена `informatyk.local`, получает OU `Serwisanci`, пользователя `abackia` с перемещаемым профилем в скрытом ресурсе `profile$`. Windows-станция входит в домен, шифрует файл (EFS). В конце — график работ в электронной таблице с условным форматированием.

## Порядок работы (план на 150 минут)

1. 0–10 мин — установка RAM (Задание 1).
2. 10–25 мин — загрузка Linux, `dmidecode`, скриншот `ram.jpg` (Задание 2).
3. 25–50 мин — роутер, коммутатор, кабели (Задания 3–5).
4. 50–95 мин — сервер: имя, NIC Teaming, AD DS, OU, пользователь, ресурс, профиль (Задание 6).
5. 95–125 мин — станция: сеть, имя, EFS, домен, вход как abackia (Задание 7).
6. 125–135 мин — пинги (Задание 8).
7. 135–150 мин — таблица «harmonogram» (Задание 9).

## Задание 1. Установка запасного модуля RAM

**Что требуется** — установить запасной модуль RAM; поднять руку до закрытия корпуса и запуска.

**Как сделать**
1. Выключи ПК, **выдерни кабель питания**, надень антистатический браслет.
2. Найди свободный слот (обычно того же цвета, что занятый — для двухканального режима), отожми защёлки.
3. Совмести вырез модуля с ключом слота, вдави до щелчка.
4. Подними руку; после оценки закрой корпус и загрузи **Linux**.

**За что дают баллы** — модуль установлен без повреждений; устройства подключены по схеме; в процессе — питание выключено, браслет, правильные инструменты.

## Задание 2. Параметры RAM в Linux

**Что требуется** — в таблицу 1: ёмкость, стандарт, частота, производитель, серийный номер или номер продукта. Скриншот — файл `ram.jpg` на флешке `Egzamin-x`.

**Как сделать**
```bash
sudo dmidecode -t memory | less     # блоки "Memory Device"
# или кратко:
sudo dmidecode -t 17 | grep -E "Size|Type:|Speed|Manufacturer|Serial|Part"
sudo lshw -short -C memory          # альтернатива
```
Нужные поля: `Size` (ёмкость), `Type` (DDR4/DDR5 — стандарт), `Speed` (частота, MT/s), `Manufacturer`, `Serial Number` / `Part Number`.

Скриншот в JPG:
```bash
gnome-screenshot -w -f ~/ram.jpg               # если установлен gnome-screenshot
cp ~/ram.jpg /media/administrator/Egzamin-*/   # путь флешки смотри в lsblk
```
Если есть только клавиша `PrtSc` (сохраняет PNG в `~/Obrazy/Zrzuty ekranu`), открой PNG в GIMP/LibreOffice Draw и экспортируй как `ram.jpg`.

**За что дают баллы** — скриншот с инструментом системы; по баллу за каждую из 5 строк таблицы (совпадает со скриншотом).

**Частые ошибки** — модулей несколько, а в таблицу записан пустой слот («No Module Installed»); файл назван не `ram.jpg`.

## Задание 3. Роутер

**Что требуется** — WAN `200.200.200.9/28` (маска `255.255.255.240`), шлюз `200.200.200.1`, DNS `4.4.4.4`, второй `8.8.8.8`; LAN `192.168.0.1/24`; DHCP выключен.

**Как сделать** — веб-интерфейс по адресу из папки `RUTER`; `Network → WAN` → Static IP → IP, маска, шлюз, DNS → Save; `DHCP → Disable`; `Network → LAN` → `192.168.0.1`, `255.255.255.0` → Save.

**За что дают баллы** — WAN (IP, маска, шлюз, DNS); LAN; DHCP выключен.

## Задание 4. Коммутатор: IP и VLAN 200

**Что требуется** — IP `192.168.0.2/24` (на L3 — на интерфейсе VLAN 200), шлюз `192.168.0.1`, VLAN 802.1Q ID `200`, порты 1, 2, 3, 4 — untagged (access).

**Как сделать**
1. `System → IP Setting` → Static: `192.168.0.2`, `255.255.255.0`, Gateway `192.168.0.1`.
2. `VLAN → 802.1Q VLAN` → Enable → VLAN ID `200`, порты 1–4 **Untagged** (из VLAN 1 их убери).
3. `802.1Q PVID Setting`: порты 1–4 → PVID `200`.
4. Если есть «Management VLAN» — поставь `200`, иначе потеряешь доступ. Save Config.

**За что дают баллы** — IP; VLAN 200 создан; порты 1–4 untagged; пинги сервер → роутер, станция, коммутатор.

## Задание 6. Windows Server

**Что требуется**
- Интерфейс к порту 3 → `LAN1`, к порту 4 → `LAN2`.
- NIC Teaming `LAN12` из LAN1+LAN2: **niezależny od przełącznika**, **dynamiczne** równoważenie, все карты активны; IP `192.168.0.4/24`, шлюз `192.168.0.1`, DNS localhost.
- Имя компьютера `SERWER-XX` (XX — номер места).
- AD DS, новый лес `informatyk.local`, пароль DSRM `ZAQ!2wsx`.
- OU `Serwisanci`, пользователь Adam Abacki, логин `abackia`, пароль `12!@EWSX`.
- Папка `C:\Profile`, ресурс `profile$`: общие права только «Wszyscy — Pełna kontrola»; NTFS только Administratorzy и Użytkownicy — Pełna kontrola.
- Путь перемещаемого профиля для abackia в этом ресурсе.

**Как сделать**
1. `ncpa.cpl` → переименуй адаптеры (какой в каком порту — смотри по выдернутому кабелю: статус «Kabel sieciowy odłączony»).
2. `Menedżer serwera → Serwer lokalny → Tworzenie zespołu kart interfejsu sieciowego: Wyłączone` → `ZESPOŁY → ZADANIA → Nowy zespół` → имя `LAN12`, отметь LAN1 и LAN2 → `Właściwości dodatkowe`: Tryb tworzenia zespołu **Niezależny od przełącznika**, Tryb równoważenia obciążenia **Dynamiczny**, Karta rezerwowa **Brak (wszystkie karty są aktywne)** → OK.
3. В `ncpa.cpl` появится адаптер `LAN12` → IPv4: `192.168.0.4`, `255.255.255.0`, `192.168.0.1`, DNS `127.0.0.1`.
4. `Serwer lokalny → Nazwa komputera → Zmień` → `SERWER-05` → перезагрузка (**до** установки AD!).
5. `Dodaj role i funkcje → Usługi domenowe w usłudze Active Directory` → `Promuj ten serwer do roli kontrolera domeny → Dodaj nowy las` → `informatyk.local` → DSRM `ZAQ!2wsx` → Zainstaluj.
6. `Użytkownicy i komputery usługi Active Directory` → домен → `Nowy → Jednostka organizacyjna` → `Serwisanci` → в ней `Nowy → Użytkownik`: Imię `Adam`, Nazwisko `Abacki`, logowanie `abackia`, пароль `12!@EWSX`, сними «musi zmienić hasło».
7. `C:\Profile → Właściwości → Udostępnianie → Udostępnianie zaawansowane` → `Udostępnij ten folder`, nazwa `profile$` → `Uprawnienia` → Wszyscy: **Pełna kontrola** (других записей не должно быть).
8. `Zabezpieczenia → Zaawansowane → Wyłącz dziedziczenie → Usuń…` → `Dodaj`: Administratorzy — Pełna kontrola, Użytkownicy — Pełna kontrola.
9. Свойства `abackia` → вкладка `Profil` → `Ścieżka profilu`: `\\SERWER-05\profile$\%username%`.

```powershell
Rename-NetAdapter -Name "Ethernet" -NewName "LAN1"
Rename-NetAdapter -Name "Ethernet 2" -NewName "LAN2"
New-NetLbfoTeam -Name "LAN12" -TeamMembers "LAN1","LAN2" -TeamingMode SwitchIndependent -LoadBalancingAlgorithm Dynamic
New-NetIPAddress -InterfaceAlias "LAN12" -IPAddress 192.168.0.4 -PrefixLength 24 -DefaultGateway 192.168.0.1
Set-DnsClientServerAddress -InterfaceAlias "LAN12" -ServerAddresses 127.0.0.1
Rename-Computer -NewName "SERWER-05" -Restart
Install-WindowsFeature AD-Domain-Services -IncludeManagementTools
Install-ADDSForest -DomainName "informatyk.local" -InstallDns `
  -SafeModeAdministratorPassword (ConvertTo-SecureString "ZAQ!2wsx" -AsPlainText -Force)
# после перезагрузки:
New-ADOrganizationalUnit -Name "Serwisanci" -Path "DC=informatyk,DC=local"
New-ADUser -Name "Adam Abacki" -GivenName Adam -Surname Abacki -SamAccountName abackia `
  -UserPrincipalName abackia@informatyk.local -Path "OU=Serwisanci,DC=informatyk,DC=local" `
  -AccountPassword (ConvertTo-SecureString "12!@EWSX" -AsPlainText -Force) -Enabled $true `
  -ProfilePath "\\SERWER-05\profile$\abackia"
New-Item C:\Profile -ItemType Directory
New-SmbShare -Name 'profile$' -Path C:\Profile -FullAccess 'Wszyscy'
icacls C:\Profile /inheritance:r /grant:r "*S-1-5-32-544:(OI)(CI)F" "*S-1-5-32-545:(OI)(CI)F"
```

**Как проверить** — `Get-NetLbfoTeam` (Status Up); `Get-SmbShareAccess 'profile$'` — только Wszyscy Full; после входа abackia на станции и выхода в `C:\Profile` появится папка `abackia.V6`.

**За что дают баллы** — имена LAN1/LAN2 + команда LAN12; IP команды; AD DS + DC; лес informatyk.local; OU; пользователь; ресурс profile$; права (только Wszyscy FC / только Administratorzy+Użytkownicy FC); путь профиля `\\SERWER-XX\profile$\abackia`; папка профиля в `C:\Profile`.

**Частые ошибки**
- Сменили имя сервера **после** повышения до DC — так делать нельзя.
- Не удалили «Odczyt» у Wszyscy по умолчанию / унаследованные NTFS-права.
- Профиль-папка не появилась, потому что abackia не вышел из системы на станции.

## Задание 7. Windows-станция

**Что требуется** — `LAN3`: `192.168.0.3/24`, шлюз `192.168.0.1`, DNS — IP сервера `192.168.0.4`; имя `SERWIS`; `C:\PLIKI\tapeta.jpg` (из `PLIKI` носителя), зашифровать атрибутом; присоединить к домену; войти как `abackia` и выйти.

**Как сделать**
1. `ncpa.cpl` → переименуй в `LAN3`, IPv4: `192.168.0.3`, `255.255.255.0`, `192.168.0.1`, DNS `192.168.0.4`.
2. Скопируй файл в `C:\PLIKI`. `tapeta.jpg → Właściwości → Zaawansowane → Szyfruj zawartość, aby zabezpieczyć dane` → OK → «Szyfruj tylko plik».
3. `sysdm.cpl → Zmień…` → Nazwa komputera `SERWIS`, Członek: **Domena** `informatyk.local` → учётка `Administrator` / пароль домена → перезагрузка.
4. На экране входа: `Inny użytkownik` → `INFORMATYK\abackia`, пароль `12!@EWSX` → дождись рабочего стола → **Wyloguj**.

```powershell
Rename-NetAdapter -Name "Ethernet" -NewName "LAN3"
New-NetIPAddress -InterfaceAlias "LAN3" -IPAddress 192.168.0.3 -PrefixLength 24 -DefaultGateway 192.168.0.1
Set-DnsClientServerAddress -InterfaceAlias "LAN3" -ServerAddresses 192.168.0.4
cipher /e C:\PLIKI\tapeta.jpg
Add-Computer -DomainName "informatyk.local" -NewName "SERWIS" -Credential INFORMATYK\Administrator -Restart
```

**Как проверить** — имя файла в Проводнике с замком; `cipher C:\PLIKI` показывает `E tapeta.jpg`; `nslookup informatyk.local` отвечает с `192.168.0.4`.

**За что дают баллы** — LAN3 и параметры; имя SERWIS; станция в домене; вход abackia возможен; папка PLIKI; файл; файл зашифрован.

**Частые ошибки** — DNS станции не указывает на сервер → «Nie można skontaktować się z kontrolerem domeny».

## Задание 9. График работ (таблица)

**Что требуется** — файл `harmonogram` на флешке; столбцы «Nazwa czynności» и «Czas wykonania [min]» по таблице 2; сумма в «RAZEM» считается формулой; ячейка суммы синяя, если ≤ 150, иначе зелёная.

**Как сделать** (Excel или LibreOffice Calc)
1. A1 `Nazwa czynności`, B1 `Czas wykonania [min]`; A2–A7 — шесть действий из таблицы 2; B2–B7 — минуты (невыполненное = 0); A8 `RAZEM:`, B8 `=SUMA(B2:B7)`.
2. Excel: выдели B8 → `Narzędzia główne → Formatowanie warunkowe → Nowa reguła → Użyj formuły…` → `=B8<=150` → Wypełnienie niebieskie; вторая правило `=B8>150` → зелёное.
   Calc: `Format → Warunkowe → Warunek…` → «Wartość komórki» «mniejsza lub równa» `150` → новый стиль с синим фоном; `Dodaj` → «większa niż» `150` → зелёный фон.
3. Сохрани как `harmonogram.xlsx` (или `.ods`) на флешке `Egzamin-x`.

**За что дают баллы** — файл с двумя столбцами; неотрицательные значения; цвет по условию; автоматическая сумма.
