# INF.02-03-25.06-SG: VLAN 2/3 с маршрутизацией, DNS + IIS-сайт, политика входа Ctrl+Alt+Del

Сценарий: роутер маршрутизирует две сети VLAN (2 — станция `172.16.100.0/24`, 3 — сервер и принтер `192.168.0.0/24`), тегированные на порту 2; коммутатор принимает их по trunk-порту 1. Windows Server получает DNS-зону `egzamin.local` с записью `www` и IIS-сайт `egzamin` с документом по умолчанию `egzamin.html`. Windows-станция открывает `www.egzamin.local`, на ней включается Ctrl+Alt+Del и сообщение при входе. Также оценивают патч-корд T568B и идентификацию комплектующих.

## Порядок работы (план на 150 минут)

1. 0–15 мин — патч-корд + тест (Задание 1).
2. 15–55 мин — роутер (VLAN), коммутатор (VLAN), подключение (Задания 2–4).
3. 55–95 мин — сервер: сеть, DNS, IIS (Задание 5).
4. 95–120 мин — станция, страница, пинги (Задания 6–7).
5. 120–140 мин — идентификация компонентов (Задание 8).
6. 140–150 мин — проверка.

Схема адресов (X — номер места; для места 5: сервер `192.168.0.205`):

| Устройство | Адрес | Шлюз |
|---|---|---|
| Роутер LAN / VLAN2 / VLAN3 | 192.168.1.1 / 172.16.100.100 / 192.168.0.100 | — |
| Коммутатор | 192.168.1.144/24 | 192.168.1.1 |
| Сервер LAN_WWW (VLAN 3) | 192.168.0.200+X/24 | 192.168.0.100 |
| Станция LAN_SR (VLAN 2) | 172.16.100.10/24 | 172.16.100.100 |
| Принтер (VLAN 3) | 192.168.0.200 | — |

## Задание 1. Патч-корд T568B

**Что требуется** — прямой U/UTP, оба конца 8P8C по T568B, кабель «linka».

**Как сделать** — порядок **бело-оранжевый, оранжевый, бело-зелёный, синий, бело-синий, зелёный, бело-коричневый, коричневый**; оболочка под фиксатором; обжать оба конца; поднять руку и проверить тестером при экзаменаторе.

**За что дают баллы** — T568B с двух сторон; фиксатор на оболочке; «linka»; тест пройден; подключение по схеме; аккуратность и инструменты (BHP).

## Задание 2. Роутер: VLAN 2 и VLAN 3

**Что требуется**
- LAN `192.168.1.1/24`; DHCP выключен; 802.1Q включён.
- VLAN ID 2 на порту 2 tagged (trunk), IP `172.16.100.100/24`.
- VLAN ID 3 на порту 2 tagged, IP `192.168.0.100/24`.
- Маршрутизация между VLAN включена.

**Как сделать**
1. Веб-интерфейс роутера → `DHCP → Disable`.
2. `Network → LAN` → `192.168.1.1`, `255.255.255.0` → Save, переподключись.
3. `Network → VLAN` (или `Interfaces → VLAN`): Enable 802.1Q → `Add`: ID `2`, порт 2 **Tagged**, IP `172.16.100.100`, маска `255.255.255.0`; `Add`: ID `3`, порт 2 **Tagged**, IP `192.168.0.100`, маска `255.255.255.0`.
4. Включи Inter-VLAN routing (если есть флажок) → Save.

**За что дают баллы** — LAN-IP; VLAN 2 tagged на порту 2 с IP; VLAN 3 tagged на порту 2 с IP; DHCP выключен.

## Задание 3. Коммутатор

**Что требуется** — IP `192.168.1.144/24`, шлюз `192.168.1.1`; 802.1Q; VLAN 2: порт 1 tagged, порт 2 untagged; VLAN 3: порт 1 tagged, порты 3 и 4 untagged.

**Как сделать**
1. `System → IP Setting` → Static: `192.168.1.144`, `255.255.255.0`, `192.168.1.1`.
2. `VLAN → 802.1Q VLAN` → Enable. VLAN 1 оставь с портом 1 untagged (по нему идёт управление и LAN роутера).
3. VLAN 2: порт 1 **Tagged**, порт 2 **Untagged**. VLAN 3: порт 1 **Tagged**, порты 3, 4 **Untagged**. Порты 2–4 убери из VLAN 1.
4. `PVID`: порт 2 → 2, порты 3, 4 → 3, порт 1 → 1. Save Config.

**За что дают баллы** — IP+шлюз; VLAN 2 (1 T, 2 U); VLAN 3 (1 T, 3–4 U).

**Частые ошибки** — не изменён PVID; порт 1 сделан untagged в VLAN 2/3.

## Задание 4. Подключение по схеме

Порт 2 роутера ↔ порт 1 коммутатора; станция → порт 2; сервер и розетка E-X (принтер) → порты 3 и 4 (см. схему). Затем питание.

## Задание 5. Windows Server: сеть, DNS, IIS

**Что требуется**
- Интерфейс к коммутатору: `LAN_WWW`, `192.168.0.200+X/24`, шлюз `192.168.0.100`, DNS localhost; второй интерфейс выключен.
- Роли IIS и DNS; первичная прямая зона `egzamin.local`, запись хоста `www` → IP LAN_WWW.
- `C:\www\egzamin.html` (это `index.html` из `PLIKI`, переименованный).
- Сайт `egzamin`: путь `C:\www`, привязка только HTTP, IP LAN_WWW, порт 80, документ по умолчанию `egzamin.html`.

**Как сделать**
1. `ncpa.cpl` → переименуй в `LAN_WWW`, IPv4: `192.168.0.205`, `255.255.255.0`, `192.168.0.100`, DNS `127.0.0.1`. Второй адаптер → ПКМ `Wyłącz`.
2. `Menedżer serwera → Zarządzaj → Dodaj role i funkcje` → `Serwer DNS` + `Serwer sieci Web (IIS)`.
3. `Narzędzia → DNS → Strefy wyszukiwania do przodu → Nowa strefa → Strefa podstawowa` → `egzamin.local` → ПКМ `Nowy host (A lub AAAA)` → `www`, `192.168.0.205`.
4. Создай `C:\www`, скопируй `index.html`, переименуй в `egzamin.html` (включи `Widok → Rozszerzenia nazw plików`, чтобы не получилось `egzamin.html.html`).
5. Менеджер IIS → `Witryny → Dodaj witrynę sieci Web`: nazwa `egzamin`, ścieżka `C:\www`, Typ `http`, Adres IP `192.168.0.205`, Port `80`. Остановить `Default Web Site`.
6. Сайт `egzamin` → `Dokument domyślny` → `Dodaj…` → `egzamin.html` (переместь вверх).

```powershell
Rename-NetAdapter -Name "Ethernet" -NewName "LAN_WWW"
New-NetIPAddress -InterfaceAlias "LAN_WWW" -IPAddress 192.168.0.205 -PrefixLength 24 -DefaultGateway 192.168.0.100
Set-DnsClientServerAddress -InterfaceAlias "LAN_WWW" -ServerAddresses 127.0.0.1
Disable-NetAdapter -Name "Ethernet 2" -Confirm:$false
Install-WindowsFeature DNS, Web-Server -IncludeManagementTools
Add-DnsServerPrimaryZone -Name "egzamin.local" -ZoneFile "egzamin.local.dns"
Add-DnsServerResourceRecordA -ZoneName "egzamin.local" -Name "www" -IPv4Address 192.168.0.205
Import-Module WebAdministration
Stop-Website "Default Web Site"
New-Website -Name "egzamin" -PhysicalPath "C:\www" -IPAddress 192.168.0.205 -Port 80
Add-WebConfigurationProperty -PSPath "IIS:\Sites\egzamin" -Filter "system.webServer/defaultDocument/files" -Name "." -Value @{value="egzamin.html"}
```

**Как проверить** — `nslookup www.egzamin.local 127.0.0.1`; в браузере сервера `http://192.168.0.205`.

**За что дают баллы** — IP/шлюз/DNS; имя LAN_WWW; роли; `C:\www\egzamin.html`; зона; запись www; сайт + документ по умолчанию; привязка HTTP/IP/80.

**Частые ошибки** — вместо документа по умолчанию сайт отдаёт 403 (нет `egzamin.html` в списке); привязка «Wszystkie nieprzypisane» вместо IP LAN_WWW.

## Задание 6. Windows-станция

**Что требуется** — `LAN_SR`: `172.16.100.10/24`, шлюз `172.16.100.100`, DNS = IP сервера; требование Ctrl+Alt+Del; текст сообщения «Uwaga! Logujesz się do komputera egzaminacyjnego!»; открыть `www.egzamin.local`.

**Как сделать**
1. `ncpa.cpl` → `LAN_SR`, IPv4: `172.16.100.10`, `255.255.255.0`, `172.16.100.100`, DNS `192.168.0.205`.
2. `secpol.msc → Zasady lokalne → Opcje zabezpieczeń`:
   - `Logowanie interakcyjne: nie wymagaj naciśnięcia klawiszy CTRL+ALT+DEL` → **Wyłączone**;
   - `Logowanie interakcyjne: tekst komunikatu dla użytkowników próbujących się zalogować` → `Uwaga! Logujesz się do komputera egzaminacyjnego!`;
   - (по желанию) `…tytuł komunikatu…` — любой заголовок.
3. Браузер → `http://www.egzamin.local` → поднять руку.

```powershell
Rename-NetAdapter -Name "Ethernet" -NewName "LAN_SR"
New-NetIPAddress -InterfaceAlias "LAN_SR" -IPAddress 172.16.100.10 -PrefixLength 24 -DefaultGateway 172.16.100.100
Set-DnsClientServerAddress -InterfaceAlias "LAN_SR" -ServerAddresses 192.168.0.205
```

**За что дают баллы** — адресация; Ctrl+Alt+Del; текст сообщения; страница открыта; пинги с сервера.

## Задание 7. Тест связи с сервера

```powershell
ping 172.16.100.10    # станция (через маршрутизацию VLAN)
ping 192.168.0.100    # роутер
ping 192.168.0.200    # принтер
```
Станция не отвечает → на ней `Enable-NetFirewallRule -Name FPS-ICMP4-ERQ-In`. Подними руку.

## Задание 8. Идентификация компонентов станции

**Что требуется** — в таблицу 1 производитель и модель: CPU, материнская плата, видеокарта, диск; скриншоты на флешку `Egzamin-x`.

**Как сделать**
1. `msinfo32` → `Podsumowanie systemu`: `Procesor`, `Producent płyty głównej`, `Produkt płyty głównej`.
2. `devmgmt.msc` → `Karty graficzne` и `Stacje dysków` — модели (или `msinfo32 → Składniki → Ekran / Magazyn → Dyski`).
3. Скриншоты сохрани на флешку.

**За что дают баллы** — по баллу за CPU, плату, видеокарту, диск (как в реальности).
