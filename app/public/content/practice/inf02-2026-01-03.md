# INF.02-03-26.01-SG: RAM, msinfo32, принтер RAW, пакетные файлы .bat и Apache на Linux

Сценарий: меняешь планку RAM, снимаешь параметры системы (msinfo32) в таблицу 1, настраиваешь роутер (статический WAN + DHCP) и коммутатор. На Windows-станции — статический IP, сетевой принтер через RAW, пользователь `EGZAMIN`, политика сложности паролей и три пакетных файла. На Linux-сервере — статический IP, Apache с новой главной страницей и каталог `/kopie_strony` с правами и владельцем веб-сервера.

## Порядок работы (план на 150 минут)

1. 0–15 мин — замена RAM, оценка (Задание 1).
2. 15–25 мин — msinfo32 + скриншоты (Задание 2).
3. 25–50 мин — роутер, коммутатор, подключение (Задания 3–5).
4. 50–80 мин — Windows: сеть, принтер, пользователь, политика (Задание 6).
5. 80–100 мин — пакетные файлы (Задание 7).
6. 100–135 мин — Linux: сеть, Apache, `/kopie_strony` (Задание 8).
7. 135–150 мин — пинги (Задание 9), проверка.

## Задание 1. Замена RAM

**Что требуется** — снять установленный модуль, поставить запасной; поднять руку до запуска системы.

**Как сделать**
1. Выключи ПК, **выдерни кабель питания**, надень антистатический браслет.
2. Открой корпус, отожми защёлки, вынь модуль; вставь запасной по ключу до щелчка.
3. Подними руку. После оценки закрой корпус и запусти Windows.

**За что дают баллы** — демонтаж; монтаж без повреждений; система загружается; устройства подключены по схеме; в процессе — питание отключено, браслет, порядок.

## Задание 2. Идентификация параметров

**Что требуется** — в таблицу 1: название ОС, версия ОС, установленная RAM, доступная RAM, доступная виртуальная память, объём файла подкачки. Скриншоты — в папку `podzespoly` на флешке `Egzamin-x`.

**Как сделать**
1. `Win+R` → `msinfo32` → `Podsumowanie systemu`. Там всё сразу: `Nazwa systemu operacyjnego`, `Wersja`, `Zainstalowana pamięć fizyczna (RAM)`, `Dostępna pamięć fizyczna`, `Dostępna pamięć wirtualna`, `Obszar pliku stronicowania`.
2. Сделай скриншот (`Win+Shift+S`), вставь в Paint, сохрани в `E:\podzespoly\`.
3. Перепиши значения **точно как на экране** (с единицами GB/MB).

**За что дают баллы** — 4 критерия: ОС+версия; RAM установленная и доступная; виртуальная память; файл подкачки — всё совпадает со скриншотом.

**Частые ошибки** — путают «Dostępna pamięć wirtualna» и «Całkowita pamięć wirtualna».

## Задание 6. Windows-станция

**Что требуется**
- IP `192.168.0.10+X/24` (место 5 → `192.168.0.15`), шлюз и DNS `192.168.0.1`.
- Принтер `192.168.0.200` через протокол **RAW**, распечатать тестовую страницу (поднять руку, приложить к листу).
- Пользователь: полное имя и логин `EGZAMIN`, пароль `INF@02egz#`, «użytkownik nie może zmienić hasła».
- Добавить в группу **Czytelnicy dzienników zdarzeń**; включить требование сложности паролей.

**Как сделать**
1. `ncpa.cpl → Właściwości → Protokół internetowy w wersji 4` → адрес, маска `255.255.255.0`, brama `192.168.0.1`, DNS `192.168.0.1`.
2. Принтер: `Panel sterowania → Urządzenia i drukarki → Dodaj drukarkę → Drukarki, której szukam, nie ma na liście → Dodaj drukarkę przy użyciu adresu TCP/IP lub nazwy hosta` → `192.168.0.200`, сними «Odpytaj drukarkę…» → если спросит тип — `Niestandardowe → Ustawienia`: Protokół **Raw**, port **9100** → выбери драйвер (например Generic / Text Only или с носителя) → `Drukuj stronę testową`.
3. `lusrmgr.msc → Użytkownicy → Nowy użytkownik`: Nazwa `EGZAMIN`, Pełna nazwa `EGZAMIN`, hasło, сними «Użytkownik musi zmienić hasło przy następnym logowaniu», отметь **«Użytkownik nie może zmienić hasła»**.
4. Свойства пользователя → `Członek grupy → Dodaj` → `Czytelnicy dzienników zdarzeń`.
5. `secpol.msc → Zasady konta → Zasady haseł → Hasło musi spełniać wymagania co do złożoności` → **Włączone**.

```powershell
New-NetIPAddress -InterfaceAlias "Ethernet" -IPAddress 192.168.0.15 -PrefixLength 24 -DefaultGateway 192.168.0.1
Set-DnsClientServerAddress -InterfaceAlias "Ethernet" -ServerAddresses 192.168.0.1
Add-PrinterPort -Name "IP_192.168.0.200" -PrinterHostAddress "192.168.0.200"   # RAW, 9100
net user EGZAMIN INF@02egz# /add /fullname:"EGZAMIN" /passwordchg:no
net localgroup "Czytelnicy dzienników zdarzeń" EGZAMIN /add
```

**Как проверить** — `ipconfig /all`; `net user EGZAMIN` (строка «Użytkownik może zmieniać hasło: Nie»); свойства порта принтера — Raw.

**За что дают баллы** — IP/шлюз/DNS; пользователь; запрет смены пароля; группа; сложность паролей; принтер; тестовая страница.

**Частые ошибки** — оставлена галочка «musi zmienić hasło» — тогда «nie może zmienić» недоступна.

## Задание 7. Пакетные файлы

**Что требуется**
- Папка `C:\Wsadowe`, в неё скопировать папки `archiwum1`, `archiwum2`, `dane` из `PLIKI` на носителе.
- `plik1.bat` — копирует все файлы из `dane` в `archiwum1`.
- `plik2.bat` — расширение как параметр, копирует файлы с этим расширением из `dane` в `archiwum2`.
- `plik3.bat` — дописывает в конец `dane\informacje.txt`: «Nowy wpis w dniu:», текущую дату, список папок и файлов только корня `C:`.
- Запустить все три.

**Как сделать** — создай файлы в Блокноте («Zapisz jako» → Typ: Wszystkie pliki, имя с `.bat`).

`plik1.bat`:
```bat
copy /Y C:\Wsadowe\dane\*.* C:\Wsadowe\archiwum1\
```
`plik2.bat`:
```bat
copy /Y C:\Wsadowe\dane\*.%1 C:\Wsadowe\archiwum2\
```
`plik3.bat`:
```bat
echo Nowy wpis w dniu:>> C:\Wsadowe\dane\informacje.txt
echo %date%>> C:\Wsadowe\dane\informacje.txt
dir C:\ /b >> C:\Wsadowe\dane\informacje.txt
```
Запуск в `cmd`:
```bat
cd C:\Wsadowe
plik1.bat
plik2.bat txt
plik3.bat
```

**Как проверить** — `dir archiwum1`, `dir archiwum2` (только `.txt`), `type dane\informacje.txt`.

**За что дают баллы** — папки на месте; есть хотя бы один рабочий .bat; plik1; plik2 с параметром `%1`; plik3 с автоматическими датой (`%date%`) и списком (`dir C:\`).

**Частые ошибки** — `>` вместо `>>` (файл перезаписан); `dir C:\ /s` выводит подкаталоги — нужен только корень.

## Задание 8. Linux-сервер: сеть и Apache

**Что требуется**
- Интерфейс к коммутатору: `192.168.0.30+X/24` (место 5 → `192.168.0.35`), шлюз `192.168.0.1`, DNS localhost; второй интерфейс выключен.
- Записать в таблицу 2 путь корня сайта; заменить главную страницу на `index.html` из `PLIKI`; запустить HTTP-сервер; открыть страницу браузером.
- `/kopie_strony`: права владелец — полные, группа — r-x, остальные — нет (**750**); владелец и группа — те, под кем работает Apache.

**Как сделать**
1. Netplan (`ls /etc/netplan`, затем редактируй файл):
```yaml
network:
  version: 2
  ethernets:
    enp0s3:
      dhcp4: false
      addresses: [192.168.0.35/24]
      routes:
        - to: default
          via: 192.168.0.1
      nameservers:
        addresses: [127.0.0.1]
    enp0s8:
      activation-mode: off
```
```bash
sudo netplan apply
sudo ip link set enp0s8 down     # сразу выключить второй интерфейс
```
2. Корень сайта: `grep DocumentRoot /etc/apache2/sites-enabled/000-default.conf` → в Ubuntu `/var/www/html` (в openSUSE `/srv/www/htdocs`) — запиши в таблицу 2.
3. Скопируй страницу с флешки:
```bash
lsblk                                  # флешка, напр. /dev/sdb1
sudo mount /dev/sdb1 /mnt
sudo cp /mnt/PLIKI/index.html /var/www/html/index.html
sudo systemctl restart apache2 && sudo systemctl enable apache2
lynx http://localhost        # или firefox, если есть GUI
```
Подними руку, когда страница («EGZAMIN INF.02!» на синем фоне) видна.
4. Пользователь Apache: `grep RUN_ /etc/apache2/envvars` → `www-data` / `www-data` (openSUSE: `wwwrun` / `www`).
```bash
sudo mkdir /kopie_strony
sudo chmod 750 /kopie_strony
sudo chown www-data:www-data /kopie_strony
ls -ld /kopie_strony        # drwxr-x--- www-data www-data
```

**За что дают баллы** — IP/шлюз/DNS; путь в таблице 2 верный; заменена страница; страница открыта в браузере; `/kopie_strony` с 750; владелец/группа веб-сервера; пинги.

**Частые ошибки** — скопировали файл как `index.html` в другую папку, а Apache показывает старую страницу; забыли запустить `apache2`.
