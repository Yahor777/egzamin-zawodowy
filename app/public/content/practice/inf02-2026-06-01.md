# INF.02-01-26.06-SG: запасной диск, VLAN 2/4, общий диск DRUGI и смета на сервер хранения

Сценарий: монтируешь запасной HDD в рабочую станцию, настраиваешь роутер (LAN + DHCP с резервацией для сервера) и коммутатор (VLAN 2 и 4), подключаешь всё по схеме. Потом диагностика рабочей станции в Linux, настройка Windows на станции (интерфейс, пользователь, новый диск, общий ресурс), настройка Windows Server (два интерфейса, сетевой принтер, подключение диска K:) и смета в табличном процессоре. Оценивается 6 результатов: монтаж и подключение, диагностика, сетевые устройства, сервер, рабочая станция, смета, а также ход монтажа.

> Файла с критериями (_zo) для этого листа нет, поэтому раздел «За что дают баллы» составлен по тексту задания и по аналогичным листам 2026 года.

## Порядок работы (план на 150 минут)
1. Монтаж диска, поднять руку (0–10 мин).
2. Подключение кабелей по схеме (10–15).
3. Роутер: LAN + DHCP; резервацию добавишь, когда узнаешь MAC LANZ сервера (15–30).
4. Коммутатор: IP, VLAN 2/4, поднять руку (30–45).
5. Linux на станции: диагностика + скриншоты (45–60).
6. Windows на станции: LAN2, TESTY, диск M:, общий ресурс DRUGI, брандмауэр (60–85).
7. Сервер: LANZ/LANW, принтер, тестовая страница, K: (85–110).
8. Проверка связи с экзаменатором (110–115).
9. Смета KOSZTORYS (115–140), резерв 10 мин.

## Задание 1. Монтаж запасного жёсткого диска
**Что требуется**
- Установить запасной диск в системный блок рабочей станции; после монтажа поднять руку.

**Как сделать**
1. Выключи ПК, отключи кабель питания, надень антистатический браслет (BHP — это тоже оценивают).
2. Закрепи диск в корзине 3,5"/2,5" винтами (все 4 винта, не «на одном»).
3. Подключи кабель SATA data к свободному порту SATA на материнской плате и кабель питания SATA от блока питания.
4. Аккуратно уложи кабели, подними руку. Только после разрешения закрывай корпус и включай.

**Как проверить**
- В BIOS/UEFI (или позже в `Zarządzanie dyskami`) диск виден.

**За что дают баллы**
- Диск закреплён стабильно, подключены сигнальный и силовой кабели, плата не повреждена; работа велась с соблюдением BHP, рабочее место убрано.

**Частые ошибки**
- Включить ПК до проверки экзаменатором.
- Забыть кабель питания диска.

## Задание 2. Роутер
**Что требуется**
- LAN: `192.168.16.1/24`.
- DHCP включён, диапазон `192.168.16.12 ÷ 192.168.16.20`.
- Резервация `192.168.16.12` для интерфейса **LANZ** сервера.

**Как сделать**
1. Подключись к роутеру по адресу по умолчанию (см. документацию на носителе DOKUMENTACJA/PROGRAMY, обычно `192.168.0.1` или `192.168.1.1`), при необходимости смени пароль.
2. `Network → LAN`: IP `192.168.16.1`, маска `255.255.255.0`, сохранить. Роутер перезагрузится — получи на ПК новый адрес и зайди на `http://192.168.16.1`.
3. `DHCP → DHCP Settings`: Enable, Start `192.168.16.12`, End `192.168.16.20`, сохранить.
4. На сервере узнай MAC интерфейса LANZ: `ipconfig /all` (поле «Adres fizyczny») или `getmac /v`.
5. `DHCP → Address Reservation → Add New`: MAC LANZ (в формате роутера, например `AA-BB-CC-DD-EE-FF`), IP `192.168.16.12`, Enabled, сохранить.

**Как проверить**
- На сервере после `ipconfig /renew` у LANZ адрес `192.168.16.12`.

**За что дают баллы**
- IP LAN 192.168.16.1/24; DHCP включён с нужным диапазоном; резервация 192.168.16.12 на MAC именно LANZ.

**Частые ошибки**
- Резервация на MAC не того интерфейса (LANW вместо LANZ).
- Адрес резервации вне пула — тут он внутри пула, это допустимо.

## Задание 3. Коммутатор
**Что требуется**
- VLAN 802.1Q с ID = 2 и ID = 4.
- Порты 1, 2, 3 → VLAN 2 без тегов (access); порт 4 → VLAN 4 без тегов.
- IP коммутатора `192.168.0.32/24` (на L3 — на интерфейсе VLAN 2), шлюз `192.168.0.X` (X — номер стенда).

**Как сделать**
1. Зайди на коммутатор по адресу из документации. Сначала `System → IP Setting`: DHCP выкл., IP `192.168.0.32`, маска `255.255.255.0`, шлюз `192.168.0.X`. Перезайди на новый адрес (ПК временно в 192.168.0.0/24).
2. `VLAN → 802.1Q VLAN`: включи 802.1Q (Enable).
3. Создай VLAN 2: порты 1, 2, 3 — Untagged. Создай VLAN 4: порт 4 — Untagged.
4. Убери порты 1–4 из VLAN 1 (снять Untagged/Not Member).
5. `802.1Q PVID Setting`: PVID портов 1–3 = 2, порта 4 = 4.
6. На L3/управляемом коммутаторе: management VLAN = 2 (интерфейс VLAN 2 с IP 192.168.0.32). Подними руку.

**Как проверить**
- Таблица VLAN: VLAN 2 = порты 1–3 untagged, VLAN 4 = порт 4 untagged; страница IP показывает 192.168.0.32/24 и шлюз 192.168.0.X.

**За что дают баллы**
- Созданы VLAN 2 и 4; правильные порты без тегов; IP 192.168.0.32/24 и шлюз 192.168.0.X.

**Частые ошибки**
- Не поменять PVID — порт остаётся в VLAN 1.
- Потерять доступ к управлению: подключайся к порту из VLAN управления (1–3).

## Задание 5. Диагностика в Linux
**Что требуется**
- Заполнить таблицу 3: название и версия ОС, процессор (название и обозначение), объём RAM, максимальное разрешение монитора; при отсутствии данных писать «brak danych».
- Скриншоты в папку `LINUX` на USB `Egzamin-x`.
- Оценка: можно ли поставить CAD (Ubuntu 20.04+/openSUSE 15.5+, Intel i3/Ryzen 3, RAM 8 GB, 1280×720) с обоснованием.

**Как сделать**
```bash
cat /etc/os-release          # NAME и VERSION
lsb_release -a               # то же самое (Ubuntu)
lscpu | grep -i "model name" # процессор
free -h                      # RAM (строка Mem:, total)
xrandr | grep -A3 connected  # разрешения монитора (максимальное — первое/самое большое)
lsblk; ls /media/$USER       # найди точку монтирования USB Egzamin-x
mkdir -p /media/$USER/Egzamin-x/LINUX
```
Скриншот: клавиша `PrtSc` (Ubuntu сохраняет в `~/Obrazy/Zrzuty ekranu` или `~/Pictures/Screenshots`), затем скопируй: `cp ~/Obrazy/Zrzuty\ ekranu/* /media/$USER/Egzamin-x/LINUX/`.

**Как проверить**
- Значения в таблице совпадают со скриншотами (экзаменатор сравнивает именно это).

**За что дают баллы**
- Каждая строка таблицы заполнена и подтверждена скриншотом; оценка с аргументами (например: «Instalacja możliwa: Ubuntu 24.04 ≥ 20.04, Intel Core i5 ≥ i3, RAM 16 GB ≥ 8 GB, 1920×1080 ≥ 1280×720»).

**Частые ошибки**
- Написать в таблицу то, чего нет на скриншоте.
- Оценка без ссылки на конкретные параметры.

## Задание 6. Windows на рабочей станции
**Что требуется**
- Интерфейс к коммутатору: имя `LAN2`, IP `192.168.0.33/24`, шлюз и DNS = IP LANW сервера (`192.168.0.X`).
- Пользователь `TESTY` (полное имя и логин), пароль `TE20#st10@`, член группы `Administratorzy`.
- Запасной диск: один раздел на весь диск, NTFS, буква `M:`, метка `DANE`.
- Общий ресурс `DRUGI` (диск M:), полный доступ (общий доступ и NTFS) только для `Administratorzy`.

**Как сделать**
1. `Panel sterowania → Centrum sieci i udostępniania → Zmień ustawienia karty` (`ncpa.cpl`): переименуй адаптер в `LAN2`, `Właściwości → Protokół internetowy w wersji 4 (TCP/IPv4)`.
2. Пользователь: `lusrmgr.msc → Użytkownicy → Nowy użytkownik`, снять «Użytkownik musi zmienić hasło…»; `Właściwości → Członek grupy → Dodaj → Administratorzy`.
3. Диск: `diskmgmt.msc` → инициализировать (GPT) → `Nowy wolumin prosty` → весь объём, буква M, NTFS, etykieta DANE.
4. Общий доступ: ПКМ на M: → `Właściwości → Udostępnianie → Udostępnianie zaawansowane` → «Udostępnij ten folder», nazwa `DRUGI` → `Uprawnienia`: удалить `Wszyscy`, добавить `Administratorzy` — Pełna kontrola.
5. Вкладка `Zabezpieczenia` → `Zaawansowane` → `Wyłącz dziedziczenie` (преобразовать), удалить всё кроме `Administratorzy` (Pełna kontrola). `SYSTEM` можно оставить только если не мешает критерию; надёжнее оставить лишь Administratorzy.
6. Брандмауэр: разреши эхо ICMP (нужно для задания 8).

```powershell
Rename-NetAdapter -Name "Ethernet" -NewName "LAN2"
New-NetIPAddress -InterfaceAlias "LAN2" -IPAddress 192.168.0.33 -PrefixLength 24 -DefaultGateway 192.168.0.X
Set-DnsClientServerAddress -InterfaceAlias "LAN2" -ServerAddresses 192.168.0.X
New-LocalUser -Name "TESTY" -FullName "TESTY" -Password (ConvertTo-SecureString 'TE20#st10@' -AsPlainText -Force)
Add-LocalGroupMember -Group "Administratorzy" -Member "TESTY"
Initialize-Disk -Number 1 -PartitionStyle GPT
New-Partition -DiskNumber 1 -UseMaximumSize -DriveLetter M | Format-Volume -FileSystem NTFS -NewFileSystemLabel "DANE"
New-SmbShare -Name "DRUGI" -Path "M:\" -FullAccess "Administratorzy"
Enable-NetFirewallRule -Name FPS-ICMP4-ERQ-In
```

**Как проверить**
- `ipconfig /all`, `net user TESTY`, `net localgroup Administratorzy`, `Get-SmbShareAccess DRUGI`.

**За что дают баллы**
- Имя LAN2 и верные IP/шлюз/DNS; пользователь TESTY с паролем и в группе Administratorzy; диск M: NTFS DANE на весь объём; ресурс DRUGI с правами только для Administratorzy (и в общем доступе, и в NTFS).

**Частые ошибки**
- Оставить `Wszyscy`/`Użytkownicy` во вкладке Zabezpieczenia.
- Номер диска в PowerShell — проверь `Get-Disk`, не отформатируй системный.

## Задание 7. Windows Server
**Что требуется**
- `LANZ` (к роутеру): всё автоматически, обновить адрес.
- `LANW` (к коммутатору): `192.168.0.X/24`, без шлюза и DNS.
- Сетевой принтер: TCP/IP `192.168.0.200`, протокол RAW, драйвер из папки `DRUKARKA`; напечатать тестовую страницу (поднять руку), приложить к листу.
- Для Administrator подключить ресурс станции как диск `K:`.

**Как сделать**
1. `ncpa.cpl`: переименуй адаптеры в LANZ и LANW; LANZ — «Uzyskaj adres IP automatycznie», LANW — статический адрес без шлюза/DNS. `ipconfig /renew LANZ`.
2. Принтер: `Panel sterowania → Urządzenia i drukarki → Dodaj drukarkę → Drukarki, której szukam, nie ma na liście → Dodaj drukarkę przy użyciu adresu TCP/IP` → `192.168.0.200`, снять автоопрос; тип порта `Niestandardowy → Ustawienia → Raw, port 9100` → `Z dysku…` → папка DRUKARKA. В конце `Drukuj stronę testową`.
3. Диск K:: `Eksplorator → Ten komputer → Mapuj dysk sieciowy`, litera K:, folder `\\192.168.0.33\DRUGI`, «Połącz ponownie przy logowaniu», «Połącz przy użyciu innych poświadczeń» → `192.168.0.33\Administrator` / `ZAQ!2wsx`.

```powershell
Rename-NetAdapter -Name "Ethernet" -NewName "LANZ"
Rename-NetAdapter -Name "Ethernet 2" -NewName "LANW"
Set-NetIPInterface -InterfaceAlias "LANZ" -Dhcp Enabled
Set-DnsClientServerAddress -InterfaceAlias "LANZ" -ResetServerAddresses
ipconfig /renew LANZ
New-NetIPAddress -InterfaceAlias "LANW" -IPAddress 192.168.0.X -PrefixLength 24
Add-PrinterDriver -Name "<nazwa sterownika>"   # после pnputil /add-driver D:\DRUKARKA\*.inf
Add-PrinterPort -Name "IP_192.168.0.200" -PrinterHostAddress 192.168.0.200 -PortNumber 9100
Add-Printer -Name "Drukarka" -DriverName "<nazwa sterownika>" -PortName "IP_192.168.0.200"
net use K: \\192.168.0.33\DRUGI /user:192.168.0.33\Administrator ZAQ!2wsx /persistent:yes
```

**Как проверить**
- `ipconfig` (LANZ = 192.168.16.12), `Get-Printer`, `net use`.

**За что дают баллы**
- Имена LANZ/LANW; LANZ получает адрес по DHCP (192.168.16.12); LANW 192.168.0.X/24 без шлюза/DNS; установлен принтер 192.168.0.200 (RAW); напечатана тестовая страница; диск K: подключён к ресурсу DRUGI.

**Частые ошибки**
- Входить в ресурс как `TESTY`: из-за UAC удалённый токен локального админа (не встроенного) урезается, и доступ «только для Administratorzy» может не пройти. Используй встроенного `Administrator` станции.
- Указать шлюз на LANW.

## Задание 8. Проверка связи
**Что требуется**
- С сервера: ping коммутатора, принтера, станции и LAN роутера; показать IP LANZ. На станции при необходимости открыть брандмауэр.

**Как сделать**
```powershell
ping 192.168.0.32      # коммутатор
ping 192.168.0.200     # принтер
ping 192.168.0.33      # рабочая станция
ping 192.168.16.1      # LAN роутера
ipconfig               # адрес LANZ (192.168.16.12)
```
Поднять руку и повторить всё при экзаменаторе.

**За что дают баллы**
- Каждое устройство отвечает на ping; на экране автоматически полученный адрес LANZ.

**Частые ошибки**
- Станция не отвечает — не включено правило эха ICMPv4 в `Zapora Windows Defender → Ustawienia zaawansowane → Reguły przychodzące`.

## Задание 9. Смета KOSZTORYS
**Что требуется**
- Хранилище данных в домене AD, Windows, платформа Intel, плюс дополнительный HDD для архивов.
- Структура таблицы 4: Lp., Nazwa elementu, Cena netto, VAT (kwota), Cena brutto, Ilość, Wartość netto, Wartość brutto; строки Suma, Rabat 10%, Do zapłaty. Сохранить как `KOSZTORYS` на USB.

**Как сделать**
1. Подбор (только из таблицы 2): Płyta główna 2 (Z390, Socket 1151) + Procesor 1 (i9-9900K, Socket 1151, DDR4-2666) + Pamięć RAM 1 (DDR4) + Dysk 1 SSD (система) + Dysk 2 HDD 3000 GB (архив) + Zasilacz 1 ATX 650 W + Obudowa (ATX) + System operacyjny 1 **Windows 11 Pro** (Home нельзя подключить к домену AD). Видеокарта не нужна: у i9-9900K есть встроенная графика, у платы есть видеовыходы.
2. Пусть данные начинаются со строки 2 (C — Cena netto, F — Ilość). Формулы:
   - D2 `=C2*23%`, E2 `=C2+D2`, G2 `=C2*F2`, H2 `=E2*F2`, протяни вниз.
   - Suma: `=SUMA(G2:G9)` и `=SUMA(H2:H9)` (в английском Excel `SUM`).
   - Rabat: `=JEŻELI(H10>=2000;H10*10%;0)` (англ. `IF`).
   - Do zapłaty: `=H10-H11`.
3. Денежные ячейки: `Formatuj komórki → Walutowe → zł`.

**За что дают баллы**
- Правильный подбор совместимых компонентов под Intel/AD/архив; автоматические VAT, брутто, значения; суммы через SUMA; условный рабат через JEŻELI; Do zapłaty с учётом рабата; формат валюты; имя файла KOSZTORYS.

**Частые ошибки**
- Выбрать Windows Home или плату AM4 (AMD).
- Вписать числа вручную вместо формул.
