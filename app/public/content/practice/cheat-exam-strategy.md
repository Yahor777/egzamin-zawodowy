# Стратегия на практической части INF.02

## 1. Как считаются баллы

- Лист делится на **4–6 rezultatów** (кабель+подключение, идентификация, сетевые устройства, сервер, станция, таблица/смета) + **przebieg** (наблюдение за процессом монтажа: инструменты, BHP, порядок).
- Каждый критерий — **1 балл, T (spełnia) / N (nie spełnia)**, без частичных. Всего обычно **35–50 критериев**.
- Сдал практику = **≥ 75 % всех критериев**. Пример: 44 критерия → нужно 33, можно потерять **11**.
- Письменная часть — отдельно, порог 50 %. Обе части нужны для диплома.
- Экзаминатор проверяет **по скриншотам, по таблице в листе и вживую** (ping, GUI роутера). Сделал, но не задокументировал скриншотом, когда это требовалось = 0.
- Нестандартное, но правильное решение принимается («zgodnie ze sztuką»). Неважно, GUI или PowerShell — важен результат.

## 2. Тайминг (150 мин + 10 мин на чтение)

**10 минут чтения (не входят во время):** прочитай весь лист, обведи: номера портов, имена интерфейсов, X = номер места, пароли, имена папок для скриншотов; посмотри схему подключения; найди флешки `DOKUMENTACJA/PROGRAMY` и `Egzamin-x`, документацию роутера/свитча. Подумай, какие задания блокируют другие.

| Минуты | Что | Почему так |
|---|---|---|
| 0–20 | **Физика**: кабель/Keystone или монтаж RAM/диска → поднять руку → оценка | монтаж оценивают с наблюдением, лучше пока свеж и пока экзаминатор свободен; без монтажа станция не запустится |
| 20–25 | Подключить устройства **по схеме**, запустить ПК | всё остальное зависит от кабелей |
| 25–50 | **Роутер → рука, коммутатор → рука** | 8–10 простых баллов; от них зависят DHCP и ping |
| 50–100 | **Сервер** (сеть → имя → роли → AD/DNS/IIS/общие папки) | самый большой блок; AD DS ставь рано — перезагрузка 5–10 мин, в это время делай станцию |
| 100–125 | **Станция** (сеть, пользователи, политики, домен) | присоединение к домену требует готового DC |
| 125–135 | Идентификация параметров + скриншоты (если ещё не сделана), смета в Calc/Excel | механическая работа |
| 135–150 | **Ping-тесты → рука**, финальная проверка по чек-листу | ping проверяют вживую в конце |

> Идентификацию «до/после замены» (CPU-Z до и после смены RAM/видеокарты) делай **в порядке листа**: часть параметров нужно снять до демонтажа!

## 3. Когда поднимать руку

Только в местах с «**UWAGA: … zgłoś gotowość … przez podniesienie ręki**». Типично:
1. после монтажа кабеля → тест тестером при экзаминаторе;
2. после монтажа компонента (до закрытия корпуса);
3. после настройки роутера; 4. после настройки коммутатора;
5. перед печатью тестовой страницы («chęć wydruku zgłoś»);
6. после ping-тестов → повтор при экзаминаторе;
7. показ сайта/FTP/IP, полученного по DHCP.

Пока ждёшь экзаминатора — **не стой**, делай следующее задание (кроме того, что требует того же устройства).

## 4. Чек-лист «самые частые потери баллов»

- [ ] **X / XX = номер места**: `192.168.0.10+X` → для места 5 = `192.168.0.15`; `firma05.local` (с ведущим нулём, если так в примере листа).
- [ ] Имена интерфейсов **точно** как в листе: `LAN Z` ≠ `LAN_Z` ≠ `LANZ`, регистр букв.
- [ ] DNS «localhost» = `127.0.0.1`; «brama: brak» — поле пустое; «drugi interfejs wyłączony» — реально выключен.
- [ ] Нужный адаптер = нужный порт коммутатора (проверь выдёргиванием кабеля).
- [ ] Флажки пароля пользователя: «hasło docelowe» → снять *musi zmienić hasło przy następnym logowaniu*.
- [ ] Share-права **и** NTFS-права — это два разных места; «tylko dla …» → удалить лишних, отключить наследование.
- [ ] Скриншоты: правильная **папка** и **имя файла** (`ram.jpg`, а не `ram.png`), на флешке `Egzamin-x`, на скриншоте видны значения/команда.
- [ ] Таблицы в бумажном листе заполнены, значения совпадают со скриншотами; пустых клеток нет («brak danych»).
- [ ] Брандмауэр: ping в **обе** стороны (ICMPv4 echo на сервере **и** станции).
- [ ] Роутер/свитч: настройки **сохранены**; DHCP выключен, если так написано.
- [ ] Конфигурации Linux применены (`netplan apply`, `systemctl restart`, `enable`).
- [ ] После перезагрузки DC вход уже `DOMENA\Administrator`; пароль мог смениться — записан.
- [ ] Использованные пароли записаны в таблицу листа, если просят.
- [ ] В конце **не выходить из системы и не выключать** компьютеры и сетевые устройства.

## 5. Если что-то не получается

- Застрял > 5 минут на одном пункте — **пропусти**, вернись в конце. Каждый критерий весит одинаково.
- Блокирующие зависимости: нет связи → сначала кабель/порт/VLAN/IP; нет домена → станцию настраивай без присоединения, вернёшься.
- Роутер/свитч «потерялся» после смены IP — задай ПК статический адрес в новой подсети; в крайнем случае Reset + быстрая повторная настройка (5 мин).
- Linux-служба не стартует → `systemctl status …` / `journalctl -u … -n 20` → обычно опечатка в конфиге.

## 6. Электронная таблица (смета/график, 37 % листов)

LibreOffice Calc / Excel по-польски — функции **на польском**, разделитель аргументов `;`, десятичная запятая.

| Нужно | Формула (пример) |
|---|---|
| VAT 23 % | `=C2*23%` или `=C2*0,23` |
| Cena brutto | `=C2+D2` или `=C2*1,23` |
| Wartość brutto | `=E2*F2` (cena brutto × ilość) |
| Suma kolumny | `=SUMA(G2:G10)` |
| Rabat 10 % если ≥ 2000 zł | `=JEŻELI(G11>=2000;G11*10%;0)` |
| Do zapłaty | `=G11-G12` |
| Wartość po rabacie 10 % / 5 % | `=JEŻELI(G11>4000;G11*0,9;G11*0,95)` |
| Napis TAK/NIE | `=JEŻELI(B11>=B12;"NIE";"TAK")` |
| +20 % zapasu | `=B9*1,2` |
| Roboczogodziny × stawka | `=C2*D2` и `=E2*$F$1` (абсолютная ссылка `$`) |

- Формат валюты: ПКМ → *Formatuj komórki* → *Walutowe* → `zł`, 2 знака после запятой.
- Цвет по условию (синий ≤150 мин, иначе зелёный): *Format → Formatowanie warunkowe → Warunek*: «wartość komórki ≤ 150» → стиль с синим фоном + второе условие «> 150» → зелёный (в Excel: *Narzędzia główne → Formatowanie warunkowe → Reguły wyróżniania komórek*).
- Ячейки с расчётами — **только формулами** (оценивают «obliczenia wykonują się automatycznie»). Проверь: поменяй число → итог меняется.
- Сохрани под **точным именем** на `Egzamin-x` (формат по умолчанию `.ods`/`.xlsx` подходит, если не указано иное).

## 7. «Wskazania» (письменные рекомендации, ~10 %)

Если просят ≥5 рекомендаций для пользователя ПК в Интернете — пиши коротко и **из разных областей**: aktualizacje systemu i programów; program antywirusowy i zapora; silne, unikalne hasła + menedżer haseł + 2FA; nie otwieraj podejrzanych załączników/linków (phishing); kopie zapasowe (zasada 3-2-1); szyfrowane połączenia HTTPS, unikaj publicznych Wi-Fi bez VPN; konto standardowe zamiast administratora; blokada ekranu przy odejściu; ergonomia/BHP (przerwy, odległość od monitora).

- Windows Server: `tools/check-winserver.ps1` — `Set-ExecutionPolicy -Scope Process Bypass; .\check-winserver.ps1 -Expect expect.json`.
- Linux: `sudo bash tools/check-linux.sh oczekiwane.txt`.
- Тренировка на время: возьми любой лист 2025–2026, поставь таймер 150 мин, в конце сверь с `_zo` (критерии оценки) и посчитай процент.
