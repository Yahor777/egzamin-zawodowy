# INF.02-02-26.01-SG: VLAN, DHCP с резервациями, DNS + IIS на Windows Server, диск в Linux

Сценарий: роутер раздаёт адреса по DHCP с двумя резервациями, коммутатор получает VLAN 802.1Q с ID 2. Windows Server (два интерфейса) получает роли DNS и IIS: прямая и обратная зона, сайт по имени `app.egzamin.local`. Рабочая станция работает на Linux: получает адрес по DHCP, в неё ставится второй диск, его надо разметить в ext4, смонтировать в `/dane` и сравнить скорость двух разделов. Отдельно оценивают прямой патч-корд T568B.

## Порядок работы (план на 150 минут)

1. 0–15 мин — кабель T568B + тест (Задание 1).
2. 15–25 мин — собрать MAC-адреса сервера (LAN2) и станции (нужны для резерваций).
3. 25–50 мин — роутер и коммутатор (VLAN), подключение по схеме (Задания 2–4).
4. 50–70 мин — интерфейсы сервера и станции, пинги (Задания 5–7).
5. 70–105 мин — DNS, папка, права, сайт IIS (Задание 8).
6. 105–140 мин — монтаж диска, раздел, `/dane`, тесты скорости (Задания 9–10).
7. 140–150 мин — финальная проверка.

## Задание 1. Прямой патч-корд T568B

**Что требуется** — прямой кабель, оба конца T568B, кабель типа «linka».

**Как сделать**
1. Сними оболочку стриппером, расплети пары, выпрями жилы.
2. T568B: **бело-оранжевый, оранжевый, бело-зелёный, синий, бело-синий, зелёный, бело-коричневый, коричневый**.
3. Подрежь ровно, вставь до упора (оболочка под фиксатором), обожми. Повтори на втором конце.
4. Подними руку — тест тестером при экзаменаторе.

**За что дают баллы** — T568B на обоих концах; оболочка зажата; «linka»; тест пройден; устройства подключены по схеме.

**Частые ошибки** — жилы не дошли до конца разъёма (тестер показывает обрыв).

## Задание 2. Роутер: LAN и DHCP с резервациями

**Что требуется**
- LAN `192.168.1.1/24`.
- DHCP включён: пул `192.168.1.101–192.168.1.150`, lease **12 часов**, DNS `192.168.1.101`.
- Резервации: `192.168.1.101` — интерфейс сервера, подключённый к коммутатору (LAN2); `192.168.1.102` — проводной интерфейс станции.

**Как сделать**
1. Узнай MAC: на сервере `getmac /v` или `ipconfig /all` («Adres fizyczny»), на Linux `ip link` (поле `link/ether`).
2. Веб-интерфейс роутера → `Network → LAN`: IP `192.168.1.1`, маска `255.255.255.0` → Save, переподключись по новому адресу.
3. `DHCP → DHCP Settings`: Enable, Start `192.168.1.101`, End `192.168.1.150`, Lease Time — 12 ч (на TP-Link поле в минутах: **720**), Primary DNS `192.168.1.101` → Save.
4. `DHCP → Address Reservation → Add New`: MAC сервера → `192.168.1.101`; MAC станции → `192.168.1.102`; статус Enabled.

**Как проверить** — список резерваций содержит оба MAC; после обновления аренды адреса совпадают.

**За что дают баллы** — LAN-IP; пул; обе резервации; 12 ч; DNS 192.168.1.101.

**Частые ошибки** — MAC взят не с того адаптера сервера (у сервера их два!).

## Задание 3. Коммутатор: IP и VLAN 802.1Q

**Что требуется** — IP `192.168.1.2/24` (на L3-коммутаторе — на интерфейсе VLAN 2), шлюз `192.168.1.1`, включён 802.1Q, создан VLAN ID 2, порты 1, 2, 3 — **untagged** (access) в VLAN 2.

**Как сделать**
1. Зайди в коммутатор (адрес по умолчанию из документации, ПК временно в той же подсети).
2. `System → IP Setting`: Static, `192.168.1.2`, маска `255.255.255.0`, Gateway `192.168.1.1` → Apply.
3. `VLAN → 802.1Q VLAN`: включи (Enable) → создай VLAN ID `2` (имя например `VLAN2`), порты 1, 2, 3 — **Untagged**.
4. `802.1Q PVID Setting`: портам 1, 2, 3 задай PVID `2`.
5. На L3-коммутаторе создай интерфейс VLAN 2 и назначь IP ему. Сохрани конфигурацию (Save Config).

**Как проверить** — таблица VLAN: VLAN 2, порты 1–3 untagged, PVID = 2; ping 192.168.1.2 с сервера.

**За что дают баллы** — IP+шлюз; VLAN 2 создан; порты 1–3 untagged в VLAN 2.

**Частые ошибки** — не изменён PVID: кадры с портов продолжают идти в VLAN 1.

## Задание 4. Подключение по схеме

Сервер LAN2 → порт 1 коммутатора, станция и роутер — в порты по схеме (обычно 2 и 3, все в VLAN 2), сервер LAN1 → розетка E-X. Затем питание.

## Задание 5. Интерфейсы Windows Server

**Что требуется**
- Интерфейс к розетке E-X: имя `LAN1`, IP `192.168.0.X/24` (X — номер места), шлюза нет, DNS — localhost.
- Интерфейс к порту 1 коммутатора: имя `LAN2`, IP и DNS автоматически; обновить аренду.

**Как сделать**
1. `ncpa.cpl` → `Zmień nazwę` → `LAN1` / `LAN2`.
2. LAN1 → `Właściwości → Protokół internetowy w wersji 4 (TCP/IPv4)` → `Użyj następującego adresu IP`: `192.168.0.X`, `255.255.255.0`, brama пусто, DNS `127.0.0.1`.
3. LAN2 → `Uzyskaj adres IP automatycznie`, `Uzyskaj adres serwera DNS automatycznie`.

```powershell
Rename-NetAdapter -Name "Ethernet" -NewName "LAN1"
Rename-NetAdapter -Name "Ethernet 2" -NewName "LAN2"
New-NetIPAddress -InterfaceAlias "LAN1" -IPAddress 192.168.0.X -PrefixLength 24
Set-DnsClientServerAddress -InterfaceAlias "LAN1" -ServerAddresses 127.0.0.1
Set-NetIPInterface -InterfaceAlias "LAN2" -Dhcp Enabled
Set-DnsClientServerAddress -InterfaceAlias "LAN2" -ResetServerAddresses
ipconfig /release "LAN2"
ipconfig /renew "LAN2"
```

**Как проверить** — `ipconfig /all`: LAN2 = `192.168.1.101`, DNS `192.168.1.101`.

**За что дают баллы** — имя/IP/DNS LAN1; имя LAN2; LAN2 получил 192.168.1.101 и DNS 192.168.1.101.

## Задание 6. Интерфейс Linux-станции

**Что требуется** — соединение `LAN2`, IP автоматически, обновить аренду.

**Как сделать** (Ubuntu Desktop, NetworkManager):
```bash
nmcli device                     # имя устройства, напр. enp0s3
sudo nmcli con add type ethernet ifname enp0s3 con-name LAN2 ipv4.method auto
# или переименовать существующее:
# sudo nmcli con modify "Wired connection 1" connection.id LAN2
sudo nmcli con down LAN2; sudo nmcli con up LAN2
ip a show enp0s3
```
GUI: `Ustawienia → Sieć → ⚙ → Tożsamość: Nazwa LAN2; IPv4: Automatycznie (DHCP)`, выключить/включить соединение.

**Как проверить** — адрес `192.168.1.102`; `resolvectl status` — DNS `192.168.1.101`.

**За что дают баллы** — станция получила 192.168.1.102 и DNS 192.168.1.101.

## Задание 7. Тест связи с сервера

```powershell
ping 192.168.1.102     # станция
ping 192.168.0.200     # принтер (через LAN1)
ipconfig               # показать адрес LAN2
```
На станции: `ip a`. Подними руку, повтори при экзаменаторе.

## Задание 8. Windows Server: DNS, IIS, сайт

**Что требуется**
- Роли **Serwer DNS** и **Serwer sieci Web (IIS)**.
- Прямая зона `egzamin.local`, запись A `app` → `192.168.1.101`.
- Обратная зона для `192.168.1.0/24`, PTR `app` → `192.168.1.101`.
- Папка `C:\app` с `index.html` (из `PLIKI` на носителе DOKUMENTACJA/PROGRAMY).
- Права **только**: Administratorzy — Pełna kontrola, IUSR — Odczyt i wykonywanie.
- Новый сайт: путь `C:\app`, имя хоста `app.egzamin.local`; страница открывается на станции по `http://192.168.1.101`.

**Как сделать**
1. `Menedżer serwera → Zarządzaj → Dodaj role i funkcje` → отметь `Serwer DNS` и `Serwer sieci Web (IIS)` → Zainstaluj.
2. `Narzędzia → DNS` → `Strefy wyszukiwania do przodu → Nowa strefa` → Strefa podstawowa → `egzamin.local`. ПКМ на зоне → `Nowy host (A lub AAAA)` → `app`, `192.168.1.101` (можно сразу отметить «Utwórz skojarzony rekord wskaźnika (PTR)», если обратная зона уже есть).
3. `Strefy wyszukiwania wstecznego → Nowa strefa` → Strefa podstawowa → IPv4 → Identyfikator sieci `192.168.1` → ПКМ → `Nowy wskaźnik (PTR)` → `192.168.1.101` → `app.egzamin.local`.
4. Создай `C:\app`, скопируй `index.html`. `Właściwości → Zabezpieczenia → Zaawansowane → Wyłącz dziedziczenie → Usuń wszystkie odziedziczone uprawnienia`, затем `Dodaj`: Administratorzy — Pełna kontrola; IUSR (`Lokalizacje` = локальный компьютер) — Odczyt i wykonywanie.
5. `Narzędzia → Menedżer internetowych usług informacyjnych (IIS)` → `Witryny → Dodaj witrynę sieci Web`: nazwa `app`, ścieżka fizyczna `C:\app`, Powiązanie http, port 80, Nazwa hosta `app.egzamin.local`.
6. Чтобы `http://192.168.1.101` показывал именно эту страницу: `Default Web Site → Zatrzymaj`, затем у сайта `app` → `Powiązania → Dodaj` → http, adres IP `192.168.1.101`, port 80, имя хоста пустое.

```powershell
Install-WindowsFeature DNS, Web-Server -IncludeManagementTools
Add-DnsServerPrimaryZone -Name "egzamin.local" -ZoneFile "egzamin.local.dns"
Add-DnsServerResourceRecordA -ZoneName "egzamin.local" -Name "app" -IPv4Address 192.168.1.101
Add-DnsServerPrimaryZone -NetworkId "192.168.1.0/24" -ZoneFile "1.168.192.in-addr.arpa.dns"
Add-DnsServerResourceRecordPtr -ZoneName "1.168.192.in-addr.arpa" -Name "101" -PtrDomainName "app.egzamin.local"
New-Item C:\app -ItemType Directory
icacls C:\app /inheritance:r /grant:r "*S-1-5-32-544:(OI)(CI)F" "IUSR:(OI)(CI)RX"
Import-Module WebAdministration
New-Website -Name "app" -PhysicalPath "C:\app" -Port 80 -HostHeader "app.egzamin.local"
Stop-Website "Default Web Site"
New-WebBinding -Name "app" -IPAddress "192.168.1.101" -Port 80 -Protocol http
```

**Как проверить**
```powershell
nslookup app.egzamin.local 127.0.0.1
nslookup 192.168.1.101 127.0.0.1
icacls C:\app
```
На станции: `firefox http://192.168.1.101` (или `http://app.egzamin.local`). Подними руку.

**За что дают баллы** — роли; зона; A-запись; обратная зона 192.168.1.0/24; PTR; папка с index.html; ровно два ACL; сайт с хостом app.egzamin.local; страница открыта на станции.

**Частые ошибки**
- Не удалены унаследованные права (остались Użytkownicy, SYSTEM) — критерий «tylko» не выполнен.
- По IP открывается стандартная страница IIS, а не `index.html`.

## Задание 9. Монтаж запасного диска

Выключи станцию, отключи питание, браслет. Закрепи диск винтами, подключи SATA-данные и SATA-питание. Подними руку, затем включи.

## Задание 10. Linux: раздел, `/dane`, тест скорости

**Что требуется** — раздел на весь диск, ext4, смонтирован в `/dane`; тесты чтения системного и нового раздела с параметрами: передача — 200 проб по 20 MiB, время доступа — 1000 проб; средняя скорость с единицей в таблицу 1, скриншоты на флешку `Egzamin-x`, в последней строке — какой диск быстрее.

**Как сделать**
```bash
lsblk                                   # новый диск, напр. /dev/sdb
sudo parted /dev/sdb --script mklabel gpt mkpart primary ext4 0% 100%
sudo mkfs.ext4 /dev/sdb1
sudo mkdir /dane
sudo mount /dev/sdb1 /dane
df -h /dane
```
Тест: запусти **Dyski** (`gnome-disks`) → выбери раздел → меню ⚙/⋮ → `Testuj wydajność partycji…` → `Rozpocznij test wydajności…` → Szybkość przesyłania: Liczba próbek **200**, Rozmiar próbki **20 MiB**; Czas dostępu: Liczba próbek **1000**; тест записи выключи → Start. Сделай скриншот (`PrtSc`), сохрани на флешку. Повтори для системного раздела.

**Как проверить** — `lsblk -f` показывает `sdb1 ext4 /dane`.

**За что дают баллы** — диск установлен; раздел ext4 на всю ёмкость; смонтирован в `/dane`; оба теста с правильными параметрами; значения в таблице совпадают со скриншотами; верно указан более быстрый диск.

**Частые ошибки** — в таблице нет единицы (MB/s); скриншот без видимых параметров теста.
