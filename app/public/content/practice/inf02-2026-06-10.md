# INF.02-10-26.06-SG: сервер-маршрутизатор, домен egzamin.local с перемещаемым профилем и BitLocker на втором диске

Сценарий: обжимаешь прямой патч-корд, настраиваешь роутер (статический WAN /29, DHCP выкл., маршрут в 192.168.1.0/24 через сервер) и коммутатор с VLAN 101/102. Windows Server маршрутизирует между сетями (RRAS), отвечает на ping, становится DC `egzamin.local`; пользователь anowak получает перемещаемый профиль в `profiles$`. На станции — вход в домен, новый диск GPT с двумя разделами и BitLocker на R:. Оценивается 5 результатов: кабель и подключение, сетевые устройства, интерфейсы, сервер и станция, модернизация станции + ход работ.

## Порядок работы (план на 150 минут)
1. Патч-корд + тест (0–15 мин).
2. Монтаж диска (поднять руку), подключение по схеме (15–30).
3. Роутер (30–40), коммутатор (40–55).
4. Сервер: имя (перезагрузка!), V101/V102, RRAS, брандмауэр; станция V102; ping (55–75).
5. AD DS, OU, anowak, C:\Profiles, профиль (75–105).
6. Станция в домен, вход/выход anowak (105–115).
7. Разделы и BitLocker (115–135), резерв.

## Задание 1. Прямой патч-корд
**Что требуется**
- Прямой кабель, оба конца по **T568B**, тип кабеля — «linka».

**Как сделать**
1. Порядок T568B: бело-оранжевый, оранжевый, бело-зелёный, синий, бело-синий, зелёный, бело-коричневый, коричневый.
2. Жилы ~12–13 мм, до упора в 8P8C, оболочка под фиксатором; обжать оба конца. Подними руку, тест при экзаменаторе.

**За что дают баллы**
- T568B на обоих концах; фиксатор на внешней оболочке; кабель «linka»; тест OK; подключение по схеме; BHP.

**Частые ошибки**
- Слишком длинные жилы — фиксатор прижимает только жилы.

## Задание 2. Роутер
**Что требуется**
- WAN (PORT1): `90.90.90.1/29` (маска `255.255.255.248`), шлюз `90.90.90.2`, DNS `8.8.8.8`, `8.8.4.4`.
- LAN (PORT2): `192.168.0.1/24`; DHCP **выключен**.
- Статический маршрут: `192.168.1.0/24` через `192.168.0.3`.

**Как сделать**
1. `Network → WAN`: Static IP. `Network → LAN`: `192.168.0.1`/`255.255.255.0`.
2. `DHCP → Disable`.
3. `Advanced Routing → Static Routing → Add`: `192.168.1.0`, `255.255.255.0`, gateway `192.168.0.3`. Подними руку.

**За что дают баллы**
- WAN IP/29; шлюз и DNS; LAN 192.168.0.1/24; DHCP выкл.; маршрут через 192.168.0.3.

**Частые ошибки**
- /29 = 255.255.255.248 (не .240 и не .252).

## Задание 3. Коммутатор
**Что требуется**
- IP `192.168.0.2/24`, шлюз `192.168.0.1`; 802.1Q включён.
- VLAN 101: порты 1, 4 untagged; VLAN 102: порты 2, 3 untagged; на L3 IP на VLAN 101, управляющий VLAN 101.

**Как сделать**
1. `System → IP Setting`: IP, маска, шлюз.
2. `VLAN → 802.1Q VLAN`: Enable; VLAN 101 (1, 4 Untagged), VLAN 102 (2, 3 Untagged); убери порты из VLAN 1; PVID 1/4 = 101, 2/3 = 102; management VLAN 101. Подними руку.

**За что дают баллы**
- Созданы VLAN 101 и 102; правильные порты; IP/шлюз коммутатора.

## Задание 4. Подключение по схеме
- Сервер V101 ↔ порт 1, роутер PORT2 ↔ порт 4 (VLAN 101); сервер V102 ↔ порт 2, станция ↔ порт 3 (VLAN 102) — сверь со схемой листа.

## Задание 5. Интерфейсы, RRAS, брандмауэр
**Что требуется**
- Сервер: `V101` — `192.168.0.3/24`, шлюз `192.168.0.1`, DNS localhost; `V102` — `192.168.1.1/24`, DNS localhost.
- Роль `Dostęp zdalny` + `Routing`, включён `Routing sieci LAN`.
- Брандмауэр включён, правило на ответ на эхо ICMP.
- Станция: проводной `V102` — `192.168.1.2/24`, шлюз и DNS `192.168.1.1`; беспроводной выключен. Ping сервера и роутера.

**Как сделать (сервер)**
1. `ncpa.cpl`: переименуй адаптеры (V101 — тот, что в порту 1), IPv4.
2. `Dodaj role i funkcje → Dostęp zdalny → Routing` → `Routing i dostęp zdalny → Skonfiguruj i włącz… → Konfiguracja niestandardowa → Routing sieci LAN → Uruchom usługę`.
3. `Zapora Windows Defender z zabezpieczeniami zaawansowanymi → Reguły przychodzące` → включи «Udostępnianie plików i drukarek (żądanie echa — ICMPv4 — ruch przychodzący)» или создай новое правило ICMPv4 → Typ 8.
```powershell
Rename-NetAdapter -Name "Ethernet" -NewName "V101"; Rename-NetAdapter -Name "Ethernet 2" -NewName "V102"
New-NetIPAddress -InterfaceAlias "V101" -IPAddress 192.168.0.3 -PrefixLength 24 -DefaultGateway 192.168.0.1
New-NetIPAddress -InterfaceAlias "V102" -IPAddress 192.168.1.1 -PrefixLength 24
Set-DnsClientServerAddress -InterfaceAlias "V101","V102" -ServerAddresses 127.0.0.1
Install-WindowsFeature RemoteAccess, Routing -IncludeManagementTools
Install-RemoteAccess -VpnType RoutingOnly
Set-NetFirewallProfile -All -Enabled True
New-NetFirewallRule -DisplayName "ICMPv4 echo" -Protocol ICMPv4 -IcmpType 8 -Direction Inbound -Action Allow
```

**Как сделать (станция)**
```powershell
Rename-NetAdapter -Name "Ethernet" -NewName "V102"
New-NetIPAddress -InterfaceAlias "V102" -IPAddress 192.168.1.2 -PrefixLength 24 -DefaultGateway 192.168.1.1
Set-DnsClientServerAddress -InterfaceAlias "V102" -ServerAddresses 192.168.1.1
Disable-NetAdapter -Name "Wi-Fi" -Confirm:$false
ping 192.168.1.1; ping 192.168.0.3; ping 192.168.0.1
```

**За что дают баллы**
- Имена V101/V102 на сервере; адреса, шлюз, DNS localhost; станция 192.168.1.2/24, шлюз+DNS 192.168.1.1; ping сервера и роутера; Routing LAN; правило ICMP.

**Частые ошибки**
- Ping роутера не проходит: нет маршрута на роутере или RRAS не запущен.

## Задание 6. Active Directory и перемещаемый профиль
**Что требуется**
- Имя сервера `serwer-x` (до промоции!).
- AD DS, новый лес `egzamin.local`, DSRM `ZAQ!2wsx` (если потребуется сменить пароль Administrator — `zaq1@WSX`).
- OU `Pracownicy`, пользователь Adam Nowak, `anowak`, пароль `Mojedlugiehaslo!`, без смены при входе.
- `C:\Profiles`: NTFS только Administratorzy — Pełna kontrola; Użytkownicy uwierzytelnieni — Tworzenie folderów, `Dotyczy: tylko ten folder`.
- Ресурс `profiles$`, общий доступ только Wszyscy — Pełna kontrola.
- Профиль anowak: `\\serwer-x\profiles$\anowak`.

**Как сделать**
1. `Menedżer serwera → Serwer lokalny → Nazwa komputera` → `serwer-x` → перезагрузка.
2. `Usługi domenowe w usłudze Active Directory` → `Podnieś poziom… → Dodaj nowy las → egzamin.local` → DSRM → перезагрузка.
3. OU `Pracownicy` → `Nowy → Użytkownik`: Adam, Nowak, `anowak`, сними «musi zmienić hasło».
4. `C:\Profiles → Właściwości → Zabezpieczenia → Zaawansowane → Wyłącz dziedziczenie → Usuń wszystkie`. `Dodaj → Administratorzy → Pełna kontrola`. `Dodaj → Użytkownicy uwierzytelnieni → Pokaż uprawnienia zaawansowane`: только `Tworzenie folderów/dołączanie danych`, `Dotyczy: Tylko ten folder`.
5. `Udostępnianie zaawansowane → profiles$ → Uprawnienia: Wszyscy — Pełna kontrola` (`$` скрывает ресурс в сети).
6. `anowak → Właściwości → Profil → Ścieżka profilu: \\serwer-x\profiles$\%username%` (после OK превратится в `…\anowak`).
```powershell
Rename-Computer -NewName "serwer-x" -Restart
Install-WindowsFeature AD-Domain-Services -IncludeManagementTools
Install-ADDSForest -DomainName "egzamin.local" -SafeModeAdministratorPassword (ConvertTo-SecureString 'ZAQ!2wsx' -AsPlainText -Force) -InstallDns -Force
New-ADOrganizationalUnit -Name "Pracownicy" -Path "DC=egzamin,DC=local"
New-ADUser -Name "Adam Nowak" -GivenName Adam -Surname Nowak -SamAccountName anowak -Path "OU=Pracownicy,DC=egzamin,DC=local" `
  -AccountPassword (ConvertTo-SecureString 'Mojedlugiehaslo!' -AsPlainText -Force) -ChangePasswordAtLogon $false -Enabled $true `
  -ProfilePath "\\serwer-x\profiles$\anowak"
New-Item C:\Profiles -ItemType Directory
icacls C:\Profiles /inheritance:r /grant:r "*S-1-5-32-544:(OI)(CI)F" "*S-1-5-11:(AD)"
New-SmbShare -Name 'profiles$' -Path "C:\Profiles" -FullAccess "Wszyscy"
```
`(AD)` без `(OI)(CI)` = «Tworzenie folderów» только для этой папки; `S-1-5-11` — Użytkownicy uwierzytelnieni.

**Как проверить**
- `icacls C:\Profiles`, `Get-SmbShareAccess 'profiles$'`, `Get-ADUser anowak -Properties ProfilePath`.

**За что дают баллы**
- Routing LAN; правило ICMP; имя serwer-x; домен egzamin.local; OU + anowak; ACL C:\Profiles ровно как задано; profiles$ с Wszyscy FC; путь профиля `\\serwer-x\profiles$\anowak`; станция в домене; в C:\Profiles есть папка профиля anowak.

**Частые ошибки**
- Переименовать сервер после промоции — сложно и рискованно; делай до.
- Не выйти из anowak — папка профиля появится только после выхода.

## Задание 7. Станция в домене
**Как сделать**
1. `sysdm.cpl → Zmień → Domena: egzamin.local` → `EGZAMIN\Administrator` → перезагрузка.
2. Войди как `EGZAMIN\anowak` (`Mojedlugiehaslo!`), дождись рабочего стола, `Wyloguj`.
3. На сервере в `C:\Profiles` должна появиться папка `anowak.V6` (суффикс версии добавляет Windows — это нормально).
```powershell
Add-Computer -DomainName egzamin.local -Credential EGZAMIN\Administrator -Restart
```

## Задание 8. Монтаж запасного диска
- ПК выключен, питание отключено, браслет; диск закреплён винтами, подключены SATA data и питание. Подними руку до включения.
- Баллы: диск закреплён стабильно; BHP и порядок.

## Задание 9. Разделы и BitLocker
**Что требуется**
- GPT; раздел 1 ≈ 40 % ёмкости, NTFS, `P:`, метка `Dysk2_1`; раздел 2 — остаток, NTFS, `R:`, `Dysk2_2`.
- BitLocker на R: с паролем `Mojedlugiehaslo!`, ключ восстановления — на USB `Egzamin-x`.

**Как сделать**
1. `diskmgmt.msc` → инициализация `GPT` (если диск MBR и пустой — ПКМ `Konwertuj na dysk GPT`).
2. `Nowy wolumin prosty` → размер = 40 % (например диск 238 475 MB → 95 390 MB), P:, NTFS, `Dysk2_1`; второй — весь остаток, R:, `Dysk2_2`.
3. ПКМ на R: → `Włącz funkcję BitLocker` → `Użyj hasła do odblokowania dysku` → `Zapisz w pliku` → выбери USB `Egzamin-x` → шифровать только использованное место → `Rozpocznij szyfrowanie`.
```powershell
Get-Disk                                         # номер нового диска, здесь 1
Initialize-Disk -Number 1 -PartitionStyle GPT
$size = [math]::Floor((Get-Disk -Number 1).Size * 0.4)
New-Partition -DiskNumber 1 -Size $size -DriveLetter P | Format-Volume -FileSystem NTFS -NewFileSystemLabel "Dysk2_1"
New-Partition -DiskNumber 1 -UseMaximumSize -DriveLetter R | Format-Volume -FileSystem NTFS -NewFileSystemLabel "Dysk2_2"
$pw = ConvertTo-SecureString 'Mojedlugiehaslo!' -AsPlainText -Force
Enable-BitLocker -MountPoint "R:" -PasswordProtector -Password $pw -UsedSpaceOnly
Add-BitLockerKeyProtector -MountPoint "R:" -RecoveryPasswordProtector
(Get-BitLockerVolume R:).KeyProtector | Out-File E:\klucz_odzyskiwania_R.txt   # E: = USB
```

**Как проверить**
- `manage-bde -status R:` — «Ochrona: włączona» / шифрование идёт или завершено; файл ключа на USB.

**За что дают баллы**
- Диск закреплён; GPT; два раздела ~40 %/остаток; NTFS; P: Dysk2_1; R: Dysk2_2; BitLocker на R:; ключ восстановления на USB.

**Частые ошибки**
- Перепутать номер диска и отформатировать системный — всегда сначала `Get-Disk`.
- Сохранить ключ на тот же диск — Windows не даст; нужен USB.
