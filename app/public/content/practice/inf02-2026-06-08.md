# INF.02-08-26.06-SG: патч-корд T568B, CPU-Z, Wi-Fi, домен egzaminXX.local, общая папка и смета услуг

Сценарий: обжимаешь прямой патч-корд, определяешь параметры станции (CPU-Z + средства Windows) для программы обработки графики. Роутер — статический WAN /30, DHCP с резервацией для сервера, Wi-Fi; коммутатор — VLAN 2 и 3. Windows Server: два интерфейса, общий принтер, контроллер домена `egzaminXX.local`, OU, пользователь, папка с правами; станция подключена по Wi-Fi, включён аудит входа, станция в домене. В конце смета услуг. Оценивается 6 результатов: кабель и подключение, идентификация, сетевые устройства, сервер, станция, смета + ход монтажа.

> XX — номер стенда двумя цифрами (стенд 4 → `egzamin04.local`, `EGZAMIN_04`, `printer_04`, `STACJA04`). X в IP — просто номер (`192.168.0.4`).

## Порядок работы (план на 150 минут)
1. Патч-корд + тест (0–15 мин).
2. Идентификация с CPU-Z, скриншоты (15–30).
3. Подключение по схеме, роутер с Wi-Fi (30–50), коммутатор (50–60).
4. Сервер: интерфейсы, принтер + общий доступ (60–75).
5. Промоция DC (75–90), OU/пользователь/папка (90–105).
6. Станция: Wi-Fi, DNS, имя, аудит, домен, вход jnowak (105–125).
7. Проверка связи (125–130), смета (130–145), резерв.

## Задание 1. Прямой патч-корд
**Что требуется**
- Прямой кабель U/UTP, оба конца по **T568B**, подходящий тип кабеля (для патч-корда — «linka», многожильный).

**Как сделать**
1. Сними оболочку ~2,5 см, расплети пары, выпрями жилы в порядке T568B: бело-оранжевый, оранжевый, бело-зелёный, синий, бело-синий, зелёный, бело-коричневый, коричневый.
2. Обрежь ровно ~12–13 мм, вставь в разъём 8P8C до упора, оболочка должна заходить под фиксатор.
3. Обожми клещами, повтори на другом конце. Подними руку, протестируй тестером при экзаменаторе.

**За что дают баллы**
- Оба конца по T568B; фиксатор зажимает внешнюю оболочку; кабель «linka»; тест OK; устройства по схеме; BHP и порядок.

**Частые ошибки**
- Оболочка не доходит до фиксатора — отдельный критерий.
- Взять «drut» вместо «linka».

## Задание 2. Идентификация (CPU-Z + Windows)
**Что требуется**
- Таблица 4: материнская плата (производитель и модель, количество слотов RAM, объём RAM), диск (производитель, ёмкость, свободное место на системном диске), видеокарта (производитель, память GPU).
- Скриншоты в `Identyfikacja` на USB `Egzamin-x`; хотя бы один параметр — через CPU-Z.
- Оценка: 20 GB свободно, RAM ≥ 8 GB, видеопамять ≥ 2 GB.

**Как сделать**
1. Установи CPU-Z с носителя. Вкладка `Mainboard` — Manufacturer, Model; `Memory` — Size; `SPD` — список `Slot #1…#4` (количество слотов); `Graphics` — Name/Vendor, Memory Size.
2. Диск: `diskmgmt.msc` (модель/ёмкость) или `Menedżer urządzeń → Stacje dysków`; свободное место — `Ten komputer → C:`.
```powershell
Get-CimInstance Win32_BaseBoard | Select Manufacturer, Product
(Get-CimInstance Win32_PhysicalMemoryArray).MemoryDevices   # количество слотов
Get-PhysicalDisk | Select FriendlyName, Size
Get-PSDrive C
```
3. Оценка, например: «Stacja spełnia wymagania: wolne 180 GB ≥ 20 GB, RAM 16 GB ≥ 8 GB, VRAM 4 GB ≥ 2 GB».

**За что дают баллы**
- Три группы параметров совпадают со скриншотами; оценка соответствует фактическому состоянию; использован CPU-Z.

**Частые ошибки**
- Записать общую ёмкость вместо свободного места.

## Задание 3. Роутер
**Что требуется**
- WAN: `87.105.190.109/30` (маска `255.255.255.252`), шлюз `87.105.190.110`, DNS `8.8.8.8`, `8.8.4.4`.
- LAN: `172.20.250.1/24`.
- DHCP: `172.20.250.100 ÷ 172.20.250.200`, резервация `172.20.250.150` для интерфейса сервера на порту 1 коммутатора (LAN1).
- Wi-Fi: SSID `EGZAMIN_XX`, WPA2-PSK, ключ `egzaminXX`, AES/CCMP, 2,4 GHz, канал = номер стенда.
- Отдельная точка доступа: свободный адрес из 172.20.250.0/24, шлюз `172.20.250.1`, режим Access Point.

**Как сделать**
1. `Network → WAN`: Static IP. `Network → LAN`: `172.20.250.1`/`255.255.255.0`, перезайти.
2. `DHCP Settings`: Enable, пул.
3. `DHCP → Address Reservation`: MAC LAN1 сервера (`getmac /v`), `172.20.250.150`.
4. `Wireless → Basic`: SSID, канал, 2,4 GHz; `Wireless Security`: WPA2-PSK, AES, пароль `egzaminXX`. Подними руку.

**За что дают баллы**
- LAN; WAN (IP, маска .252, шлюз, DNS); пул DHCP; резервация .150; SSID на 2,4 GHz; WPA2-PSK + AES и канал = номер стенда.

**Частые ошибки**
- Канал оставлен «Auto».

## Задание 4. Коммутатор
**Что требуется**
- IP `192.168.0.102/24`, шлюз `192.168.0.X` (LAN2 сервера).
- VLAN 2: порты 2 и 4 untagged; VLAN 3: порты 1 и 3 untagged; на L3 — IP на VLAN 2, управляющий VLAN 2.

**Как сделать**
1. `System → IP Setting`: IP/маска/шлюз.
2. `VLAN → 802.1Q VLAN`: Enable, VLAN 2 (порты 2, 4 Untagged), VLAN 3 (порты 1, 3 Untagged), убрать порты из VLAN 1; PVID 2/4 = 2, 1/3 = 3. Подними руку.

**За что дают баллы**
- IP/шлюз; VLAN 2 с портами 2, 4; VLAN 3 с портами 1, 3.

## Задание 5. Подключение по схеме
- LAN1 сервера ↔ порт 1, роутер LAN ↔ порт 3 (VLAN 3); LAN2 сервера ↔ порт 4, гнездо E-X ↔ порт 2 (VLAN 2) — сверь со схемой листа. Отдельную точку доступа — в LAN роутера.

## Задание 6. Windows Server
**Что требуется**
- `LAN1`: IP по DHCP (получит `172.20.250.150`), DNS localhost; `LAN2`: `192.168.0.X/24`, DNS localhost. Обновить аренду.
- Принтер TCP/IP `192.168.0.200`, RAW, драйвер из `DRUKARKA`, общий доступ `printer_XX`.
- DC: новый лес `egzaminXX.local`, пароль DSRM `egz@INF2` (если потребуется сменить пароль Administrator — `zaq1@WSX`).
- OU `KADRY`, пользователь Janina Nowak, логин `jnowak`, пароль `zaq1@WSX`, без «смены пароля при следующем входе».
- `C:\Projekty`: NTFS только Administrator — Pełna kontrola, jnowak — Modyfikacja, Użytkownicy — Odczyt i wykonywanie; общий ресурс `Projekty_drukarnia`, Wszyscy — Pełna kontrola.

**Как сделать**
1. `ncpa.cpl`: LAN1 — автоматический IP, DNS вручную `127.0.0.1`; LAN2 — статический, DNS `127.0.0.1`. `ipconfig /renew`.
2. Принтер: `Dodaj drukarkę → … adres TCP/IP` → `192.168.0.200`, порт Raw 9100, драйвер `Z dysku…`; на шаге «Udostępnianie drukarki» → nazwa `printer_XX` (или `Właściwości drukarki → Udostępnianie`).
3. `Dodaj role i funkcje → Usługi domenowe w usłudze Active Directory` → `Podnieś poziom… → Dodaj nowy las → egzaminXX.local` → DSRM `egz@INF2` → перезагрузка (предупреждение о динамическом IP можно пропустить — адрес зарезервирован).
4. `Użytkownicy i komputery AD`: OU `KADRY` → `Nowy → Użytkownik` (Janina, Nowak, `jnowak`), сними «Użytkownik musi zmienić hasło przy następnym logowaniu».
5. `C:\Projekty → Właściwości → Zabezpieczenia → Zaawansowane → Wyłącz dziedziczenie → Usuń wszystkie odziedziczone`, затем `Dodaj`: Administrator (Pełna kontrola), jnowak (Modyfikacja), Użytkownicy (Odczyt i wykonywanie).
6. `Udostępnianie → Udostępnianie zaawansowane` → `Projekty_drukarnia` → `Uprawnienia: Wszyscy — Pełna kontrola`.

```powershell
Rename-NetAdapter -Name "Ethernet" -NewName "LAN1"; Rename-NetAdapter -Name "Ethernet 2" -NewName "LAN2"
Set-DnsClientServerAddress -InterfaceAlias "LAN1" -ServerAddresses 127.0.0.1
New-NetIPAddress -InterfaceAlias "LAN2" -IPAddress 192.168.0.X -PrefixLength 24
Set-DnsClientServerAddress -InterfaceAlias "LAN2" -ServerAddresses 127.0.0.1
ipconfig /renew LAN1
Set-Printer -Name "<nazwa drukarki>" -Shared $true -ShareName "printer_XX"
Install-WindowsFeature AD-Domain-Services -IncludeManagementTools
Install-ADDSForest -DomainName "egzaminXX.local" -SafeModeAdministratorPassword (ConvertTo-SecureString 'egz@INF2' -AsPlainText -Force) -InstallDns -Force
# после перезагрузки:
New-ADOrganizationalUnit -Name "KADRY" -Path "DC=egzaminXX,DC=local"
New-ADUser -Name "Janina Nowak" -GivenName Janina -Surname Nowak -SamAccountName jnowak -Path "OU=KADRY,DC=egzaminXX,DC=local" `
  -AccountPassword (ConvertTo-SecureString 'zaq1@WSX' -AsPlainText -Force) -ChangePasswordAtLogon $false -Enabled $true
New-Item C:\Projekty -ItemType Directory
icacls C:\Projekty /inheritance:r /grant:r "Administrator:(OI)(CI)F" "jnowak:(OI)(CI)M" "*S-1-5-32-545:(OI)(CI)RX"
New-SmbShare -Name "Projekty_drukarnia" -Path "C:\Projekty" -FullAccess "Wszyscy"
```

**Как проверить**
- `ipconfig /all`, `Get-Printer | Select Name, ShareName`, `icacls C:\Projekty`, `Get-SmbShareAccess Projekty_drukarnia`.

**За что дают баллы**
- LAN1 = .150 с DNS localhost; LAN2 = 192.168.0.X, DNS localhost; принтер и общий доступ printer_XX; домен egzaminXX.local; OU KADRY с jnowak; ACL C:\Projekty ровно из трёх записей; ресурс с Wszyscy — Pełna kontrola; ping роутера, станции, принтера.

**Частые ошибки**
- Оставить `SYSTEM`, `Twórca-właściciel`, `Administratorzy` в ACL — критерий «tylko dla».
- Указать DNS 172.20.250.1 на LAN1 вместо localhost.

## Задание 7. Windows-станция
**Что требуется**
- Проводной интерфейс выключен; беспроводной: IP автоматически, DNS `172.20.250.150`; подключиться к Wi-Fi, обновить аренду.
- Имя `STACJAXX`; аудит успешных и неудачных входов; присоединить к `egzaminXX.local`; войти как `jnowak`.

**Как сделать**
1. `ncpa.cpl`: проводной → `Wyłącz`; `Wi-Fi → Właściwości → IPv4`: «Uzyskaj adres IP automatycznie», «Użyj następujących adresów serwerów DNS: 172.20.250.150».
2. Подключись к `EGZAMIN_XX` (ключ `egzaminXX`), `ipconfig /renew`.
3. `secpol.msc → Zasady lokalne → Zasady inspekcji → Przeprowadź inspekcję zdarzeń logowania` → Sukces + Niepowodzenie.
4. `sysdm.cpl → Zmień`: имя `STACJAXX`, `Domena: egzaminXX.local` → `EGZAMINXX\Administrator` → перезагрузка.
5. Экран входа: `Inny użytkownik` → `EGZAMINXX\jnowak`, `zaq1@WSX`.
```powershell
Disable-NetAdapter -Name "Ethernet" -Confirm:$false
Set-DnsClientServerAddress -InterfaceAlias "Wi-Fi" -ServerAddresses 172.20.250.150
auditpol /set /subcategory:"{0CCE9215-69AE-11D9-BED3-505054503030}" /success:enable /failure:enable
Enable-NetFirewallRule -Name FPS-ICMP4-ERQ-In
Add-Computer -DomainName egzaminXX.local -NewName STACJAXX -Credential EGZAMINXX\Administrator -Restart
```

**За что дают баллы**
- Проводной выключен; Wi-Fi адрес из пула; DNS .150; имя STACJAXX; аудит входа; станция в домене; вход как jnowak.

**Частые ошибки**
- Без DNS 172.20.250.150 станция не найдёт домен.
- Брандмауэр станции блокирует ping с сервера — правило ICMPv4.
