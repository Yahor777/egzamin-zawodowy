# INF.02-01-26.01-SG: замена RAM, диагностика, Linux DHCP и скрипт создания пользователей

Сценарий: на рабочей станции меняешь планку RAM и проводишь диагностику (оценка, подойдёт ли эмулятор Android), обжимаешь прямой патч-корд T568B, настраиваешь роутер (статический WAN, DHCP выключен) и коммутатор. Главная часть — Linux-сервер с двумя интерфейсами, сервером `isc-dhcp-server` и скриптом `konta.sh`, создающим 5 пользователей в цикле. Windows-клиент получает адрес по DHCP от Linux, плюс WSL, квоты, GPO на обои и индикатор текстового курсора.

## Порядок работы (план на 150 минут)

1. 0–15 мин — замена RAM (Задание 1), поднять руку; затем собрать ПК и включить.
2. 15–30 мин — диагностика и скриншоты, заполнить таблицу 2 (Задание 2).
3. 30–45 мин — кабель T568B + тест при экзаменаторе (Задание 3).
4. 45–65 мин — роутер и коммутатор, подключение по схеме (Задания 4–6).
5. 65–95 мин — Linux: netplan, DHCP, скрипт (Задания 7–8).
6. 95–125 мин — Windows-клиент (Задание 9).
7. 125–150 мин — тесты ping (Задание 10), проверка таблиц, запас.

## Задание 1. Замена оперативной памяти

**Что требуется**
- Демонтировать установленный модуль RAM, установить запасной модуль со стенда.
- После установки — поднять руку для оценки, только потом собирать и включать.

**Как сделать**
1. Выключи компьютер, **вытащи кабель питания** из блока питания, надень антистатический браслет.
2. Сними боковую крышку, отведи защёлки слота DIMM, вынь модуль.
3. Совмести вырез запасного модуля с ключом слота и вдави до щелчка защёлок.
4. Подними руку. После оценки закрой корпус, подключи питание, загрузи Windows.

**Как проверить** — в `Menedżer zadań → Wydajność → Pamięć` виден новый объём.

**За что дают баллы** — модуль снят; запасной установлен без повреждения платы; в процессе оценивают: работа при отключённом питании, браслет, порядок на столе.

**Частые ошибки**
- Работа без браслета или с подключённым кабелем питания — минус баллы «Przebieg».

## Задание 2. Диагностика рабочей станции

**Что требуется**
- Заполнить таблицу 2: ОС (название и тип/разрядность), процессор (название, частота), производитель видеокарты, виртуализация (TAK/NIE), объём и тип RAM, тип и ёмкость диска.
- Скриншоты сохранить в папку `Wymagania` на флешке `Egzamin-x`.
- Сравнить с таблицей 1 (Windows 10+, Core i3–i9/Ryzen, виртуализация włączona, RAM ≥ 8 GB, SSD) и записать вывод в строку «Ocena» с обоснованием.

**Как сделать**
1. `Win+R` → `msinfo32` — «Nazwa systemu operacyjnego», «Typ systemu», «Procesor» (модель и частота).
2. `Menedżer zadań → Wydajność`: **Procesor** → «Wirtualizacja: Włączone/Wyłączone»; **Pamięć** → объём и «Szybkość/Typ» (DDR4 и т.п.); **Dysk 0** → тип (SSD/HDD) и ёмкость; **GPU** → производитель.
3. Альтернатива: `dxdiag` (вкладка «Ekran» — производитель видеокарты).
4. Каждый экран фотографируй `Win+Shift+S` → вставь в Paint → сохрани в `E:\Wymagania\` (создай папку).
5. В «Ocena» пиши конкретно: «NIE — RAM 4 GB < 8 GB, dysk HDD zamiast SSD» или «TAK — wszystkie wymagania spełnione: Windows 11, i5, wirtualizacja włączona, 16 GB, SSD».

```powershell
Get-CimInstance Win32_Processor | Select Name, MaxClockSpeed, VirtualizationFirmwareEnabled
Get-PhysicalDisk | Select FriendlyName, MediaType, Size
```

**Как проверить** — каждое значение таблицы видно хотя бы на одном скриншоте.

**За что дают баллы** — ОС; процессор + частота; видеокарта + RAM; виртуализация + диск; есть вывод; вывод обоснован конкретными параметрами и соответствует действительности.

**Частые ошибки**
- Данные в таблице не совпадают со скриншотами — тогда критерий не засчитывается.
- Вывод без ссылки на параметры («nie spełnia» без объяснения).

## Задание 3. Прямой кабель U/UTP T568B

**Что требуется** — прямой патч-корд U/UTP, оба конца 8P8C по T568B, кабель типа «linka» (многожильный).

**Как сделать**
1. Сними оболочку стриппером ~2–3 см, расплети пары.
2. Порядок T568B: **бело-оранжевый, оранжевый, бело-зелёный, синий, бело-синий, зелёный, бело-коричневый, коричневый**.
3. Подрежь жилы ровно (~1,2 см), вставь до упора так, чтобы оболочка зашла под защёлку, обожми.
4. Повтори на другом конце, подними руку и протестируй тестером при экзаменаторе (1–8 по порядку).

**За что дают баллы** — T568B на обоих концах; оболочка зажата фиксатором; кабель «linka»; положительный тест; все устройства подключены по схеме.

**Частые ошибки** — оболочка не зажата в разъёме; использован одножильный «drut».

## Задание 4. Роутер

**Что требуется**
- WAN: `90.90.0.1/29` (маска `255.255.255.248`), шлюз `90.90.0.2`, DNS `208.67.222.222`, второй `208.67.220.220`.
- LAN: `10.90.0.1/24`. Сервер DHCP: **wyłączony**.

**Как сделать**
1. Подключи ПК к LAN-порту роутера, зайди на адрес по умолчанию из документации (часто `192.168.0.1` / `192.168.1.1`), смени пароль если требуют.
2. `Network → WAN`: тип подключения **Static IP**, введи IP, маску, шлюз, оба DNS → Save.
3. `DHCP → DHCP Settings`: **Disable** → Save (лучше сделать до смены LAN-IP).
4. `Network → LAN`: IP `10.90.0.1`, маска `255.255.255.0` → Save (роутер перезагрузится).

**Как проверить** — страница Status показывает WAN и LAN с нужными значениями. Подними руку.

**За что дают баллы** — WAN (IP, маска /29, шлюз, DNS 208.67.222.222); LAN 10.90.0.1/24; DHCP выключен.

## Задание 7. Linux-сервер: сеть, DHCP, каталог

**Что требуется**
- Интерфейс к роутеру: `90.90.0.3/29`, шлюз `90.90.0.1`, DNS нет.
- Интерфейс к коммутатору: `10.80.0.2/24`, шлюза нет, DNS `10.80.0.2`.
- DHCP на интерфейсе к коммутатору, `authoritative`, подсеть `10.80.0.0/24`, диапазон `10.80.0.10–10.80.0.30`, DNS `10.80.0.2`, домен `egzamin.edu`, шлюз `10.80.0.2`, broadcast `10.80.0.255`, lease 1 ч, max 3 ч.
- Каталог `~/skrypty_admina` с файлом `konta.sh`, права **710**.

**Как сделать**
1. Узнай имена интерфейсов: `ip a` (например `enp0s3` — к роутеру, `enp0s8` — к коммутатору; проверь, какой кабель куда, через `ip link` up/down).
2. Netplan:

```bash
sudo nano /etc/netplan/50-cloud-init.yaml   # имя файла смотри: ls /etc/netplan
```
```yaml
network:
  version: 2
  ethernets:
    enp0s3:
      dhcp4: false
      addresses: [90.90.0.3/29]
      routes:
        - to: default
          via: 90.90.0.1
    enp0s8:
      dhcp4: false
      addresses: [10.80.0.2/24]
      nameservers:
        addresses: [10.80.0.2]
```
```bash
sudo netplan apply
ip a; ip r
```
3. DHCP (если пакета нет: `sudo apt install isc-dhcp-server`):

```bash
sudo nano /etc/default/isc-dhcp-server
# INTERFACESv4="enp0s8"
sudo nano /etc/dhcp/dhcpd.conf
```
```
authoritative;
subnet 10.80.0.0 netmask 255.255.255.0 {
  range 10.80.0.10 10.80.0.30;
  option domain-name-servers 10.80.0.2;
  option domain-name "egzamin.edu";
  option routers 10.80.0.2;
  option broadcast-address 10.80.0.255;
  default-lease-time 3600;
  max-lease-time 10800;
}
```
```bash
sudo dhcpd -t -cf /etc/dhcp/dhcpd.conf     # проверка синтаксиса
sudo systemctl restart isc-dhcp-server
sudo systemctl enable isc-dhcp-server
```
4. Каталог и права:

```bash
mkdir ~/skrypty_admina
cd ~/skrypty_admina
touch konta.sh
chmod 710 konta.sh
```
Запиши в таблицу 3: `chmod 710 konta.sh` (7 = rwx владелец, 1 = только x группа, 0 = остальные).

**Как проверить** — `systemctl status isc-dhcp-server` = active (running); `ls -l` показывает `-rwx--x---`.

**За что дают баллы** — IP обоих интерфейсов; `INTERFACESv4` = интерфейс к коммутатору; authoritative + subnet + range; DNS/домен/шлюз; broadcast + 3600/10800; каталог `skrypty_admina`; ping роутера WAN, коммутатора, станции.

**Частые ошибки**
- Строка `authoritative;` осталась закомментированной (`#authoritative;`).
- Перепутаны интерфейсы — DHCP раздаёт не в ту сеть.
- Ошибка отступов в YAML (только пробелы, без табов).

## Задание 8. Скрипт `konta.sh`

**Что требуется** — 2 параметра: `$1` — базовое имя пользователя, `$2` — базовое имя домашнего каталога; цикл на 5 итераций; `uczen1…uczen5` с каталогами `/home/3TI1…/home/3TI5`. Запустить с `uczen 3TI`, команду записать в таблицу 3.

**Как сделать**
```bash
nano ~/skrypty_admina/konta.sh
```
```bash
#!/bin/bash
for i in 1 2 3 4 5
do
  useradd -m -d /home/$2$i -s /bin/bash $1$i
done
```
```bash
cd ~/skrypty_admina
sudo ./konta.sh uczen 3TI
```
В таблицу 3: `sudo ./konta.sh uczen 3TI` (или `sudo sh konta.sh uczen 3TI`).

**Как проверить**
```bash
tail -5 /etc/passwd     # uczen1 ... /home/3TI1 и т.д.
ls -ld /home/3TI*
```

**За что дают баллы** — есть `useradd`/`adduser` с домашним каталогом; цикл из 5 итераций; `$1`+номер для имён; `$2`+номер для каталогов; 5 учёток реально созданы; скрипт работает и с другими параметрами (экзаменатор проверит).

**Частые ошибки** — без `-m` каталог не создаётся; запуск без `sudo` → `useradd: Permission denied`.

## Задание 9. Windows-клиент

**Что требуется**
- Интерфейс к коммутатору: имя `LAN_S`, IP и всё остальное — автоматически.
- Компонент «Podsystem Windows dla systemu Linux».
- Стандартный пользователь `asystent`; квота 8 GB, предупреждение 7 GB.
- Запрет менять фон рабочего стола; индикатор текстового курсора — зелёный.

**Как сделать**
1. `ncpa.cpl` → ПКМ на адаптере → `Zmień nazwę` → `LAN_S`; `Właściwości → Protokół internetowy w wersji 4 → Uzyskaj adres IP automatycznie` и `Uzyskaj adres serwera DNS automatycznie`.
2. `Panel sterowania → Programy → Włącz lub wyłącz funkcje systemu Windows` → отметь **Podsystem Windows dla systemu Linux** → OK (перезагрузка позже).
3. `lusrmgr.msc → Użytkownicy → Nowy użytkownik` → `asystent` (по умолчанию группа Użytkownicy = стандартный).
4. Квоты: `Ten komputer → C: → Właściwości → Przydział → Pokaż ustawienia przydziału` → `Włącz zarządzanie przydziałami` → Zastosuj → `Wpisy przydziałów → Przydział → Nowy wpis przydziału` → `asystent` → «Ogranicz miejsce na dysku do» 8 GB, «Ustaw poziom ostrzeżeń na» 7 GB.
5. `gpedit.msc → Konfiguracja użytkownika → Szablony administracyjne → Panel sterowania → Personalizacja` → политика запрета смены фона рабочего стола (Prevent changing desktop background) → **Włączone**.
6. `Ustawienia → Ułatwienia dostępu (Dostępność) → Kursor tekstu → Wskaźnik kursora tekstu` → Włączony, выбери зелёный цвет.

```powershell
Rename-NetAdapter -Name "Ethernet" -NewName "LAN_S"
Set-NetIPInterface -InterfaceAlias "LAN_S" -Dhcp Enabled
Set-DnsClientServerAddress -InterfaceAlias "LAN_S" -ResetServerAddresses
Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Windows-Subsystem-Linux -NoRestart
New-LocalUser -Name "asystent" -NoPassword
Add-LocalGroupMember -Group "Użytkownicy" -Member "asystent"
gpupdate /force
```

**Как проверить** — `ipconfig /all`: адрес из 10.80.0.10–30, суффикс `egzamin.edu`.

**За что дают баллы** — имя LAN_S; адрес по DHCP из диапазона; WSL включён; пользователь стандартный; квота 8/7 GB; запрет обоев (gpedit); зелёный индикатор курсора.

**Частые ошибки** — квоту поставили на «Domyślne» для всех, а не отдельной записью для `asystent`.

## Задание 10. Тест связи

На сервере:
```bash
ping -c 4 90.90.0.1     # WAN роутера
ping -c 4 10.80.0.3     # коммутатор
ping -c 4 10.80.0.10    # станция (адрес смотри в ipconfig)
```
Если станция не отвечает — разреши ICMP на Windows:
```powershell
Enable-NetFirewallRule -Name FPS-ICMP4-ERQ-In
```
(GUI: `Zapora Windows Defender → Ustawienia zaawansowane → Reguły przychodzące → Udostępnianie plików i drukarek (Żądanie echa — ICMPv4 — ruch przychodzący)` → Włącz regułę.) На станции оставь открытым `ipconfig`. Подними руку и повтори при экзаменаторе.
