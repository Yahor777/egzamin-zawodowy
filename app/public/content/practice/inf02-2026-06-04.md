# INF.02-04-26.06-SG: замена сетевой карты, Wi-Fi с резервацией, VLAN 201/202 и Samba на Linux-сервере

Сценарий: монтируешь линию патч-панель ↔ Keystone (T568B), определяешь параметры встроенной и запасной сетевой карты в Windows и меняешь карту. Настраиваешь роутер (DHCP с DNS 10.0.0.3, резервация, Wi-Fi), коммутатор с двумя VLAN, Linux-сервер (сеть, DNS, Samba) и Windows-станцию по Wi-Fi с подключёнными дисками M: и P:. Оценивается 5 результатов: кабели и подключение, сетевые устройства, сетевые интерфейсы, сервер и станция, модернизация станции + ход работ.

## Порядок работы (план на 150 минут)
1. Монтаж кабеля + тест (0–20 мин).
2. Идентификация карты 1, замена, идентификация карты 2 (20–40).
3. Подключение по схеме (40–45).
4. Роутер: LAN, DHCP, Wi-Fi (45–60); резервацию — после того как узнаешь MAC Wi-Fi станции.
5. Коммутатор: VLAN 201/202 (60–70).
6. Linux-сервер: сеть, имя, пользователь, /dane, DNS, Samba (70–105).
7. Windows-станция: имя, суффикс, Wi-Fi, брандмауэр, пользователь, диски (105–130).
8. Проверка связи с экзаменатором, резерв (130–150).

## Задание 1. Монтаж кабельной линии
**Что требуется**
- U/UTP в патч-панель по **T568B**, второй конец — в Keystone по **T568B**; розетка с одним модулем; кабель «drut»; панель в стойке RACK.

**Как сделать**
1. T568B: бело-оранжевый, оранжевый, бело-зелёный, синий, бело-синий, зелёный, бело-коричневый, коричневый.
2. Оболочку снимать ≤ 25 мм от контактов, пары раскручивать ≤ 13 мм; заделка ударным инструментом.
3. Собери розетку, закрепи панель лицом наружу, подними руку и протестируй тестером.

**За что дают баллы**
- Порядок B на обоих концах, допуски 25/13 мм, собранная розетка, кабель «drut», панель стабильно, тест успешен, подключение по схеме; BHP и порядок.

**Частые ошибки**
- Кабель «linka»; не собранная до конца розетка.

## Задание 2. Сетевые карты: идентификация и замена
**Что требуется**
- Для установленной проводной карты: производитель, модель, MAC → таблица 2, скриншоты в `Karta1` на USB `Egzamin-x`.
- Снять карту (встроенную — отключить в BIOS или `Menedżer urządzeń`), установить запасную, поднять руку.
- Те же параметры для запасной карты, скриншоты в `Karta2`.

**Как сделать**
1. `Menedżer urządzeń → Karty sieciowe → Właściwości`: вкладка `Ogólne` (Producent), `Szczegóły → Adres MAC`/`Opis urządzenia`.
2. Или в терминале:
```powershell
Get-NetAdapter | Format-List Name, InterfaceDescription, MacAddress, DriverProvider
ipconfig /all
getmac /v
```
3. Скриншот: `Win+Shift+S` или `PrtSc` → Paint → сохранить в `E:\Karta1` (буква USB своя).
4. Встроенную карту: ПКМ → `Wyłącz urządzenie` (или в BIOS `Onboard LAN → Disabled`).
5. Выключи ПК, вставь запасную карту PCIe в слот, прикрути планку винтом; подними руку; включи, установи драйвер при необходимости, повтори шаги 1–3 для `Karta2`.

**За что дают баллы**
- По 3 параметра для каждой карты, совпадающих со скриншотами; карта закреплена, плата не повреждена; BHP.

**Частые ошибки**
- Записать MAC Wi-Fi-адаптера вместо проводного.
- Не закрепить планку винтом.

## Задание 3. Роутер
**Что требуется**
- WAN: автоматически (DHCP). LAN: `10.0.0.1/24`.
- DHCP: пул `10.0.0.101 ÷ 10.0.0.200`, DNS `10.0.0.3`, резервация MAC Wi-Fi-карты станции → `10.0.0.110`.
- Wi-Fi: SSID `egzamin_x`, WPA2-PSK, ключ `x_egzamin`, AES/CCMP, 2,4 GHz, канал = номер стенда.
- Если точка доступа отдельная: IP `10.0.0.4/24`, Wi-Fi настраивается на ней.

**Как сделать**
1. `Network → WAN`: `Dynamic IP`. `Network → LAN`: `10.0.0.1`/`255.255.255.0`.
2. `DHCP Settings`: Start `10.0.0.101`, End `10.0.0.200`, Primary DNS `10.0.0.3`.
3. `Wireless → Basic Settings`: SSID `egzamin_5` (пример для стенда 5), Region, Channel `5`, Mode b/g/n, 2,4 GHz; `Wireless Security`: WPA2-PSK (Personal), Encryption AES, Password `5_egzamin`.
4. MAC Wi-Fi станции: `ipconfig /all` → адаптер «Wi-Fi», «Adres fizyczny». `DHCP → Address Reservation` → `10.0.0.110`. Подними руку.

**Как проверить**
- Станция подключается к `egzamin_x` и получает `10.0.0.110`.

**За что дают баллы**
- WAN авто; LAN 10.0.0.1/24; пул .101–.200; DNS 10.0.0.3; резервация .110 на MAC Wi-Fi; SSID egzamin_x, WPA2-PSK + AES.

**Частые ошибки**
- Ключ короче 8 символов не примут — `x_egzamin` всегда ≥ 9, всё ок.
- Резервация на MAC проводной карты.

## Задание 4. Коммутатор
**Что требуется**
- IP `10.0.0.2/24`, шлюз `10.0.0.1`; 802.1Q включён.
- VLAN 201: порты 1 и 4 untagged; VLAN 202: порты 2 и 3 untagged; на L3 IP на VLAN 201, управляющий VLAN 201.

**Как сделать**
1. `System → IP Setting`: `10.0.0.2`, `255.255.255.0`, шлюз `10.0.0.1`.
2. `VLAN → 802.1Q VLAN`: Enable; VLAN 201 → порты 1, 4 Untagged; VLAN 202 → порты 2, 3 Untagged; убрать порты 1–4 из VLAN 1.
3. PVID: порты 1, 4 = 201; порты 2, 3 = 202. Management VLAN = 201. Подними руку.

**За что дают баллы**
- Созданы VLAN 201/202; правильные порты untagged; IP 10.0.0.2/24, шлюз 10.0.0.1.

**Частые ошибки**
- Управлять коммутатором с порта VLAN 202 — после смены PVID доступа не будет.

## Задание 5. Подключение по схеме
**Что требуется**
- Соединить устройства по схеме и включить питание; гнездо `E-X` даёт доступ к принтеру 192.168.0.200.

**Как сделать**
1. Порт 1 коммутатора ↔ первый интерфейс сервера (V201), порт 2 ↔ второй интерфейс сервера (V202), порт 3 ↔ гнездо E-X, порт 4 ↔ LAN роутера (сверь со схемой листа). Отдельную точку доступа — в любой LAN-порт роутера.

**За что дают баллы**
- Соответствие схеме (результат 1).

## Задание 6. Сетевые интерфейсы станции и сервера
**Что требуется**
- Станция (Windows): имя `stacja-x`, основной DNS-суффикс `egzamin.internal`; Wi-Fi к `egzamin_x`, IP автоматически, обновить аренду; брандмауэр включён, правило на ответ на эхо ICMP; проводной интерфейс выключен.
- Сервер (Linux): `V201` — `10.0.0.3/24`, шлюз `10.0.0.1`, DNS localhost; `V202` — `192.168.0.X/24`, DNS localhost. Ping станции, роутера, коммутатора, принтера.

**Как сделать (станция)**
1. `Ustawienia → System → Informacje → Zmień nazwę tego komputera` или `sysdm.cpl → Zmień → Więcej… → Podstawowy sufiks DNS tego komputera: egzamin.internal`, имя `stacja-x`, перезагрузка.
2. Подключись к Wi-Fi `egzamin_x`, затем `ipconfig /release` и `ipconfig /renew`.
3. Проводной адаптер: `ncpa.cpl → Wyłącz`.
```powershell
Rename-Computer -NewName "stacja-x"
Set-ItemProperty "HKLM:\SYSTEM\CurrentControlSet\Services\Tcpip\Parameters" -Name "NV Domain" -Value "egzamin.internal"
Set-NetFirewallProfile -All -Enabled True
New-NetFirewallRule -DisplayName "ICMP echo" -Protocol ICMPv4 -IcmpType 8 -Direction Inbound -Action Allow
Restart-Computer
```

**Как сделать (сервер Ubuntu)**
1. Узнай MAC обоих интерфейсов: `ip link`. Определи, какой подключён к порту 1 (отключай кабели по одному и смотри `state DOWN`).
2. Файл `/etc/netplan/50-cloud-init.yaml` (или существующий в каталоге):
```yaml
network:
  version: 2
  ethernets:
    V201:
      match:
        macaddress: "aa:bb:cc:dd:ee:01"
      set-name: V201
      addresses: [10.0.0.3/24]
      routes:
        - to: default
          via: 10.0.0.1
      nameservers:
        addresses: [127.0.0.1]
    V202:
      match:
        macaddress: "aa:bb:cc:dd:ee:02"
      set-name: V202
      addresses: [192.168.0.X/24]
      nameservers:
        addresses: [127.0.0.1]
```
```bash
sudo chmod 600 /etc/netplan/*.yaml
sudo netplan apply        # если имена не сменились — sudo reboot
ip a
ping -c 4 10.0.0.110      # станция
ping -c 4 10.0.0.1; ping -c 4 10.0.0.2; ping -c 4 192.168.0.200
```

**За что дают баллы**
- Имя stacja-x и суффикс; Wi-Fi подключён, адрес 10.0.0.110; правило ICMP; сервер 10.0.0.3/24, шлюз 10.0.0.1, DNS localhost; 192.168.0.X/24 с DNS localhost; ping станции, роутера, коммутатора, принтера при экзаменаторе.

**Частые ошибки**
- Перепутать интерфейсы сервера (порт 1 ↔ V201).
- Пробелы/табуляция в YAML: только пробелы.

## Задание 7. Linux-сервер: имя, пользователь, DNS, Samba
**Что требуется**
- Имя `serwer-x`.
- Пользователь `jkowalski` с домашним каталогом, пароль `XSW@3edc`, описание `Jan Kowalski`.
- `/dane` — полные права только для jkowalski.
- DNS-служба и Samba: автозапуск и запущены.
- Samba: пользователь jkowalski (`XSW@3edc`); домашние каталоги (каждый видит только свой); ресурс `dane` (= /dane) — чтение/запись только jkowalski.

**Как сделать**
```bash
sudo hostnamectl set-hostname serwer-x
sudo sed -i 's/^127.0.1.1.*/127.0.1.1 serwer-x/' /etc/hosts
sudo useradd -m -c "Jan Kowalski" -s /bin/bash jkowalski
sudo passwd jkowalski                     # XSW@3edc
sudo mkdir /dane
sudo chown jkowalski:jkowalski /dane
sudo chmod 700 /dane
sudo apt install -y bind9 samba           # если не установлены
sudo systemctl enable --now named         # служба DNS (bind9) в Ubuntu 24.04
sudo systemctl enable --now smbd
sudo smbpasswd -a jkowalski               # XSW@3edc
sudo nano /etc/samba/smb.conf
```
В конце `/etc/samba/smb.conf`:
```ini
[homes]
   comment = Katalogi domowe
   browseable = no
   read only = no
   valid users = %S
   create mask = 0700
   directory mask = 0700

[dane]
   path = /dane
   valid users = jkowalski
   read only = no
```
```bash
testparm
sudo systemctl restart smbd
```

**Как проверить**
```bash
hostnamectl; id jkowalski; ls -ld /dane
systemctl is-enabled named smbd; systemctl is-active named smbd
sudo pdbedit -L                     # jkowalski в базе Samba
smbclient -L localhost -U jkowalski
```

**За что дают баллы**
- Имя serwer-x; пользователь с домашним каталогом; права /dane только для jkowalski; DNS и Samba enabled+active; пользователь Samba; [homes] с доступом только к своему; [dane] только для jkowalski.

**Частые ошибки**
- Забыть `smbpasswd -a` — системный пароль Samba не использует.
- В секции `[homes]` указать `path` — не нужно, Samba подставит домашний каталог.

## Задание 8. Windows-станция: пользователь и диски
**Что требуется**
- Локальный пользователь `jkowalski`, пароль `XSW@3edc`, полное имя `Jan Kowalski`.
- Войти как jkowalski и постоянно подключить: домашний каталог → `M:`, ресурс `dane` → `P:`.

**Как сделать**
```powershell
New-LocalUser -Name "jkowalski" -FullName "Jan Kowalski" -Password (ConvertTo-SecureString 'XSW@3edc' -AsPlainText -Force)
Add-LocalGroupMember -Group "Użytkownicy" -Member "jkowalski"
```
Выйди и войди как jkowalski, затем в `cmd`:
```powershell
net use M: \\10.0.0.3\jkowalski /persistent:yes
net use P: \\10.0.0.3\dane /persistent:yes
```
(или `Ten komputer → Mapuj dysk sieciowy`, галка `Połącz ponownie przy logowaniu`). Логин и пароль совпадают с Samba, поэтому вход пройдёт без запроса.

**Как проверить**
- `net use` показывает M: и P: со статусом OK; в P: можно создать файл.

**За что дают баллы**
- Пользователь jkowalski на станции; M: и P: подключены постоянно для него.

**Частые ошибки**
- Подключать диски под Administrator — критерий проверяется у jkowalski.
