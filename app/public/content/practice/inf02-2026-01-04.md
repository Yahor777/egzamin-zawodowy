# INF.02-04-26.01-SG: замена сетевой карты, CPU-Z, домен AD с GPO и пакетный файл

Сценарий: на рабочей станции меняешь (или отключаешь встроенную) сетевую карту и ставишь запасную, снимаешь параметры CPU-Z. Роутер получает статический WAN, DHCP на нём выключен, коммутатор — статический IP. Windows Server с двумя интерфейсами повышается до контроллера домена `firmaXX.local`, создаётся GPO `Polityka` с политикой паролей, OU `BIURO` с двумя пользователями. Linux-станция: сеть через NetworkManager, имя хоста, MAC, каталог с правами, обои. Плюс пакетный файл `powitanie.bat`.

## Порядок работы (план на 150 минут)

1. 0–15 мин — замена сетевой карты (Задание 1).
2. 15–30 мин — CPU-Z, скриншоты, таблица 1 (Задание 2).
3. 30–50 мин — роутер, коммутатор, кабели (Задания 3–5).
4. 50–70 мин — интерфейсы сервера, запуск повышения до DC (идёт перезагрузка — в это время делай Linux).
5. 70–95 мин — Linux-станция (Задание 6).
6. 95–125 мин — GPO, OU, пользователи (Задание 7), `powitanie.bat` (Задание 8).
7. 125–150 мин — пинги (Задание 9), проверка.

## Задание 1. Замена сетевой карты

**Что требуется** — снять установленную проводную сетевую карту; если она встроенная — отключить в BIOS или в Menedżer urządzeń; установить запасную карту со стенда. Поднять руку до запуска системы.

**Как сделать**
1. Выключи ПК, **выдерни кабель питания**, надень браслет.
2. Если карта PCIe — открути винт планки, вынь карту. Если встроенная — её отключишь позже (шаг 4).
3. Вставь запасную карту в свободный слот PCIe/PCI, прикрути винтом к корпусу (монтаж должен быть «trwały»).
4. Подними руку. После оценки запусти ПК; встроенную карту отключи: BIOS (`Onboard LAN Controller → Disabled`) или `devmgmt.msc → Karty sieciowe → ПКМ → Wyłącz urządzenie`.

**За что дают баллы** — карта снята/отключена; новая закреплена, система стартует; устройства подключены по схеме; в процессе — питание отключено, браслет, порядок.

**Частые ошибки** — карта не прикручена винтом.

## Задание 2. CPU-Z и параметры

**Что требуется** — установить CPU-Z с носителя DOKUMENTACJA/PROGRAMY; в таблицу 1: производитель и модель материнской платы, число ядер, тип сокета, базовая частота, техпроцесс, мгновенная загрузка CPU в %. Скриншоты — папка `PARAMETRY` на флешке `Egzamin-x`.

**Как сделать**
1. Запусти установщик CPU-Z, затем программу.
2. Вкладка **CPU**: `Cores` (ядра), `Package` (сокет, напр. Socket 1700 LGA), `Technology` (напр. 10 nm), `Specification` (базовая частота в названии, напр. @ 3.60GHz).
3. Вкладка **Mainboard**: `Manufacturer`, `Model`.
4. Загрузка: `Menedżer zadań → Wydajność → Procesor → Wykorzystanie` (скриншот в тот же момент).
5. Скриншоты всех окон (на одном обязательно видно окно CPU-Z) → `E:\PARAMETRY\`.

**За что дают баллы** — CPU-Z установлен (скриншот); плата; ядра + сокет; частота + техпроцесс; загрузка в %.

**Частые ошибки** — вместо базовой частоты записали текущую `Core Speed`.

## Задание 6. Linux-станция

**Что требуется**
- Соединение `LAN K`: `10.0.10.11/24`, шлюз и DNS `10.0.10.1`.
- Имя компьютера `stanowiskoXX` (место 5 → `stanowisko05`).
- Командой узнать MAC, записать MAC и команду в таблицу 3.
- `~/ELEKTRONIKA`: владелец — полные, группа — чтение, остальные — выполнение (**741**).
- Обои — `water.jpg` из `PLIKI`.

**Как сделать**
```bash
nmcli device                                   # имя карты, напр. enp0s3
sudo nmcli con add type ethernet ifname enp0s3 con-name "LAN K" \
  ipv4.method manual ipv4.addresses 10.0.10.11/24 \
  ipv4.gateway 10.0.10.1 ipv4.dns 10.0.10.1
sudo nmcli con up "LAN K"
sudo hostnamectl set-hostname stanowisko05
ip link show enp0s3                            # MAC после link/ether
mkdir ~/ELEKTRONIKA
chmod 741 ~/ELEKTRONIKA
cp /media/administrator/*/PLIKI/water.jpg ~/    # путь к флешке смотри в lsblk
gsettings set org.gnome.desktop.background picture-uri "file:///home/administrator/water.jpg"
gsettings set org.gnome.desktop.background picture-uri-dark "file:///home/administrator/water.jpg"
```
GUI-вариант обоев: ПКМ на файле `water.jpg` → `Ustaw jako tapetę`.
В таблицу 3: MAC (напр. `08:00:27:ab:cd:ef`) и команду `ip link show`.

**Как проверить** — `ip a`, `ip r`, `resolvectl status`, `hostnamectl`, `ls -ld ~/ELEKTRONIKA` → `drwxr----x`.

**За что дают баллы** — имя «LAN K» + IP/шлюз/DNS; имя хоста; MAC и команда, MAC совпадает; каталог; права 741; обои.

**Частые ошибки** — MAC записан от старой (отключённой) карты; на Ubuntu с тёмной темой меняется только `picture-uri-dark`.

## Задание 7. Windows Server: сеть, домен, GPO, пользователи

**Что требуется**
- `LAN Z` (к роутеру): `172.16.10.1/24`, шлюз `172.16.10.10`, DNS localhost.
- `LAN W` (к коммутатору): `10.0.10.1/24`, без шлюза, DNS localhost.
- Новый лес, домен `firmaXX.local`, пароль DSRM `ZAQ!2wsx`; если требуют сменить пароль Administratora — `zaq1@WSX`.
- GPO `Polityka` для всего домена: сложные пароли — включено, минимальная длина 8; `gpupdate`.
- OU `BIURO`, пользователи: Krystyna Nowak / `sekretarka`, Jan Kowalski / `elektronik`; пароли по политике — записать в таблицу 2.

**Как сделать**
1. `ncpa.cpl` → переименуй адаптеры в `LAN Z` и `LAN W`, задай IPv4 (DNS `127.0.0.1`).
2. `Menedżer serwera → Zarządzaj → Dodaj role i funkcje → Usługi domenowe w usłudze Active Directory` → Zainstaluj → флажок уведомлений → `Promuj ten serwer do roli kontrolera domeny` → `Dodaj nowy las` → `firma05.local` → пароль DSRM `ZAQ!2wsx` → Dalej… → Zainstaluj (перезагрузка).
3. `Narzędzia → Zarządzanie zasadami grupy → Las → Domeny → firma05.local` → ПКМ `Utwórz obiekt GPO w tej domenie i umieść tu link…` → `Polityka` → ПКМ `Edytuj` → `Konfiguracja komputera → Zasady → Ustawienia systemu Windows → Ustawienia zabezpieczeń → Zasady konta → Zasady haseł`: `Hasło musi spełniać wymagania co do złożoności` = Włączone, `Minimalna długość hasła` = 8.
4. На вкладке `Połączone obiekty zasad grupy` домена передвинь `Polityka` на **kolejność łączy 1** (выше Default Domain Policy), затем `gpupdate /force`.
5. `Narzędzia → Użytkownicy i komputery usługi Active Directory` → ПКМ на домене `Nowy → Jednostka organizacyjna` → `BIURO` → в ней `Nowy → Użytkownik`: имя/фамилия, логин; пароль, например `Biuro#2026`, сними «musi zmienić hasło».

```powershell
Rename-NetAdapter -Name "Ethernet" -NewName "LAN Z"
Rename-NetAdapter -Name "Ethernet 2" -NewName "LAN W"
New-NetIPAddress -InterfaceAlias "LAN Z" -IPAddress 172.16.10.1 -PrefixLength 24 -DefaultGateway 172.16.10.10
New-NetIPAddress -InterfaceAlias "LAN W" -IPAddress 10.0.10.1 -PrefixLength 24
Set-DnsClientServerAddress -InterfaceAlias "LAN Z","LAN W" -ServerAddresses 127.0.0.1
Install-WindowsFeature AD-Domain-Services -IncludeManagementTools
Install-ADDSForest -DomainName "firma05.local" -InstallDns `
  -SafeModeAdministratorPassword (ConvertTo-SecureString "ZAQ!2wsx" -AsPlainText -Force)
# после перезагрузки:
New-GPO -Name "Polityka" | New-GPLink -Target "DC=firma05,DC=local" -Order 1
New-ADOrganizationalUnit -Name "BIURO" -Path "DC=firma05,DC=local"
$p = ConvertTo-SecureString "Biuro#2026" -AsPlainText -Force
New-ADUser -Name "Krystyna Nowak" -GivenName Krystyna -Surname Nowak -SamAccountName sekretarka `
  -UserPrincipalName sekretarka@firma05.local -Path "OU=BIURO,DC=firma05,DC=local" -AccountPassword $p -Enabled $true
New-ADUser -Name "Jan Kowalski" -GivenName Jan -Surname Kowalski -SamAccountName elektronik `
  -UserPrincipalName elektronik@firma05.local -Path "OU=BIURO,DC=firma05,DC=local" -AccountPassword $p -Enabled $true
gpupdate /force
```
(Сами параметры паролей в GPO `Polityka` задаются в редакторе, шаг 3.)

**Как проверить** — `Get-ADDomain`; `gpresult /r` (видна Polityka); `Get-ADUser -Filter * -SearchBase "OU=BIURO,DC=firma05,DC=local"`.

**За что дают баллы** — LAN Z; LAN W; AD DS; домен firmaXX.local; OU BIURO с двумя пользователями и паролями ≥8 со сложностью (по таблице 2); GPO Polityka с двумя настройками; пинги роутера, коммутатора, станции.

**Частые ошибки** — настройки паролей сделаны в Default Domain Policy, а не в новой GPO; пароль содержит логин пользователя — сложность не пройдёт.

## Задание 8. `C:\powitanie.bat`

**Что требуется** — скрытие команд, очистка экрана, «Podaj imię: », затем «Witaj xxxxx», окно не закрывается.

```bat
@echo off
chcp 65001 >nul
cls
set /p imie=Podaj imię: 
echo Witaj %imie%
pause
```
Сохрани как `C:\powitanie.bat` (Typ: Wszystkie pliki, кодировка UTF-8). Если польские буквы ломаются — напиши `Podaj imie:` без «ę». Проверь двойным щелчком.

**За что дают баллы** — файл в корне C:; `@echo off`; `cls`; запрос имени (`set /p`); вывод `Witaj %imie%` + `pause`.
