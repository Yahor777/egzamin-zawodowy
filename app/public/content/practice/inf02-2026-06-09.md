# INF.02-09-26.06-SG: подсети /26, сервер-маршрутизатор RRAS, домен egzamin.local и установка 7-Zip через GPO

Сценарий: кабель патч-панель ↔ вилка 8P8C, монтаж панели, органайзера и коммутатора 2 в стойке. Роутер без DHCP, но со статическим маршрутом в подсеть 10.0.0.64/26 через сервер; два коммутатора связаны trunk-ом VLAN 2. Windows Server маршрутизирует между подсетями (RRAS), становится DC `egzamin.local`, публикует 7-Zip.msi и ставит его на станцию через GPO. В конце — добавить RAM и в CPU-Z показать двухканальный режим. Оценивается 5 результатов: кабели и подключение, сетевые устройства, интерфейсы, сервер, модернизация и диагностика + ход работ.

## Порядок работы (план на 150 минут)
1. Кабель, стойка, тест (0–25 мин).
2. Подключение по схеме (25–30).
3. Роутер: WAN, LAN /26, DHCP выкл., маршрут (30–45).
4. Коммутаторы 1 и 2 (45–65).
5. Сервер: LAN1/LAN2, RRAS; станция LAN2; ping (65–80).
6. AD DS, OU, пользователь, папка Programy (80–105).
7. Станция в домен, OU, GPO 7-Zip, проверка (105–130).
8. RAM + CPU-Z (130–145), резерв.

## Задание 1. Кабель и стойка
**Что требуется**
- Кабель U/UTP: один конец в патч-панель по **T568B**, другой — вилка **8P8C** по **T568B**.
- В стойке RACK: патч-панель, органайзер кабелей, коммутатор 2.

**Как сделать**
1. На панели: T568B (бело-оранжевый, оранжевый, бело-зелёный, синий, бело-синий, зелёный, бело-коричневый, коричневый), оболочка ≤ 25 мм, раскрутка ≤ 13 мм, заделка ударным инструментом.
2. Вилка: жилы в том же порядке, обрезать ~12–13 мм, оболочка под фиксатором, обжать.
3. Закрепи панель, органайзер и коммутатор 2 четырьмя винтами каждый. Подними руку, протестируй (вилка в тестер, панель — через патч-корд).

**За что дают баллы**
- T568B на обоих концах; фиксатор на оболочке; допуски на панели; стабильный монтаж панели, органайзера и коммутатора 2; тест OK; подключение по схеме; BHP.

**Частые ошибки**
- Оболочка обрезана слишком коротко — фиксатор держит только жилы.

## Задание 2. Роутер
**Что требуется**
- WAN: `80.80.80.1/30` (маска `255.255.255.252`), шлюз `80.80.80.2`, DNS `8.8.8.8`, `8.8.4.4`.
- LAN: `10.0.0.1/26` (маска `255.255.255.192`); DHCP **выключен**.
- Статический маршрут: сеть `10.0.0.64`, маска `255.255.255.192`, шлюз `10.0.0.4`.

**Как сделать**
1. `Network → WAN` (Static IP), `Network → LAN` (IP + маска 255.255.255.192), перезайди на `http://10.0.0.1` (ПК временно `10.0.0.10/26`).
2. `DHCP → DHCP Settings → Disable`.
3. `Advanced Routing → Static Routing List → Add New`: Destination `10.0.0.64`, Subnet Mask `255.255.255.192`, Gateway `10.0.0.4`, Enabled. Подними руку.

**За что дают баллы**
- WAN (IP, .252, шлюз, DNS); LAN 10.0.0.1/255.255.255.192; DHCP выключен; маршрут 10.0.0.64/26 через 10.0.0.4.

**Частые ошибки**
- Маска /26 введена как /24 — тогда станция из 10.0.0.64/26 «внутри» сети роутера, маршрут не нужен, и ответы уходят мимо сервера.

## Задание 3. Коммутатор 1
**Что требуется**
- IP `10.0.0.2/26` (на L3 — VLAN 2), шлюз `10.0.0.1`; 802.1Q включён.
- VLAN 2: порт 1 untagged, порт 2 tagged (trunk). VLAN 3: порты 3, 4 untagged.

**Как сделать**
1. Сначала `System → IP Setting`: `10.0.0.2`, `255.255.255.192`, шлюз `10.0.0.1`.
2. `VLAN → 802.1Q VLAN`: Enable; VLAN 2 — порт 1 Untagged, порт 2 Tagged; VLAN 3 — порты 3, 4 Untagged; убери порты 1, 3, 4 из VLAN 1.
3. PVID: порт 1 = 2, порты 3–4 = 3. Управляющий VLAN = 2 (подключайся через порт 1).

**За что дают баллы**
- IP/маска/шлюз; VLAN 2 и 3; правильные tagged/untagged порты.

## Задание 4. Коммутатор 2
**Что требуется**
- IP `10.0.0.3/26` (на L3 — VLAN 2), шлюз `10.0.0.1`; VLAN 2: порт 1 untagged, порт 2 tagged.

**Как сделать**
1. Аналогично: IP, затем VLAN 2 (порт 1 Untagged, порт 2 Tagged), PVID порта 1 = 2, management VLAN = 2. Подними руку.

**Частые ошибки**
- Trunk только с одной стороны: порт 2 должен быть Tagged в VLAN 2 на **обоих** коммутаторах.

## Задание 5. Подключение по схеме
- LAN1 сервера ↔ коммутатор 1 порт 1; LAN2 сервера ↔ коммутатор 1 порт 3; станция ↔ коммутатор 1 порт 4; коммутатор 1 порт 2 ↔ коммутатор 2 порт 2; коммутатор 2 порт 1 ↔ LAN роутера (через патч-панель — сверь со схемой листа).

## Задание 6. Интерфейсы сервера и RRAS
**Что требуется**
- `LAN1` (коммутатор 1, порт 1): `10.0.0.4/26`, шлюз `10.0.0.1`, DNS localhost.
- `LAN2` (коммутатор 1, порт 3): `10.0.0.65/26`, без шлюза, DNS localhost.
- Роль `Dostęp zdalny`, служба `Routing`, включён `Routing sieci LAN`.

**Как сделать**
1. `ncpa.cpl`: переименуй, настрой IPv4 (маска `255.255.255.192`, DNS `127.0.0.1`).
2. `Dodaj role i funkcje → Dostęp zdalny → Usługi ról: Routing` (DirectAccess i VPN добавится автоматически).
3. `Narzędzia → Routing i dostęp zdalny` → ПКМ на сервере → `Skonfiguruj i włącz routing i dostęp zdalny` → `Konfiguracja niestandardowa` → `Routing sieci LAN` → `Zakończ` → `Uruchom usługę`.
4. Брандмауэр: включи правило ICMPv4 (ping от станции).
```powershell
Rename-NetAdapter -Name "Ethernet" -NewName "LAN1"; Rename-NetAdapter -Name "Ethernet 2" -NewName "LAN2"
New-NetIPAddress -InterfaceAlias "LAN1" -IPAddress 10.0.0.4 -PrefixLength 26 -DefaultGateway 10.0.0.1
New-NetIPAddress -InterfaceAlias "LAN2" -IPAddress 10.0.0.65 -PrefixLength 26
Set-DnsClientServerAddress -InterfaceAlias "LAN1","LAN2" -ServerAddresses 127.0.0.1
Install-WindowsFeature RemoteAccess, Routing -IncludeManagementTools
Install-RemoteAccess -VpnType RoutingOnly
Enable-NetFirewallRule -Name FPS-ICMP4-ERQ-In
```

**За что дают баллы**
- Имена, IP, шлюз, DNS localhost для LAN1 и LAN2; роль Dostęp zdalny + Routing + Routing LAN.

## Задание 7. Интерфейс станции
**Что требуется**
- `LAN2`: `10.0.0.66/26`, шлюз и DNS `10.0.0.65`.

**Как сделать**
```powershell
Rename-NetAdapter -Name "Ethernet" -NewName "LAN2"
New-NetIPAddress -InterfaceAlias "LAN2" -IPAddress 10.0.0.66 -PrefixLength 26 -DefaultGateway 10.0.0.65
Set-DnsClientServerAddress -InterfaceAlias "LAN2" -ServerAddresses 10.0.0.65
```

**За что дают баллы**
- Имя LAN2, адрес, шлюз и DNS 10.0.0.65.

## Задание 8. Проверка связи со станции
```powershell
ping 10.0.0.65      # сервер (LAN2)
ping 10.0.0.4       # сервер (LAN1) — через маршрутизацию
ping 10.0.0.1       # LAN роутера — нужен RRAS + статический маршрут на роутере
tracert 10.0.0.1    # первый хоп 10.0.0.65
```
Подними руку, повтори при экзаменаторе.

**Частые ошибки**
- Роутер не отвечает: проверь маршрут на роутере и что служба `Routing i dostęp zdalny` запущена.

## Задание 9. Active Directory и GPO
**Что требуется**
- AD DS, новый лес `egzamin.local`, пароль DSRM = пароль Administrator (`ZAQ!2wsx`).
- OU `Pracownicy`, пользователь Jan Kowalski, `jkowalski`, пароль `MojeBezpieczneHaslo!`.
- `C:\Programy` → ресурс `programy`; внутри `7-Zip.msi`; общий доступ только Wszyscy — Pełna kontrola; NTFS только Administratorzy — Pełna kontrola, Wszyscy — Odczyt i wykonywanie.
- OU `Komputery pracowników`; станция в домене и в этой OU.
- GPO `Instalacja 7-Zip` (обязательная установка 7-Zip), связан с OU `Komputery pracowników`; на станции `gpupdate`, вход как jkowalski — 7-Zip доступен.

**Как сделать**
1. `Dodaj role i funkcje → Usługi domenowe w usłudze Active Directory` → `Podnieś poziom… → Dodaj nowy las → egzamin.local` → DSRM `ZAQ!2wsx` → перезагрузка.
2. `Użytkownicy i komputery AD`: OU `Pracownicy` + пользователь; OU `Komputery pracowników`.
3. Папка: создать, скопировать `7-Zip.msi`; `Udostępnianie zaawansowane → programy → Uprawnienia: Wszyscy — Pełna kontrola`; `Zabezpieczenia → Zaawansowane → Wyłącz dziedziczenie → Usuń`, добавить Administratorzy (Pełna kontrola) и Wszyscy (Odczyt i wykonywanie).
4. Станция: `sysdm.cpl → Zmień → Domena: egzamin.local` (`EGZAMIN\Administrator`) → перезагрузка. На сервере перенеси компьютер из `Computers` в `Komputery pracowników`.
5. `Zarządzanie zasadami grupy` → ПКМ на OU `Komputery pracowników → Utwórz obiekt GPO… i połącz go tutaj` → `Instalacja 7-Zip` → `Edytuj` → `Konfiguracja komputera → Zasady → Ustawienia oprogramowania → Instalacja oprogramowania → Nowy → Pakiet` → путь **UNC** `\\<nazwa serwera>\programy\7-Zip.msi` → `Przypisany`.
6. В том же GPO (рекомендуется): `Konfiguracja komputera → Zasady → Szablony administracyjne → System → Logowanie → Zawsze czekaj na sieć podczas uruchamiania komputera i logowania` → Włączone.
7. На станции `gpupdate /force` → перезагрузка (назначенный компьютеру пакет ставится при загрузке) → вход `EGZAMIN\jkowalski` → 7-Zip в меню Start.
```powershell
Install-WindowsFeature AD-Domain-Services -IncludeManagementTools
Install-ADDSForest -DomainName "egzamin.local" -SafeModeAdministratorPassword (ConvertTo-SecureString 'ZAQ!2wsx' -AsPlainText -Force) -InstallDns -Force
New-ADOrganizationalUnit -Name "Pracownicy" -Path "DC=egzamin,DC=local"
New-ADOrganizationalUnit -Name "Komputery pracowników" -Path "DC=egzamin,DC=local"
New-ADUser -Name "Jan Kowalski" -GivenName Jan -Surname Kowalski -SamAccountName jkowalski -Path "OU=Pracownicy,DC=egzamin,DC=local" `
  -AccountPassword (ConvertTo-SecureString 'MojeBezpieczneHaslo!' -AsPlainText -Force) -Enabled $true
New-Item C:\Programy -ItemType Directory; Copy-Item D:\7-Zip.msi C:\Programy\
New-SmbShare -Name "programy" -Path "C:\Programy" -FullAccess "Wszyscy"
icacls C:\Programy /inheritance:r /grant:r "*S-1-5-32-544:(OI)(CI)F" "*S-1-1-0:(OI)(CI)RX"
New-GPO -Name "Instalacja 7-Zip" | New-GPLink -Target "OU=Komputery pracowników,DC=egzamin,DC=local"
Get-ADComputer <STACJA> | Move-ADObject -TargetPath "OU=Komputery pracowników,DC=egzamin,DC=local"
```
(Сам пакет в GPO добавляется только через GUI — шаг 5.)

**Как проверить**
- На станции `gpresult /r /scope computer` — в списке применённых GPO `Instalacja 7-Zip`.

**За что дают баллы**
- RRAS с Routing LAN; домен egzamin.local; OU Pracownicy + jkowalski; ресурс programy; общий доступ только Wszyscy FC; NTFS только Administratorzy FC + Wszyscy RX; OU Komputery pracowników со станцией; GPO с назначенной установкой 7-Zip, связанный с OU; у jkowalski есть 7-Zip.

**Частые ошибки**
- Путь к MSI вида `C:\Programy\7-Zip.msi` — станция его не найдёт, нужен UNC.
- Привязать GPO к OU пользователей вместо OU компьютеров.
