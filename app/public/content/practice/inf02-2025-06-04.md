# INF.02-04-25.06-SG: Wi-Fi WPA2, домен с GPO блокировки, общий принтер и смета в Excel

Сценарий: роутер раздаёт Wi-Fi `EGZAMIN_XX` (WPA2-AES, 2,4 GHz, канал = номер места), коммутатор получает VLAN 13. Windows Server: статический IP, сетевой принтер RAW с общим доступом, контроллер домена `zsXX.local`, OU `TECHNIKUM` с группой и пользователем, перемещаемый профиль, GPO `bezpieczna_szkola` (пароль и блокировка учётки). Станция подключается по Wi-Fi, входит в домен под `knowak` и печатает тестовую страницу. В конце — смета с НДС и скидкой в электронной таблице.

## Порядок работы (план на 150 минут)

1. 0–15 мин — патч-корд + тест (Задание 1).
2. 15–25 мин — параметры Wi-Fi-карты (Задание 2).
3. 25–50 мин — роутер/Wi-Fi, коммутатор, подключение (Задания 3–5).
4. 50–100 мин — сервер: сеть, принтер, AD, OU, профиль, GPO (Задание 6).
5. 100–125 мин — станция: Wi-Fi, домен, принтер, печать (Задание 7), пинги (Задание 8).
6. 125–150 мин — смета (Задание 9) и проверка.

В примерах XX = 05 (сервер `192.168.0.15`, SSID `EGZAMIN_05`, канал 5, домен `zs05.local`).

## Задание 1. Патч-корд T568B

**Что требуется** — прямой U/UTP, 8P8C, T568B на обоих концах, кабель «linka».

**Как сделать** — порядок **бело-оранжевый, оранжевый, бело-зелёный, синий, бело-синий, зелёный, бело-коричневый, коричневый**; оболочка под фиксатором; поднять руку; тест при экзаменаторе.

**За что дают баллы** — T568B; фиксатор на оболочке; «linka»; тест; подключение по схеме.

## Задание 2. Параметры беспроводной карты

**Что требуется** — в таблицу 2: MAC, производитель, поддерживаемые стандарты 802.11; скриншоты в папку `Identyfikacja` на флешке `Egzamin-x`.

**Как сделать**
```powershell
netsh wlan show drivers     # "Dostawca"/"Producent", "Obsługiwane typy radia: 802.11n 802.11g 802.11b"
getmac /v                   # MAC беспроводного адаптера
```
Дополнительно: `devmgmt.msc → Karty sieciowe → карта Wi-Fi → Właściwości` (вкладка `Ogólne` — производитель). Скриншоты → `E:\Identyfikacja\`.

**За что дают баллы** — MAC; производитель; стандарты (совпадают со скриншотами).

## Задание 3. Роутер и Wi-Fi

**Что требуется**
- LAN `192.168.0.1/24`; DHCP выключен.
- Wi-Fi включён: SSID `EGZAMIN_XX`, WPA2 с ключом `egzamin_XX`, шифрование AES/CCMP, диапазон 2,4 GHz, канал = номер места.
- Если AP — отдельное устройство: свободный IP из `192.168.0.0/24`, шлюз `192.168.0.1`, режим Access Point.

**Как сделать**
1. `Network → LAN` (часто уже `192.168.0.1`); `DHCP → Disable`.
2. `Wireless → Wireless Settings` (2,4 GHz): Enable, SSID `EGZAMIN_05`, Channel `5`, Mode `802.11b/g/n mixed` → Save.
3. `Wireless → Wireless Security`: **WPA2-PSK** (WPA/WPA2-Personal, версия WPA2), Encryption **AES**, Password `egzamin_05` → Save.
4. 5 GHz можно выключить, чтобы не мешал.

**За что дают баллы** — LAN; DHCP выключен; SSID + 2,4 GHz; WPA2-AES + канал.

**Частые ошибки** — оставлен канал «Auto»; выбран режим «WPA/WPA2 mixed» с TKIP.

## Задание 4. Коммутатор

**Что требуется** — VLAN 13, порты 1, 2, 3 untagged; IP `192.168.0.5/24` (L3 — на VLAN 13), шлюз `192.168.0.1`.

**Как сделать** — `System → IP Setting` → `192.168.0.5`, `255.255.255.0`, `192.168.0.1`; `802.1Q VLAN` → Enable → VLAN `13` (имя например `VLAN13`), порты 1–3 **Untagged**; `PVID` портов 1–3 = 13; Management VLAN (если есть) = 13 → Save Config.

**За что дают баллы** — VLAN 13 на портах 1–3 untagged; IP и шлюз.

## Задание 5. Подключение по схеме

Роутер, сервер, розетка с принтером — в порты 1–3 коммутатора по схеме; отдельный AP — в любой порт LAN.

## Задание 6. Windows Server

**Что требуется**
- `LAN_W`: `192.168.0.10+XX/24`, шлюз `192.168.0.1`, DNS localhost; второй интерфейс выключен.
- Принтер TCP/IP `192.168.0.200`, RAW, драйвер из `DRUKARKA`; общий ресурс `drukarka_XX`.
- Лес/домен `zsXX.local`, DSRM `egz@INF2`; если просят сменить пароль Administratora — `zaq1@WSX`.
- OU `TECHNIKUM`, в ней глобальная группа `UCZNIOWIE`, пользователь Karol Nowak / `knowak` / `know#1UCZ#`, член `UCZNIOWIE`.
- `C:\ZSprofile` → ресурс `ZSprofile$`, общие и NTFS-права — Pełna kontrola для всех; перемещаемый профиль knowak в этом ресурсе.
- GPO `bezpieczna_szkola`, связанная с корнем домена: мин. длина пароля 8; блокировка после 3 неудачных попыток на 15 минут.

**Как сделать**
1. `ncpa.cpl` → `LAN_W`, IPv4 `192.168.0.15/24`, шлюз `192.168.0.1`, DNS `127.0.0.1`; второй адаптер → `Wyłącz`.
2. Принтер: `Panel sterowania → Urządzenia i drukarki → Dodaj drukarkę → Drukarki, której szukam, nie ma na liście → Dodaj drukarkę przy użyciu adresu TCP/IP` → `192.168.0.200` → `Niestandardowe → Ustawienia`: **Raw**, port 9100 → `Z dysku…` → папка `DRUKARKA` → `Udostępnij tę drukarkę`, nazwa udziału `drukarka_05`.
3. `Dodaj role i funkcje → Usługi domenowe w usłudze Active Directory` → `Promuj… → Dodaj nowy las` → `zs05.local` → DSRM `egz@INF2` → Zainstaluj.
4. `Użytkownicy i komputery usługi AD` → `Nowy → Jednostka organizacyjna` `TECHNIKUM` → в ней `Nowy → Grupa`: `UCZNIOWIE`, Zakres **Globalny**, Typ Zabezpieczenia → `Nowy → Użytkownik`: Karol / Nowak / `knowak`, пароль, сними «musi zmienić» → свойства `knowak → Członek grupy → Dodaj` `UCZNIOWIE`.
5. `C:\ZSprofile → Udostępnianie zaawansowane` → `ZSprofile$` → `Uprawnienia: Wszyscy — Pełna kontrola`; `Zabezpieczenia → Edytuj → Dodaj Wszyscy → Pełna kontrola`.
6. `knowak → Właściwości → Profil → Ścieżka profilu`: `\\NAZWA_SERWERA\ZSprofile$\%username%` (имя сервера — команда `hostname`).
7. `Zarządzanie zasadami grupy` → ПКМ на `zs05.local` → `Utwórz obiekt GPO w tej domenie i umieść tu link…` → `bezpieczna_szkola` → `Edytuj` → `Konfiguracja komputera → Zasady → Ustawienia systemu Windows → Ustawienia zabezpieczeń → Zasady konta`:
   - `Zasady haseł → Minimalna długość hasła` = 8;
   - `Zasady blokady konta → Próg blokady konta` = 3, `Czas trwania blokady konta` = 15 min (Windows сам предложит `Wyzeruj licznik blokady konta po` = 15 min — соглашайся).
   Подними GPO на `kolejność łączy 1`, затем `gpupdate /force`.

```powershell
Rename-NetAdapter -Name "Ethernet" -NewName "LAN_W"
New-NetIPAddress -InterfaceAlias "LAN_W" -IPAddress 192.168.0.15 -PrefixLength 24 -DefaultGateway 192.168.0.1
Set-DnsClientServerAddress -InterfaceAlias "LAN_W" -ServerAddresses 127.0.0.1
Disable-NetAdapter -Name "Ethernet 2" -Confirm:$false
Install-WindowsFeature AD-Domain-Services -IncludeManagementTools
Install-ADDSForest -DomainName "zs05.local" -InstallDns `
  -SafeModeAdministratorPassword (ConvertTo-SecureString "egz@INF2" -AsPlainText -Force)
# после перезагрузки:
New-ADOrganizationalUnit -Name "TECHNIKUM" -Path "DC=zs05,DC=local"
New-ADGroup -Name "UCZNIOWIE" -GroupScope Global -GroupCategory Security -Path "OU=TECHNIKUM,DC=zs05,DC=local"
New-ADUser -Name "Karol Nowak" -GivenName Karol -Surname Nowak -SamAccountName knowak `
  -UserPrincipalName knowak@zs05.local -Path "OU=TECHNIKUM,DC=zs05,DC=local" -Enabled $true `
  -AccountPassword (ConvertTo-SecureString "know#1UCZ#" -AsPlainText -Force) `
  -ProfilePath "\\$env:COMPUTERNAME\ZSprofile$\knowak"
Add-ADGroupMember -Identity "UCZNIOWIE" -Members knowak
New-Item C:\ZSprofile -ItemType Directory
New-SmbShare -Name 'ZSprofile$' -Path C:\ZSprofile -FullAccess 'Wszyscy'
icacls C:\ZSprofile /grant "*S-1-1-0:(OI)(CI)F"
New-GPO -Name "bezpieczna_szkola" | New-GPLink -Target "DC=zs05,DC=local" -Order 1
Enable-NetFirewallRule -Name FPS-ICMP4-ERQ-In
```

**Как проверить** — `Get-Printer` (Shared = True, ShareName drukarka_05); `gpresult /r`; `Get-ADGroupMember UCZNIOWIE`.

**За что дают баллы** — LAN_W; второй адаптер выключен; принтер + общий доступ; DC zsXX.local; OU + глобальная группа; пользователь в группе; ресурс с полными правами; профиль; GPO связана с корнем; 3 настройки GPO.

**Частые ошибки** — группа создана с зоной «Lokalna w domenie»; принтер расшарили до повышения до DC и потом не проверили.

## Задание 7. Станция (Wi-Fi + домен)

**Что требуется** — беспроводной интерфейс `LAN_K`: `192.168.0.101/24`, шлюз `192.168.0.1`, DNS `192.168.0.15`, подключён к `EGZAMIN_XX`; станция в домене `zsXX.local`; под `knowak` добавить общий принтер и напечатать тестовую страницу (поднять руку, приложить лист).

**Как сделать**
1. `ncpa.cpl` → адаптер `Wi-Fi` → `Zmień nazwę` → `LAN_K` → IPv4 статический.
2. Значок сети → `EGZAMIN_05` → `Połącz automatycznie` → ключ `egzamin_05`.
3. `sysdm.cpl → Zmień → Domena` `zs05.local` → `ZS05\Administrator` → перезагрузка.
4. Войди как `ZS05\knowak`. `Ustawienia → Drukarki i skanery → Dodaj urządzenie` или в Проводнике `\\192.168.0.15` → ПКМ `drukarka_05` → `Połącz` (если запросит права администратора — введи `ZS05\Administrator`).
5. Свойства принтера → `Drukuj stronę testową` — сначала подними руку.

```powershell
Rename-NetAdapter -Name "Wi-Fi" -NewName "LAN_K"
New-NetIPAddress -InterfaceAlias "LAN_K" -IPAddress 192.168.0.101 -PrefixLength 24 -DefaultGateway 192.168.0.1
Set-DnsClientServerAddress -InterfaceAlias "LAN_K" -ServerAddresses 192.168.0.15
Add-Computer -DomainName "zs05.local" -Credential ZS05\Administrator -Restart
```

**За что дают баллы** — имя LAN_K; IP/шлюз/DNS; станция в домене; вход knowak; принтер у knowak; тестовая страница.

## Задание 8. Тесты связи

На станции: `ping 192.168.0.1` и `ping 192.168.0.15`; на сервере: `ping 192.168.0.200`. Если сервер не отвечает — включи правило ICMP на нём (см. выше). Подними руку.

## Задание 9. Смета `Kosztorys`

**Что требуется** — 7 столбцов: Lp., Nazwa usługi, Cena netto w zł, VAT w zł, Cena brutto w zł, Ilość, Wartość brutto w zł; только реально выполняемые услуги; VAT 23 %; итог, скидка 10 % если сумма > 450 zł, к оплате; формат валюты zł.

**Как сделать** — услуги из таблицы 1, **кроме «Montaż podzespołów»** (в задании нет монтажа): Konfiguracja systemu Windows 100; Konfiguracja systemu Windows Serwer 150; Identyfikacja parametrów 30; Podłączenie urządzeń sieciowych 100; Instalacja drukarki 60; Konfiguracja przełącznika 80; Konfiguracja rutera 90.

| Ячейка | Формула |
|---|---|
| D2 (VAT) | `=C2*23%` |
| E2 (brutto) | `=C2+D2` |
| G2 (wartość) | `=E2*F2` (копируй вниз до 8-й строки) |
| G9 ŁĄCZNA WARTOŚĆ USŁUG | `=SUMA(G2:G8)` |
| G10 UDZIELONY RABAT | `=JEŻELI(G9>450;G9*10%;0)` |
| G11 DO ZAPŁATY | `=G9-G10` |

Выдели C2:E8, G2:G11 → `Formatuj komórki → Walutowe → zł`. Сохрани как `Kosztorys.xlsx` на флешке. (При Ilość = 1: сумма 750,30 zł, скидка 75,03 zł, к оплате 675,27 zł.)

**За что дают баллы** — 7 столбцов; наличие нужных услуг (4 критерия); формулы VAT/brutto/wartość; сумма + условная скидка + к оплате; формат валюты; нет лишних услуг.
