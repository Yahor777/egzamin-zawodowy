# INF.02-05-25.06-SG: кроссовер-кабель, Wi-Fi WPA2, квоты Windows и права в Linux

Сценарий: обжимаешь кроссовер (один конец T568A, второй T568B), настраиваешь роутер (статический WAN, LAN `/28`, Wi-Fi WPA2-AES, без DHCP). Windows-станция подключается по Wi-Fi, разблокируешь пользователя `uczen`, создаёшь группу, задаёшь квоту 20 % диска, имя компьютера и Ctrl+Alt+Del. Linux-сервер: статический IP, имя хоста, каталог/файл с правами 770/660, пользователь с датой истечения. Плюс расчёт адресации сети `/28` в таблицу 2 и идентификация диска и RAM.

## Задание 1. Кроссовер U/UTP

**Что требуется** — кабель «z przeplotem», 8P8C с двух сторон, кабель «linka».

**Как сделать**
1. Конец 1 — **T568A**: бело-зелёный, зелёный, бело-оранжевый, синий, бело-синий, оранжевый, бело-коричневый, коричневый.
2. Конец 2 — **T568B**: бело-оранжевый, оранжевый, бело-зелёный, синий, бело-синий, зелёный, бело-коричневый, коричневый.
3. Оболочка под фиксатором на обоих концах; поднять руку; тест: тестер должен показать перекрещивание 1↔3, 2↔6.

**За что дают баллы** — конец T568A + фиксатор; конец T568B + фиксатор; «linka»; тест кроссовера пройден; подключение по схеме.

**Частые ошибки** — оба конца сделаны по T568B (получился прямой кабель).

## Задание 2. Роутер и Wi-Fi

**Что требуется**
- WAN `100.0.0.4/24`, шлюз `100.0.0.1`, DNS `4.4.4.4`, второй `4.4.5.5`.
- LAN1 `192.168.1.1/28` (маска `255.255.255.240`); DHCP выключен.
- Wi-Fi 2,4 GHz: SSID `Egzamin_XX`, **только WPA2-PSK**, ключ `Qwerty_XX`, AES/CCMP, канал XX (XX — номер места).
- Отдельный AP: свободный IP из `192.168.1.0/28` (например `192.168.1.14`), шлюз `192.168.1.1`, режим Access Point.

**Как сделать**
1. `Network → WAN` → Static IP → значения → Save.
2. `DHCP → Disable` → Save.
3. `Network → LAN`: `192.168.1.1`, маска `255.255.255.240` → Save, переподключись (ПК временно в той же подсети, например `192.168.1.2/28`).
4. `Wireless → Basic`: 2,4 GHz Enable, SSID `Egzamin_05`, Channel `5`. `Wireless → Security`: **WPA2-PSK** (не «WPA/WPA2»), Encryption **AES**, ключ `Qwerty_05` → Save.

**За что дают баллы** — WAN IP; шлюз; DNS; LAN1 /28; DHCP выключен; SSID; WPA2-PSK AES; канал.

## Задание 4. Идентификация (Windows)

**Что требуется** — в таблицу 1: производитель и ёмкость диска; объём и частота RAM; скриншоты в папку `Identyfikacja` на флешке `Egzamin-x`.

**Как сделать**
1. `Menedżer zadań → Wydajność → Dysk 0` — модель (производитель) и ёмкость; `Pamięć` — объём и `Szybkość` (MHz/MT/s).
2. Или `msinfo32 → Składniki → Magazyn → Dyski` (Producent, Rozmiar).
3. Скриншоты → `E:\Identyfikacja\`.

**За что дают баллы** — производитель диска; ёмкость диска; объём RAM; частота RAM.

## Задание 5. Windows-станция

**Что требуется**
- Беспроводной интерфейс `W-LAN`: `192.168.1.2/28`, шлюз `192.168.1.1`, DNS `4.4.4.4`; подключиться к `Egzamin_XX`.
- Пользователь `uczen` не может войти — восстановить вход; пароль `QweRTY!1`, «nie może zmienić hasła», «hasło nigdy nie wygasa».
- Группа `egzamin` с членом `uczen`.
- Квоты: включить «odmów miejsca…», для `uczen` лимит 20 % ёмкости диска.
- Имя компьютера `PCuczen`; требование Ctrl+Alt+Del.

**Как сделать**
1. `ncpa.cpl` → `Wi-Fi` → `Zmień nazwę` → `W-LAN` → IPv4: `192.168.1.2`, `255.255.255.240`, `192.168.1.1`, DNS `4.4.4.4`. Подключись к `Egzamin_05` с ключом `Qwerty_05`.
2. `lusrmgr.msc → Użytkownicy → uczen → Właściwości`: сними **«Konto jest wyłączone»** (и «Konto jest zablokowane», если отмечено), отметь «Użytkownik nie może zmienić hasła» и «Hasło nigdy nie wygasa». ПКМ → `Ustaw hasło…` → `QweRTY!1`.
3. `lusrmgr.msc → Grupy → Nowa grupa` → `egzamin` → `Dodaj` → `uczen`.
4. `C: → Właściwości → Przydział → Pokaż ustawienia przydziału` → `Włącz zarządzanie przydziałami` + **`Odmów miejsca na dysku użytkownikom przekraczającym limit przydziału`** → Zastosuj → `Wpisy przydziałów → Przydział → Nowy wpis przydziału` → `uczen` → limit = 20 % ёмкости (диск 120 GB → 24 GB; ёмкость смотри на вкладке `Ogólne`).
5. `secpol.msc → Zasady lokalne → Opcje zabezpieczeń → Logowanie interakcyjne: nie wymagaj naciśnięcia klawiszy CTRL+ALT+DEL` → **Wyłączone**.
6. `sysdm.cpl → Zmień…` → `PCuczen` → перезагрузка в самом конце.

```powershell
Rename-NetAdapter -Name "Wi-Fi" -NewName "W-LAN"
New-NetIPAddress -InterfaceAlias "W-LAN" -IPAddress 192.168.1.2 -PrefixLength 28 -DefaultGateway 192.168.1.1
Set-DnsClientServerAddress -InterfaceAlias "W-LAN" -ServerAddresses 4.4.4.4
Enable-LocalUser -Name "uczen"
Set-LocalUser -Name "uczen" -Password (ConvertTo-SecureString "QweRTY!1" -AsPlainText -Force) `
  -PasswordNeverExpires $true -UserMayChangePassword $false
New-LocalGroup -Name "egzamin"
Add-LocalGroupMember -Group "egzamin" -Member "uczen"
(Get-Volume -DriveLetter C).Size / 1GB * 0.2      # 20% в GB
Rename-Computer -NewName "PCuczen"
```

**Как проверить** — `net user uczen` («Konto aktywne: Tak», «Użytkownik może zmieniać hasło: Nie»); `net localgroup egzamin`; `ipconfig /all`.

**За что дают баллы** — имя W-LAN + IP/маска; шлюз + DNS; учётка включена; два флажка пароля; имя PCuczen; группа с членом; квота ≈20 %; Ctrl+Alt+Del; пинги роутера и сервера.

**Частые ошибки** — квота задана, но не отмечен «Odmów miejsca…»; забыли перезагрузить после смены имени.

## Задание 6. Linux-сервер

**Что требуется**
- IP `192.168.1.3/28`, шлюз `192.168.1.1`, DNS `4.4.4.4`; имя хоста `PCserwer`.
- `/home/zadanie` (права 770), в нём файл `dane` с текстом `INF.02` (права 660).
- Пользователь `egzamin`, пароль `Egz@min12!`, срок действия учётки 15.02.2029.
- Владелец `/home/zadanie` — `egzamin`, группа `root`.

**Как сделать**
```bash
ip a                                     # имя интерфейса, напр. enp0s3
sudo nano /etc/netplan/50-cloud-init.yaml
```
```yaml
network:
  version: 2
  ethernets:
    enp0s3:
      dhcp4: false
      addresses: [192.168.1.3/28]
      routes:
        - to: default
          via: 192.168.1.1
      nameservers:
        addresses: [4.4.4.4]
```
```bash
sudo netplan apply
sudo hostnamectl set-hostname PCserwer
sudo mkdir /home/zadanie
echo "INF.02" | sudo tee /home/zadanie/dane
sudo useradd -m -s /bin/bash -e 2029-02-15 egzamin
sudo passwd egzamin                      # Egz@min12!
sudo chmod 770 /home/zadanie
sudo chmod 660 /home/zadanie/dane
sudo chown -R egzamin:root /home/zadanie
```

**Как проверить**
```bash
ip a; ip r; hostnamectl
sudo chage -l egzamin            # Account expires: Feb 15, 2029
ls -l /home/zadanie; ls -ld /home/zadanie
cat /home/zadanie/dane
```

**За что дают баллы** — IP/шлюз/DNS; имя PCserwer; пользователь с датой 15.02.2029; каталог; файл; права 770/660; владелец egzamin, группа root (каталог и файл).

**Частые ошибки** — `chown` без `-R` — у файла остаётся владелец root; дата введена как `15.02.2029` (формат для `-e` — `ГГГГ-ММ-ДД`).
