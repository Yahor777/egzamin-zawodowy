# INF.02-07-26.06-SG: замена видеокарты и RAM, диагностика под CAD, сайт IIS и смета с рабатом

Сценарий: в рабочей станции меняешь видеокарту и добавляешь RAM, ставишь драйвер, в Windows проверяешь соответствие требованиям CAD. Настраиваешь роутер (статический WAN /28, DHCP с резервацией) и коммутатор (только IP), на Windows Server — интерфейс LAN_S, принтер и сайт IIS `egzamin`, на Linux-станции — интерфейс LAN_K по DHCP, пользователя и группу, архив со скриншотами. В конце смета с условным рабатом. Оценивается 6 результатов: монтаж и подключение, диагностика, сетевые устройства, сервер, станция, смета + ход монтажа.

## Порядок работы (план на 150 минут)
1. Монтаж видеокарты и RAM, поднять руку (0–15 мин).
2. Драйвер видеокарты, диагностика + скриншоты (15–35).
3. Подключение по схеме, роутер, коммутатор (35–60).
4. Сервер: LAN_S, принтер, IIS (60–90).
5. Linux-станция: LAN_K, пользователь, архив, браузер (90–110).
6. Проверка связи при экзаменаторе (110–115).
7. Смета (115–140), резерв 10 мин.

## Задание 1. Монтаж видеокарты и RAM
**Что требуется**
- Снять видеокарту (интегрированную — отключить в BIOS или `Menedżer urządzeń`), поставить запасную; поставить запасную RAM; поднять руку.

**Как сделать**
1. Выключи ПК, отключи питание от сети, надень антистатический браслет.
2. Видеокарта: открути винт планки, отожми защёлку PCIe x16, вынь карту. Новую вставь до щелчка, прикрути винтом, подключи доп. питание PCIe, если есть разъём.
3. RAM: открой защёлки слота, совмести вырез модуля с ключом, нажми до щелчка.
4. Закрой корпус и только потом подключай питание. Подними руку.

**За что дают баллы**
- Старая карта снята/отключена, новая закреплена; RAM установлена без повреждений; в ходе работы — питание отключено, браслет надет, порядок на столе.

**Частые ошибки**
- Подключить питание до закрытия корпуса (отдельный критерий хода работ).

## Задание 2. Драйвер видеокарты
**Что требуется**
- Установить драйвер в Windows, в `Menedżer urządzeń` не должно быть жёлтого восклицательного знака.

**Как сделать**
1. `Menedżer urządzeń → Karty graficzne` → ПКМ → `Aktualizuj sterownik → Przeglądaj mój komputer` → папка с драйвером на носителе DOKUMENTACJA/PROGRAMY (или запусти setup.exe производителя).

**Как проверить**
- `devmgmt.msc` — карта отображается под своим именем, без «Podstawowa karta graficzna Microsoft».

**За что дают баллы**
- Драйвер установлен, нет значка с восклицательным знаком.

## Задание 3. Диагностика в Windows
**Что требуется**
- Таблица 3: название ОС и разрядность, версия ОС, частота CPU, объём RAM, ёмкость диска, память видеокарты, разрешение экрана; колонка `Wniosek` — TAK/NIE.
- Требования: Windows 11 64-bit, версия 22H1+, 3.0 GHz, 16 GB RAM, 100 GB диск, 8 GB видеопамяти, Full HD 1920×1080.
- Строка `Ocena` — какие параметры не соответствуют; `Wskazania` — что модернизировать (или `Nie wymaga`).
- Скриншоты в папку `Diagnostyka` на USB `Egzamin-x`.

**Как сделать**
1. `winver` — название и версия (например «Windows 11 Pro, wersja 23H2»).
2. `msinfo32` — «Nazwa systemu operacyjnego», «Typ systemu: komputer z procesorem x64», «Procesor … 3,20 GHz», «Zainstalowana pamięć fizyczna (RAM)».
3. `diskmgmt.msc` — ёмкость диска.
4. `dxdiag → Wyświetlanie` — «Pamięć dedykowana/Pamięć wyświetlania (VRAM)» и текущий режим; или `Ustawienia → System → Ekran → Rozdzielczość ekranu`.
```powershell
Get-ComputerInfo -Property OsName, OsArchitecture, OSDisplayVersion
Get-CimInstance Win32_Processor | Select Name, MaxClockSpeed
Get-CimInstance Win32_ComputerSystem | Select TotalPhysicalMemory
Get-Disk | Select FriendlyName, Size
```
4. Скриншоты (`Win+Shift+S` → Paint → `E:\Diagnostyka\...png`).

**Как проверить**
- Каждое значение в таблице видно на одном из скриншотов.

**За что дают баллы**
- По каждому из 7 параметров — значение + верный вывод TAK/NIE; заполнена `Ocena` (перечень несоответствий или «wszystkie spełniają»); `Wskazania` касаются именно несоответствующих частей (например «wymiana karty graficznej na model z 8 GB, rozbudowa RAM do 16 GB»).

**Частые ошибки**
- Записывать память видеокарты из `Pamięć udostępniona` (общая) вместо выделенной.
- «22H1» у Windows 11 не существует — сравнивай по году/полугодию: 22H2, 23H2, 24H2 соответствуют.

## Задание 4. Роутер
**Что требуется**
- WAN: `70.70.70.1/28` (маска `255.255.255.240`), шлюз `70.70.70.2`, DNS `8.8.8.8` (второй `4.4.4.4`, если нужен).
- LAN: `192.168.0.5/24`.
- DHCP: включён, `192.168.0.10 ÷ 192.168.0.40`, резервация `192.168.0.12` для проводного интерфейса станции.

**Как сделать**
1. `Network → WAN`: Static IP, адрес, маска, шлюз, DNS.
2. `Network → LAN`: `192.168.0.5`/`255.255.255.0`; перезайди на `http://192.168.0.5`.
3. `DHCP Settings`: Enable, `192.168.0.10`–`192.168.0.40`.
4. MAC станции в Linux: `ip link` (строка `link/ether`). `DHCP → Address Reservation` → `192.168.0.12`. Подними руку.

**За что дают баллы**
- WAN IP/28, шлюз, DNS 8.8.8.8; LAN 192.168.0.5/24; DHCP .10–.40; резервация .12.

**Частые ошибки**
- Маска /28 = 255.255.255.240 (не .248 — это /29, и не .252 — это /30).

## Задание 7. Windows Server
**Что требуется**
- Интерфейс к коммутатору: имя `LAN_S`, IP `192.168.0.100+X/24` (стенд 7 → `192.168.0.107`), шлюз `192.168.0.5`; второй интерфейс отключён.
- Принтер TCP/IP `192.168.0.200`, RAW, драйвер из `DRUKARKA`; тестовая страница (поднять руку), приложить к листу.
- Папка `C:\WITRYNA`, скопировать туда `witryna.html` из `PLIKI`.
- Роль `Serwer sieci Web (IIS)`; сайт `egzamin`, привязка к IP LAN_S, каталог `C:\WITRYNA`, документ по умолчанию `witryna.html`.

**Как сделать**
1. `ncpa.cpl`: переименовать в `LAN_S`, IPv4 статический; второй адаптер → `Wyłącz`.
2. Принтер: `Urządzenia i drukarki → Dodaj drukarkę → … przy użyciu adresu TCP/IP` → `192.168.0.200` → `Niestandardowy → Raw, 9100` → `Z dysku…` → `Drukuj stronę testową`.
3. `Menedżer serwera → Zarządzaj → Dodaj role i funkcje → Serwer sieci Web (IIS)`.
4. `Menedżer IIS → Witryny → Dodaj witrynę sieci Web`: nazwa `egzamin`, ścieżka `C:\WITRYNA`, typ http, Adres IP `192.168.0.10X`, port 80. Witrynę `Default Web Site` можно остановить.
5. На сайте `egzamin → Dokument domyślny → Dodaj… → witryna.html` и `Przenieś w górę` на первое место.

```powershell
Rename-NetAdapter -Name "Ethernet" -NewName "LAN_S"
New-NetIPAddress -InterfaceAlias "LAN_S" -IPAddress 192.168.0.10X -PrefixLength 24 -DefaultGateway 192.168.0.5
Disable-NetAdapter -Name "Ethernet 2" -Confirm:$false
New-Item C:\WITRYNA -ItemType Directory
Copy-Item D:\PLIKI\witryna.html C:\WITRYNA\
Install-WindowsFeature Web-Server -IncludeManagementTools
Import-Module WebAdministration
Stop-Website "Default Web Site"
New-Website -Name "egzamin" -PhysicalPath "C:\WITRYNA" -IPAddress 192.168.0.10X -Port 80
Add-WebConfigurationProperty -PSPath "IIS:\Sites\egzamin" -Filter "//defaultDocument/files" -AtIndex 0 -Name "Collection" -Value "witryna.html"
```

**Как проверить**
- В браузере сервера `http://192.168.0.10X` — надпись «EGZAMIN INF.02!» на синем фоне.

**За что дают баллы**
- LAN_S с правильным IP и шлюзом; принтер 192.168.0.200; тестовая страница; C:\WITRYNA со witryna.html; роль IIS; сайт egzamin (IP, каталог, документ по умолчанию); ping коммутатора, роутера, станции, принтера.

**Частые ошибки**
- Писать `192.168.0.100+X` буквально — нужно посчитать (X=12 → `192.168.0.112`).
- Привязка `Wszystkie nieprzypisane` вместо конкретного IP.

## Задание 8. Linux-станция
**Что требуется**
- Проводной интерфейс с именем `LAN_K`, адрес по DHCP (получит `192.168.0.12`).
- В терминале со скриншотами (видны команды) в домашнем каталоге `administrator`: группа `sluchacze`, пользователь `egzamin` с домашним каталогом, пароль `Egz-inf02!`, добавить в `sluchacze`.
- Архив `~/egzamin.tar` со скриншотами.
- В браузере открыть `witryna.html` с сервера.

**Как сделать**
1. Переименовать интерфейс через netplan (MAC из `ip link`), файл `/etc/netplan/01-lan_k.yaml`:
```yaml
network:
  version: 2
  ethernets:
    LAN_K:
      match:
        macaddress: "aa:bb:cc:dd:ee:ff"
      set-name: LAN_K
      dhcp4: true
```
```bash
sudo chmod 600 /etc/netplan/01-lan_k.yaml
sudo netplan apply && sudo reboot          # переименование надёжно применяется после перезагрузки
ip a show LAN_K                            # inet 192.168.0.12/24
```
На Ubuntu Desktop дополнительно переименуй профиль NetworkManager: `nmcli con show`, затем `sudo nmcli con mod "<stara nazwa>" connection.id LAN_K` (если профиль создан вручную, а не netplan).
2. Пользователи (делай скриншоты `PrtSc` после каждой команды):
```bash
sudo groupadd sluchacze
sudo useradd -m -s /bin/bash egzamin
sudo passwd egzamin                        # Egz-inf02!
sudo usermod -aG sluchacze egzamin
id egzamin
cp ~/Obrazy/Zrzuty\ ekranu/*.png ~/        # скриншоты в домашний каталог (в англ. системе ~/Pictures/Screenshots)
cd ~ && tar -cvf egzamin.tar *.png
tar -tvf egzamin.tar                       # проверка содержимого
```
3. Firefox: `http://192.168.0.10X`.

**За что дают баллы**
- Имя LAN_K + DHCP; адрес 192.168.0.12; на скриншотах команды создания пользователя с паролем, группы, добавления в группу; egzamin.tar с хотя бы одним скриншотом; страница «EGZAMIN INF.02!» на синем фоне в браузере.

**Частые ошибки**
- Скриншоты остались в `Obrazy` — нужны в домашнем каталоге.
- Пробелы в именах файлов скриншотов: используй маску `*.png` в tar, а не перечисление.

## Задание 10. Смета `kosztorys`
**Что требуется**
- Колонки: Lp., Nazwa podzespołu, Cena netto, Cena brutto, Ilość, Wartość brutto; строки `Wartość` и `Wartość po rabacie`.
- Brutto = netto + 23%; Wartość brutto = brutto × ilość; сумма автоматически; рабат 10% если > 4000 zł, иначе 5%; формат валюты с 2 знаками.

**Как сделать**
1. Состав (соответствует требованиям CAD): Płyta główna Asus (Socket 1700) + Procesor Intel Core i3 (1700, 3,5 GHz) + RAM Kingston 16 GB DDR4 + Karta graficzna Asus RX 6600 8 GB + Dysk SSD 500 GB + Obudowa Krux + Zasilacz Endorfy + Monitor ASUS Full HD + Klawiatura + Mysz (10 позиций, Ilość = 1).
2. Данные в строках 2–11: D2 `=C2*1,23`, F2 `=D2*E2`, протянуть.
3. Wartość (F12): `=SUMA(F2:F11)`; Wartość po rabacie (F13): `=JEŻELI(F12>4000;F12*0,9;F12*0,95)`.
4. Формат C, D, F: `Walutowe`, 2 знака, `zł`. Сохрани как `kosztorys` на USB.
5. Контроль: сумма нетто 3373,00 zł → брутто 4148,79 zł → после рабата 3733,91 zł.

**За что дают баллы**
- 6 колонок; Asus + i3; Kingston; RX 6600 Asus + SSD; корпус, БП, монитор, мышь, клавиатура; формулы брутто и значения; формат валюты; SUMA; JEŻELI с 10%/5%.

**Частые ошибки**
- Выбрать i5 (2,9 GHz < 3,0 GHz) или RTX 3050 (6 GB < 8 GB).
- `>=` вместо `>` в условии.
