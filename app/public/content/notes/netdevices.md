# Сетевые устройства, топологии и Wi‑Fi (Urządzenia sieciowe, topologie i Wi‑Fi)

## Устройства по уровням OSI
| Устройство | Польский | Уровень | Что делает | Домены |
|---|---|---|---|---|
| Повторитель | wzmacniak, regenerator (repeater) | 1 | усиливает/восстанавливает сигнал | не делит |
| Концентратор | **koncentrator (hub)** | 1 | рассылает сигнал на **все** порты | 1 домен коллизий на все порты → **больше коллизий** |
| Мост | **most (bridge)** | 2 | анализирует **MAC**, пропускает/блокирует кадр между сегментами; **store and forward**; может связывать сегменты с разными протоколами канального уровня | каждый сегмент — свой домен коллизий |
| Коммутатор | **przełącznik (switch)** | 2 | пересылает кадр **только в порт получателя** по таблице MAC (CAM) | **каждый порт — отдельный домен коллизий**, 1 домен broadcast (без VLAN) |
| Маршрутизатор | **ruter (router)** | 3 | пересылает **пакеты между сетями** по IP, уменьшает TTL | **граница домена broadcast** |
| Коммутатор L3 | przełącznik warstwy 3 | 3 | коммутация + маршрутизация между VLAN | — |
| Точка доступа | **punkt dostępu (access point, AP)** | 2 | соединяет беспроводных клиентов с **проводной LAN** | — |
| Модем | modem | 1 | аналог ↔ цифра (телефонная линия, ADSL, кабель) | — |
| Сетевая карта | karta sieciowa (NIC) | 1–2 | преобразует кадры в сигналы, имеет MAC | — |
| Конвертер сред | **konwerter mediów (media converter)** | 1 | оптоволокно ↔ медная витая пара (RJ45) | — |
| Межсетевой экран | **zapora sieciowa (firewall)** | 3–7 | фильтрует трафик, защищает от атак извне | — |
| Инжектор PoE | zasilacz PoE | 1 | питание по витой паре (802.3af/at/bt) | — |

- Сервер **не меняет** число доменов коллизий. Hub не ограничивает домен коллизий.
- Пример подсчёта: каждый порт коммутатора и роутера = 1 домен коллизий; каждый интерфейс роутера = 1 домен broadcast.
- Пассивные элементы (elementy pasywne): **панель коммутационная (panel krosowy)**, кабели, розетки, шкаф. Активные: switch, router, AP.
- Прочее: адаптеры **PowerLine** (сеть по электропроводке), принт-сервер (USB + RJ45), шлюз VoIP, защита от перенапряжений (NetProtector).
- Кнопка **Reset** на роутере — **сброс к заводским настройкам**. Первое действие защиты роутера — **сменить логин и пароль администратора**.

## Топологии (topologie)
### Физические (fizyczne)
| Топология | Польский | Особенности |
|---|---|---|
| Шина | **magistrala** (bus) | один общий кабель (коаксиал), **терминаторы** на концах; обрыв кабеля → падение сети |
| Звезда | **gwiazda** (star) | все к **центральному** устройству (switch); централизованное управление |
| Расширенная звезда | **rozszerzona gwiazda** | несколько звёзд, связанных коммутаторами |
| Иерархическая / дерево | **hierarchiczna** (drzewo) | уровни коммутаторов |
| Кольцо | **pierścień** (ring) | замкнутый круг, передача **маркера (żeton, token)** |
| Двойное кольцо | podwójny pierścień | FDDI |
| Полная сетка | **pełna siatka** (full mesh) | **каждый узел соединён с каждым** |
| Частичная сетка | siatka częściowa | часть связей |
| Ad-hoc / IBSS | ad-hoc | беспроводная децентрализованная, **сетка** без AP |

### Логические (logiczne)
- **Широковещательная (rozgłaszania, broadcast)** — Ethernet: все получают кадр.
- **Передача маркера (przekazywania żetonu)** — Token Ring (физически кольцо), FDDI.

### Метод доступа к среде
- **CSMA/CD** (Ethernet, IEEE 802.3): слушать среду → если занято, ждать → при коллизии сигнал jam и случайная задержка.
- **CSMA/CA** (Wi‑Fi, **IEEE 802.11**): избегание коллизий.
- Half duplex (półdupleks) — **двусторонняя поочерёдная**; full duplex — одновременно в обе стороны (NIC работает в асинхронном full duplex).

## Типы сетей по охвату
- **PAN** — персональная (Bluetooth), **LAN** — локальная, **MAN** — городская, **WAN** — глобальная.
- **Intranet** — внутренняя сеть одной организации (WWW, почта для своих); Extranet — доступ партнёров.
- Масштабируемость (skalowalność) — возможность расширения сети.

## VLAN и 802.1Q
- **VLAN** (Virtual LAN, wirtualna sieć lokalna) — логическое деление сети на коммутаторе; отдельные домены broadcast. Компьютеры в **разных VLAN** не общаются без маршрутизатора (даже с одной IP-сетью).
- Стандарт **IEEE 802.1Q** — тегирование кадров (4 байта, VLAN ID 12 бит: 1–4094).
- Порт **access** (untagged) — один VLAN; порт **trunk** (tagged) — **кадры многих VLAN по одному каналу**. Native VLAN — без тега.
- Cisco CLI: `enable` → `configure terminal` (режим конфигурации) → `vlan 10` → `name …`; `interface fa0/1` → `switchport mode access` → `switchport access vlan 10`; `show vlan`, **`show mac address-table`**.
- Linux: VLAN создаётся через **`ip link`** (`ip link add link eth0 name eth0.10 type vlan id 10`).
- Межвлановая маршрутизация: роутер (router-on-a-stick) или коммутатор L3.

## STP и функции управляемого коммутатора
- **STP** (Spanning Tree Protocol, IEEE 802.1D) — устраняет **петли** и **broadcast storm**, блокируя резервные порты; корневой мост (root bridge), кадры BPDU, hello = 2 s.
- **RSTP** (802.1w) — быстрая версия; MSTP (802.1s) — по группам VLAN.
- **Агрегация каналов (agregacja łączy, link aggregation, LACP 802.3ad)** — несколько физических линков = один логический, больше пропускная способность.
- **Port mirroring** — копия трафика порта на анализатор.
- **QoS** — приоритет трафика (VoIP).
- **RMON** (Remote Network Monitoring) — расширенный мониторинг и отчёты.
- **Port security / фильтрация MAC**, 802.1X — контроль доступа.
- Тест кабеля в коммутаторе (cable diagnostics) — состояние линии и **расстояние до повреждения**.

## Методы коммутации (metody przełączania)
| Метод | Суть |
|---|---|
| **Store-and-forward** | принять весь кадр, проверить **CRC**, затем переслать (так работает и мост) |
| **Cut-through** | пересылка после чтения MAC получателя (минимальная задержка, без проверки) |
| **Fragment-free** | читает первые **64 байта** (отсекает фрагменты коллизий) |

## Стандарты Wi‑Fi (IEEE 802.11)
| Стандарт | Имя | Диапазон | Макс. скорость |
|---|---|---|---|
| 802.11 | — | 2,4 GHz | 2 Mb/s |
| **802.11a** | — | **5 GHz** | 54 Mb/s |
| **802.11b** | — | 2,4 GHz | **11 Mb/s** |
| **802.11g** | — | 2,4 GHz | **54 Mb/s** |
| **802.11n** | Wi‑Fi 4 | **2,4 и 5 GHz** | 600 Mb/s (MIMO) |
| **802.11ac** | Wi‑Fi 5 | 5 GHz | ~6,9 Gb/s |
| **802.11ax** | Wi‑Fi 6 / 6E | 2,4 / 5 / (6) GHz | ~9,6 Gb/s |
| 802.11be | Wi‑Fi 7 | 2,4/5/6 GHz | ~46 Gb/s |

- «Wi‑Fi» — торговая марка сертифицированных устройств 802.11.
- В Польше в 2,4 GHz — **13 каналов**; непересекающиеся 1, 6, 11 → соседние сети разносить на **5 каналов**.
- Сетевая карта 54 Mb/s = 802.11g (или a).
- Режимы: **инфраструктурный** (BSS/ESS, через AP), **ad-hoc (IBSS)** — без AP; повторитель/усилитель сигнала (wzmacniacz, repeater) — увеличить зону покрытия.
- Слабый сигнал → обрывы связи. Антенна с наибольшим усилением и дальностью — **параболическая**.
- Bluetooth — **2,4 GHz ISM**, PAN; IrDA — **инфракрасный** канал.

## Безопасность Wi‑Fi
| Стандарт | Шифрование | Оценка |
|---|---|---|
| **WEP** | RC4, статический ключ | взломан, не использовать |
| **WPA** | TKIP | устарел |
| **WPA2** | **AES-CCMP** | рекомендуемый (в старых вопросах — «лучший») |
| **WPA3** | AES, SAE | **новейший** |

- **Personal (PSK)** — общий пароль (дом: WPA-PSK/WPA2-PSK). **Enterprise** — 802.1X + **RADIUS**.
- **SSID** — имя сети, должно совпадать у устройств; **скрытие SSID** (wyłączenie rozgłaszania) и **фильтрация MAC** — дополнительные (слабые) меры. Отключить WPS.

## Инструменты анализа сети
- **Сниффер (sniffer)** — перехват и анализ пакетов: **Wireshark**, CommView, tcpdump.
- **nmap** — сканирование сети/портов (Linux); Advanced IP Scanner — список активных устройств LAN.
- **MRTG** — графики трафика интерфейсов (SNMP); Nagios, ntop — мониторинг; Acrylic Wi‑Fi — анализ беспроводных сетей.

## Диагностические команды
| Команда | Назначение |
|---|---|
| `ping` | проверка связи (**ICMP** echo); `-t` бесконечно, `-n 5` кол-во, **`-l 1000` размер пакета**, `-a` имя хоста; Linux `-c` |
| TTL в ответе ping | оставшийся счётчик переходов (уменьшается каждым роутером; 0 → пакет отброшен) |
| `tracert` (Linux `traceroute`) | **трасса пакета**, число промежуточных роутеров |
| `pathping` | tracert + статистика потерь на каждом узле |
| `netstat` | **активные соединения**, порты; `-a` все, `-n` числами, `-r` таблица маршрутов, **`-e` статистика интерфейса (байты/пакеты)**, `-o` PID |
| `nslookup` | запросы к DNS; `nslookup -type=MX domena` — запись MX |
| `arp -a` | таблица ARP (IP → MAC); `arp -d` удалить, `arp -s` статическая запись |
| `ipconfig` | `/all` полная конфигурация (DNS, MAC), `/release`, `/renew`, `/flushdns`, `/displaydns`, `/registerdns` |
| `route print` / `route add` | таблица маршрутизации Windows |
| `getmac` | MAC-адреса карт; `netsh` — конфигурация сети из CLI |
| Linux | `ip a`, `ifconfig`, `ip route`, `mtr`, `ifup/ifdown`, `ss`/`netstat` |

Первый шаг при потере связи — **проверить IP, назначенный сетевой карте** (`ipconfig`).

## Условные обозначения на схемах (symbole)
- **Маршрутизатор** — круг с четырьмя стрелками (крест), **коммутатор** — прямоугольник/квадрат со стрелками в обе стороны, **концентратор** — прямоугольник со стрелками в одну линию, **мост** — прямоугольник с изогнутой стрелкой, **межсетевой экран** — кирпичная стена, **точка доступа** — прямоугольник с антенной/волнами.
- Пунктир/молния между устройствами — последовательный (WAN) канал; ломаная линия — кросс-кабель (в Packet Tracer).

## Частые ловушки на экзамене
- Hub **увеличивает** коллизии; switch делит домены **коллизий**; router делит домены **broadcast**.
- Мост — уровень 2, работает в режиме **store and forward**, анализирует MAC.
- Trunk = кадры **многих VLAN** по одному каналу (802.1Q).
- Против broadcast storm/петель — **STP/RSTP**, не VLAN и не QoS.
- 5 GHz: 802.11**a**, n, ac; только 2,4 GHz: b, g. 2,4 + 5 GHz из вариантов обычно **802.11n**.
- CSMA/CD — Ethernet; CSMA/CA — Wi‑Fi 802.11.
- Token passing → топология **кольца**; все соединены со всеми → **полная сетка**.
- Новейший стандарт защиты — **WPA3**; WEP — самый слабый.
- `netstat -e` — статистика интерфейса; `tracert` — трасса; `ping -l` — размер пакета.
- AP — соединяет беспроводных клиентов с проводной сетью; модем — аналог ↔ цифра.
