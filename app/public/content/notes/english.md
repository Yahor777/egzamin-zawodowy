# Английский в ИТ (Język angielski w IT)

## Как это встречается на экзамене
- В банке вопросов INF.02 английские слова появляются в виде **расшифровок аббревиатур** (np. «ARP (Address Resolution Protocol)»), пометок «(ang. …)», сообщений программ и BIOS («PAPER JAM», «403 Forbidden», «Display switch is set incorrectly») и названий функций устройств.
- Стратегия: знать **полную форму аббревиатуры** — по ней часто угадывается ответ (Dynamic Host **Configuration** → автоконфигурация; Trivial File **Transfer** → передача файлов).

## 10 примеров предложений
1. **The router forwards packets between different networks.** — Ruter przekazuje pakiety między różnymi sieciami. — Маршрутизатор пересылает пакеты между разными сетями.
2. **A switch creates a separate collision domain on each port.** — Przełącznik tworzy osobną domenę kolizyjną na każdym porcie. — Коммутатор создаёт отдельный домен коллизий на каждом порту.
3. **DHCP automatically assigns IP addresses to client computers.** — DHCP automatycznie przydziela adresy IP komputerom klienckim. — DHCP автоматически назначает IP-адреса клиентским компьютерам.
4. **Disable SSID broadcast and enable WPA2 encryption.** — Wyłącz rozgłaszanie SSID i włącz szyfrowanie WPA2. — Отключите вещание SSID и включите шифрование WPA2.
5. **The user does not have permission to access the requested resource.** — Użytkownik nie ma uprawnień do żądanego zasobu. — У пользователя нет прав на запрошенный ресурс (ошибка 403).
6. **Remove the jammed paper before restarting the printer.** — Usuń zacięty papier przed ponownym uruchomieniem drukarki. — Удалите замятую бумагу перед перезапуском принтера.
7. **Wear an antistatic wrist strap when installing memory modules.** — Załóż opaskę antystatyczną podczas montażu modułów pamięci. — Надевайте антистатический браслет при установке модулей памяти.
8. **Back up your data regularly to an external drive or the cloud.** — Regularnie wykonuj kopię zapasową danych na dysk zewnętrzny lub w chmurze. — Регулярно делайте резервную копию на внешний диск или в облако.
9. **Update the device driver to fix the display problem.** — Zaktualizuj sterownik urządzenia, aby usunąć problem z wyświetlaniem. — Обновите драйвер устройства, чтобы устранить проблему с изображением.
10. **The ping command uses ICMP to test connectivity between two hosts.** — Polecenie ping używa ICMP do testowania łączności między dwoma hostami. — Команда ping использует ICMP для проверки связи между двумя хостами.

## Частые ловушки на экзамене
- «Store and forward» — режим работы **моста/коммутатора**, а не концентратора.
- «Trap» в SNMP — **уведомление агента менеджеру**, а не атака.
- «Forbidden 403» — нет прав; «Not Found 404» — нет ресурса.
- «Malware» включает keylogger, exploit, scumware, но **не CAM (computer aided manufacturing)**.
- «Plug-ins» — расширения браузера (например, VPN, поддержка не-HTML документов).
- «Hot-plug» — устройство работает **сразу после подключения без перезагрузки**.
- «Token» — маркер в топологии **кольца**; «overclocking» у Intel — процессоры с буквой **K**.
- «Display switch is set incorrectly» (Award BIOS) — **неверный режим отображения**.
