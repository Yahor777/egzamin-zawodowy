# Периферийные устройства и интерфейсы (Urządzenia peryferyjne i interfejsy)

## USB (Universal Serial Bus)

Последовательный, hot-plug, до 127 устройств на контроллер, подаёт питание.

| Версия | Название | Скорость | Ток |
|---|---|---|---|
| USB 1.0 | Low Speed | 1,5 Mb/s | 100/500 mA |
| USB 1.1 | Full Speed | 12 Mb/s | 500 mA |
| **USB 2.0** | High Speed | **480 Mb/s** | 500 mA |
| **USB 3.0 = 3.1 Gen 1 = 3.2 Gen 1** | SuperSpeed | **5 Gb/s** | 900 mA |
| **USB 3.1 Gen 2** = 3.2 Gen 2 | SuperSpeed+ | **10 Gb/s** | |
| USB 3.2 Gen 2x2 | | 20 Gb/s | |
| USB4 | | 40 Gb/s | USB PD до 100/240 W |

- Разъёмы: A, B, **Mini-USB** (старые сканеры, фотоаппараты), Micro-USB, **USB-C** (симметричный). Порт USB 3.x обычно **синий**.
- Внешний диск 3,5" 5 TB: из предложенных интерфейсов быстрее всего **USB 3.1 Gen 2** (10 Gb/s).
- Длина кабеля USB 2.0 — до 5 м.
- Принтер с LPT к ПК только с USB → **adapter USB na LPT**.
- Посчитать порты на панели: USB 2.0 — чёрные/белые, USB 3.0 — синие; плюс разъёмы на плате (header = обычно 2 порта).

## Другие последовательные/параллельные интерфейсы

| Интерфейс | Польск./англ. | Характеристика |
|---|---|---|
| **IEEE 1394** | FireWire (Apple), **i.Link** (Sony) | проводной, 1394a 400 Mb/s, 1394b 800 Mb/s; цифровые видеокамеры; **прямое соединение двух устройств** |
| **Thunderbolt** | символ **молнии** | **szeregowy, dwukanałowy, dwukierunkowy, przewodowy**; TB1 10 Gb/s, TB2 20, TB3/TB4 40 Gb/s (USB-C); PCIe + DisplayPort |
| **LPT / Centronics / IEEE 1284** | port równoległy | **8 линий данных, 4 управления, 5 статуса, без питания**; на ПК **DB-25**, на принтере Centronics-36; режимы SPP, EPP, **ECP (до 2,4 MB/s, DMA шины ISA — сканеры, МФУ)** |
| **RS-232 / COM** | port szeregowy | **DB-9 (DE-9)**; кассовый аппарат DB-9M ↔ ПК (DB-9M) → кабель **DB-9F/F** |
| PS/2 | mini-DIN 6 | фиолетовый — клавиатура, зелёный — мышь |
| **IrDA** | podczerwień | **беспроводная оптическая** связь, ~1 м, прямая видимость |
| **Bluetooth** | | **радио 2,4 GHz ISM**; классы: 1 — 100 м, **2 — 10 м**, 3 — 1 м; нужно **parowanie (pairing)** |
| Wi-Fi | IEEE 802.11 | 2,4 / 5 GHz |
| PCMCIA / ExpressCard | | карты расширения ноутбука |

- **AGP — внутренний** интерфейс (не внешний). PCI — параллельная шина.
- Проектор, монитор **нельзя** подключить через **SATA**.

## Видеоинтерфейсы

| Разъём | Сигнал | Примечание |
|---|---|---|
| **VGA = D-Sub = DE-15F** | **аналоговый** | 15 pin в 3 ряда; ТВ/проектор/интерактивная доска только с аналоговым входом |
| **DVI-A** | только аналог | |
| **DVI-D** | только цифра | Single / **Dual Link** (больше пинов, выше разрешение) |
| **DVI-I** | **цифра + аналог** | можно переходником на VGA |
| **HDMI** | цифра **видео + аудио**, без потерь, HDCP | A (стандарт), C (mini), D (micro); 1.4: 4K@30, 2.0: 4K@60 (18 Gb/s), 2.1: 48 Gb/s |
| **DisplayPort (DP)** | цифра, видео + аудио | разъём с **одним скошенным углом**, защёлка; mini-DP; DP++ → пассивный переходник на HDMI/DVI |
| S-Video, композит (RCA), компонентный | аналог | ТВ-оборудование |

- **RAMDAC** на видеокарте преобразует цифровой сигнал в аналоговый для монитора VGA.
- Золочение контактов HDMI по CKE — **маркетинг**: «stworzenie produktu o charakterze ekskluzywnym…» (на передачу не влияет).
- Ошибка «нет драйвера/разрешение 800×600» → **установить драйвер видеокарты**.
- Full HD = **1920 × 1080**; HD 1280×720; QHD 2560×1440; 4K UHD 3840×2160.

## Мониторы (monitory)

### Типы матриц LCD

| Матрица | Плюсы | Минусы |
|---|---|---|
| **TN** | быстрая, дешёвая | **самые узкие углы обзора**, хуже цвета |
| **IPS** (S-IPS) | **лучшие цвета и самые широкие углы** — для графики | дороже, дольше отклик |
| VA (MVA, PVA) | высокий контраст | |
| OLED | истинный чёрный, без подсветки | выгорание |

- Подсветка: CCFL (лампы + **inwerter**) или LED.
- **Плазма**: ячейки с газом; электроды — адресующие (adresujące) и отображающие.
- CRT — электронно-лучевая трубка; с ней работало **pióro świetlne** (light pen, светочувствительный наконечник).

### Параметры

- **Plamka (dot pitch)** = **расстояние от начала одного пикселя до начала следующего** (мм).
- **Częstotliwość odświeżania**: 85 раз в секунду = 85 Hz = **0,085 kHz**.
- Czas reakcji (ms), kontrast, jasność (cd/m²), kąty widzenia, rozdzielczość natywna, proporcje 16:9.
- **ISO 13406-2 — классы дефектов пикселей** (на 1 млн пикселей), класс II: тип 1 (всегда светится) — 2, тип 2 (всегда тёмный) — 2, **тип 3 (субпиксель) — 5**.
  - Расчёт: `dopuszczalne = limit × (liczba pikseli / 1 000 000)`, округлить вниз.
  - Пример 1400×1050 = 1 470 000 px → 5 × 1,47 = 7,35 → **7 пикселей** типа 3.

## Проекторы (projektory)

- Технологии: **LCD** (3 матрицы), **DLP** (микрозеркала DMD + цветовое колесо), LCoS.
- Яркость — **ANSI lumen**; расходник — **lampa projekcyjna**.
- **Korekcja trapezowa (keystone)** — кнопки на корпусе для исправления искажённой (трапециевидной) картинки.
- Подключение: VGA (DE-15F), HDMI, DP; **не SATA**.

## Устройства ввода (urządzenia wejściowe)

- **Клавиатура**: мембранная (**przełącznik membranowy** — частая причина отказа), механическая. Контроллер шлёт **make code** (нажатие) и **break code (zwolnienie klawisza)**. Залита сладким напитком → отключить, **промыть изопропиловым спиртом**, сушить 24 ч.
- **Мышь оптическая**: LED → поверхность → сенсор CMOS → DSP. Лазерная — лазерный диод. Беспроводная «прыгает» → **садится батарейка** (замена батареи — эксплуатация беспроводной мыши). Проводная реагирует только в определённом положении → **кабель**.
- **Touchpad** — **детекция изменения ёмкости (pojemność elektryczna)**.
- **Trackpoint** — реагирует на **силу и направление нажатия**.
- **Ekran dotykowy** — urządzenie wskazujące; резистивный (давление) / ёмкостный (палец).
- Tablet graficzny: перо не позиционирует курсор → **неверный драйвер**.
- Ctrl + колесо мыши — масштаб иконок на рабочем столе.
- Сканер биометрический: отпечаток, радужка, **rysy twarzy**.
- **Karta telewizyjna (TV tuner)** — приём, обработка и воспроизведение ТВ-сигнала.

## Звук

- Динамики: **moc (W)** («10 W»), pasmo przenoszenia **20 Hz – 20 kHz**, **efektywność (skuteczność) в dB**.
- Звуковая карта: DAC (воспроизведение), ADC (запись), **S/PDIF** — цифровой аудиовыход.

## ИБП (zasilacz awaryjny, UPS)

| Тип | Польск. | Работа | IEC 62040-3 |
|---|---|---|---|
| **Offline / Standby** | | при сбое переключается на батарею (время переключения) | VFD |
| **Line-interactive** | | + **AVR** (стабилизация напряжения автотрансформатором) | VI |
| **Online (double conversion)** | podwójna konwersja | инвертор работает постоянно, нулевое время переключения — серверы | VFI |

- Мощность: VA (pozorna) и W (czynna); `P[W] = S[VA] × cos φ (PF)`. UPS 1000 VA при PF 0,6 → 600 W.
- Подбор: суммарная мощность нагрузки + запас; время работы зависит от ёмкости аккумулятора (Ah) и нагрузки.
- UPS перешёл в **tryb awaryjny (bateryjny)** → **авария системы электропитания**.
- Listwa przeciwprzepięciowa — защита от перенапряжений; для LAN — **ochronnik przepięciowy / urządzenie przeciwprzepięciowe** на кабель.
- Расходник UPS — аккумулятор (замена каждые ~3–5 лет).

## Прочее

- **PoE** (Power over Ethernet): IEEE **802.3af** (15,4 W), 802.3at (30 W); **инжектор PoE** подаёт питание по U/UTP.
- **KVM switch** — один комплект клавиатура/монитор/мышь на несколько ПК.
- Внешний диск к ноутбуку — **USB** (eSATA, Thunderbolt).
- Сканер к ПК — USB (часто **Mini USB**); стандарт сканер ↔ программа — **TWAIN** (см. printers.md).

## Частые ловушки на экзамене

- **DVI-I** = цифра **и** аналог; **DVI-A** — только аналог; DVI-D — только цифра.
- **DE-15F = D-Sub = VGA** (аналог); HDMI — цифровое аудио+видео без потерь.
- Символ **молнии** = **Thunderbolt**: последовательный, двухканальный, двунаправленный, проводной.
- **i.Link = IEEE 1394 = FireWire**; IrDA — **инфракрасный (оптический)**, Bluetooth — радио 2,4 GHz.
- Bluetooth **класс 2 = 10 м**; LPT = **DB-25**, параллельный, 8 линий данных, без питания; ECP — до 2,4 MB/s.
- **TN** — самые узкие углы обзора; **IPS** — лучшая цветопередача и широкие углы.
- **85 Hz = 0,085 kHz**; plamka — расстояние от **начала** пикселя до **начала** следующего.
- **BREAK code = отпускание клавиши**; touchpad — изменение ёмкости.
- UPS в режиме аварийном = проблема **питания**, а не сети.
- USB 3.0 = 3.1 Gen 1 = **5 Gb/s**; USB 3.1 Gen 2 = **10 Gb/s**; USB 2.0 = 480 Mb/s.
