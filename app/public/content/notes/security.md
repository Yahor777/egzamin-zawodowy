# Безопасность систем и данных (Bezpieczeństwo systemów komputerowych)

## Вредоносное ПО (złośliwe oprogramowanie, malware)

| Тип | Польск. | Суть |
|---|---|---|
| Вирус | **wirus** | дописывается к файлам/программам, нужен носитель и запуск; может заполнять диск |
| Червь | **robak (worm)** | **самостоятельно распространяется по сети**, без носителя |
| Троян | **koń trojański (trojan)** | маскируется под полезную программу; **открывает порт / backdoor** для атакующего |
| Бэкдор | backdoor | скрытый вход в систему |
| Руткит | rootkit | скрывает присутствие вредоносного ПО (в ядре) |
| Кейлоггер | **keylogger** | **регистрирует нажатые клавиши** |
| Шпион | **spyware** | без ведома пользователя собирает и отправляет данные (карты, пароли) → **antyspyware** (Spybot Search & Destroy) |
| Рекламное | adware | показывает рекламу |
| Вымогатель | **ransomware** | **шифрует данные и требует выкуп** |
| **Wabbit** | | **резидентный**, выполняет операцию, **размножается локально, не по сети** (fork bomb) |
| Бот / зомби | botnet | заражённые устройства под удалённым управлением (DDoS) |
| Dialer, scareware, hoax | | дозвонщик, запугивание, ложная тревога |
| Exploit | | использует **lukę** в ПО |

- **Не** malware: CAM (computer aided manufacturing) и прочие легальные программы.
- Неконтролируемое заполнение диска — признак **вируса**.

## Атаки (ataki)

| Атака | Суть / защита |
|---|---|
| **DoS / DDoS** | перегрузка сервера/приложения запросами; DDoS — **с множества адресов** (ботнет IoT: камеры, датчики — атака на DNS Dyn; тысячи DNS-запросов в секунду) |
| **Smurf** | ICMP echo на broadcast с подменённым адресом жертвы → **zapora sieciowa (firewall)** |
| SYN flood, ping of death, flood ping | переполнение ресурсов |
| **Spoofing** | **подмена (podszywanie się)** IP, MAC, ARP, DNS |
| **Sniffing** (**nasłuchiwanie**) | **перехват пакетов** в сети (sniffer, Wireshark) |
| Man-in-the-Middle | посредник между сторонами |
| **Phishing** | **выманивание личных данных** поддельными сообщениями «от банка/учреждения» |
| Pharming | подмена DNS → поддельный сайт |
| Vishing / smishing | по телефону / SMS |
| Brute force / słownikowy | перебор паролей → блокировка учётки, сложные пароли |
| SQL injection, XSS | атаки на веб-приложения |
| Session hijacking | кража сессии |
| Zero-day | неизвестная уязвимость |

### Социальная инженерия (socjotechnika)

- Использование доверия/невнимательности: pretexting (выдуманный повод), baiting (флешка-приманка), tailgating (проход следом), **shoulder surfing** (подглядывание).
- Защита: обучение пользователей, процедуры, не сообщать паролей, проверять отправителя и адрес (HTTPS, сертификат), **не пользоваться устаревшими браузерами**.

## Межсетевой экран (zapora sieciowa, firewall)

- **Основная защита сети от атак извне**, блокирует несанкционированный доступ к LAN; фильтрует по IP, портам, протоколам.
- Виды: filtr pakietów, **stateful inspection**, proxy/aplikacyjny, NGFW/**UTM**; **programowy** (Zapora Windows, `wf.msc`, iptables/ufw) и **sprzętowy** (отдельное устройство; доп. функции — VPN-шифрование, автообновления).
- **Пакеты Internet Security** = антивирус **+ zapora sieciowa** (+ antyspam, kontrola rodzicielska).
- **DMZ** — зона для публичных серверов; **NAT** — трансляция адресов (скрывает внутреннюю сеть); **IDS/IPS** — обнаружение/предотвращение вторжений.

### Порты, которые блокируют/открывают

| Порт | Служба |
|---|---|
| **20, 21** | **FTP** (данные, управление) |
| 22 | **SSH**, SFTP |
| 23 | **Telnet** (без шифрования) |
| 25 | SMTP |
| 53 | DNS (UDP/TCP) |
| 67/68 | DHCP |
| 80 / **443** | HTTP / **HTTPS** |
| 110 / 995 | POP3 / POP3S |
| 143 / 993 | IMAP / IMAPS |
| 161/162 | SNMP (162 — trap) |
| 445 | SMB |
| **3389** | **RDP** |

## Шифрование (szyfrowanie)

| Вид | Алгоритмы | Особенность |
|---|---|---|
| **Симметричное** | **AES**, DES, 3DES, Blowfish, RC4 | один ключ для шифрования и расшифровки; быстро |
| Асимметричное | **RSA**, ECC, Diffie-Hellman | открытый + закрытый ключ; подпись, обмен ключами |
| Хэш | MD5, SHA-1, **SHA-256** | целостность, хранение паролей (необратимо) |

- **Podpis cyfrowy**, **certyfikat** (PKI, CA). Сообщение браузера о небезопасном подключении → **проблема проверки сертификата**.
- Протоколы с шифрованием: **SSH** (шифрованный терминал), **HTTPS** (TLS, 443), **SFTP**, **FTPS** («S» = szyfrowanie SSL/TLS), IMAPS, SMTPS. Без шифрования: **Telnet**, HTTP, FTP.
- **VPN** — **tunelowanie**: зашифрованное соединение через Интернет (PPTP, L2TP/IPsec, SSTP, OpenVPN, IKEv2); site-to-site / remote access.
- Windows: **EFS** (шифрование файлов на NTFS, команда **`cipher`**), **BitLocker** (весь диск, TPM), BitLocker To Go (флешки).

## Беспроводные сети (Wi-Fi)

| Стандарт | Шифрование | Оценка |
|---|---|---|
| **WEP** | RC4 | **самый слабый**, легко взломать |
| WPA | TKIP | устарел |
| **WPA2** | **AES-CCMP** | надёжный (до 2018 лучший) |
| **WPA3** | SAE | **новейший** |

- Personal (**PSK**, общий пароль — дома) vs **Enterprise** (802.1X + **RADIUS** — удалённая аутентификация пользователей).
- Доп. меры: **filtrowanie adresów MAC** (только выбранные устройства), **wyłączenie rozgłaszania SSID**, смена логина/пароля админа роутера (**первым делом**), отключить WPS, обновить прошивку, уменьшить мощность.
- Сеть без шифрования видна в сканере (Acrylic Wi-Fi) как «Open».

## Аутентификация (uwierzytelnianie)

- Факторы: **что знаешь** (hasło, PIN), **что имеешь** (token, karta, telefon), **кто ты** (biometria: odcisk palca, tęczówka, rysy twarzy).
- **MFA / 2FA** — минимум два разных фактора.
- Протоколы/службы: **Kerberos** (AD), NTLM, **RADIUS**, TACACS+, LDAP.
- Хорошие пароли: длина ≥ 12, разные классы знаков, без слов из словаря, без повторного использования; менеджер паролей.
- Политики Windows: `net accounts`, GPO (сложность — мин. 6 знаков, история, блокировка). Linux: `passwd`, `usermod -L`, `chage`.
- **UAC**, принцип минимальных привилегий (работать на koncie z ograniczeniami).

## Резервное копирование (kopie zapasowe)

| Тип | Что копирует | Бит архива | Восстановление |
|---|---|---|---|
| **Pełna (full)** | **все выбранные данные** независимо от прошлых копий | **сбрасывает** | 1 копия |
| **Przyrostowa (incremental)** | изменения **с последней любой копии** (pełnej lub przyrostowej) | **сбрасывает** | pełna + **все** przyrostowe по порядку |
| **Różnicowa (differential)** | изменения **с последней pełnej** | **не сбрасывает** | pełna + **последняя** różnicowa |
| Kopiująca (copy) | все, как pełna | не сбрасывает | |

Пример (pełna в пн, изменения по 10 GB в день, отказ в чт перед копией):
- przyrostowe: вт 10 GB, ср 10 GB → восстановление = pełna(пн) + вт + ср; меньше места, дольше восстановление.
- różnicowe: вт 10 GB, ср 20 GB → восстановление = pełna(пн) + ср; больше места, быстрее восстановление.

### Схемы ротации

- **Dziadek–Ojciec–Syn (GFS)**: Syn — ежедневно, Ojciec — еженедельно, **Dziadek — в конце месяца**.
- **Wieża Hanoi** — ротация носителей по схеме головоломки (носитель A каждые 2 дня, B каждые 4, C каждые 8…).
- **3-2-1**: 3 копии, 2 разных носителя, 1 вне офиса.
- Филиалы в удалённых городах → **backup w chmurze firmowej**.
- Носители: диски, ленты (LTO), NAS, облако; **DVD-ROM нельзя** (только чтение).
- **RAID — не резервная копия**. Образ диска (Acronis True Image, `dd`) — защита от серьёзной аварии.
- Удаление данных безвозвратно — **zerowanie / nadpisywanie**; formatowanie быстрое — данные можно восстановить.

## Защита электропитания

- **UPS** — работа при пропадании питания; offline / line-interactive / **online (VFI)** для серверов.
- **Listwa / ochronnik przeciwprzepięciowy** — защита от перенапряжений (гроза); для LAN — ochronnik na linię sieciową.
- Знак **CE** — изделие соответствует требованиям ЕС по безопасности, здоровью, окружающей среде (обязателен в Польше/ЕС).

## Антивирус и обновления

- Устанавливать **сразу после установки ОС**, затем **регулярно обновлять программу и базы сигнатур** и **сканировать систему**.
- Методы: сигнатуры, эвристика, песочница; **skanowanie w czasie rzeczywistym (rezydentne)**, kwarantanna.
- Порядок защиты подключённого к Интернету ПК: **antywirus + aktualizacja baz + firewall + aktualizacja systemu**.
- **Ochrona przed ransomware** — защита от угроз, **шифрующих данные и требующих выкуп** (защищённые папки, Kontrolowany dostęp do folderów).
- Windows: **Windows Defender**, **SmartScreen** (неизвестные приложения из сети), Zapora, Windows Update.
- **Aktualizacje systemu** — прежде всего **латают уязвимости (luki)**, повышающие риск; важные обновления: безопасность, приватность, надёжность.
- Хорошо: шпион обнаружен → после очистки установить **antyspyware**.
- Фрагментация диска — **не** механизм безопасности.

## Сетевые устройства безопасности

- **Firewall sprzętowy/UTM** — защита от атак + VPN, фильтрация контента.
- Mostek (bridge, L2) — сегментация и фильтрация кадров; przełącznik — делит домены коллизий; ruter — домены широковещания.
- SNMP — мониторинг устройств; RMON — расширенный мониторинг в коммутаторе.

## Частые ловушки на экзамене

- **Robak** распространяется по сети сам; **trojan** открывает порт; **wabbit** размножается локально, не по сети.
- **Podszywanie się** = **spoofing**; **przechwytywanie pakietów** = **nasłuchiwanie (sniffing)**; выманивание данных письмами = **phishing**.
- **Smurf** — защищает **firewall**; DDoS — множество адресов (IoT-ботнет).
- **AES — симметричный**; RSA — асимметричный; SSH — шифрованный терминал, **Telnet — без шифрования**.
- **WEP** — самый слабый; **WPA3** — новейший; в старых вопросах «najwyższy poziom» — **WPA2**.
- Архивация всех данных независимо от прошлых копий → **pełna**; дедушка = **месяц**.
- FTP блокируется портами **20 и 21**; RDP = **3389**; HTTPS = **443**.
- Internet Security отличается от AV наличием **zapory sieciowej**.
- Антивирус — **сразу после ОС**, затем обновления баз; обновления ОС — **против luk**.
