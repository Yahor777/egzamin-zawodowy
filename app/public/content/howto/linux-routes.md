# Linux: статические маршруты

Статический маршрут отвечает на вопрос: **какую сеть искать через какой шлюз**. Без него система знает только свои подключённые сети и шлюз по умолчанию.

## Быстрые команды

```bash
ip r                         # то же, что ip route show: показать таблицу маршрутов
ip route show
route -n                     # старый вывод net-tools, только числа, без имён

sudo ip route add 192.168.10.0/24 via 192.168.0.1
sudo ip route del 192.168.10.0/24 via 192.168.0.1
sudo ip route replace 192.168.10.0/24 via 192.168.0.1
```

Формат почти всегда одинаковый:

```text
ip route add СЕТЬ/МАСКА via ШЛЮЗ [dev ИНТЕРФЕЙС]
```

Пример строки таблицы:

```text
192.168.10.0/24 via 192.168.0.1 dev enp0s3
```

Она означает: сеть `192.168.10.0/24` доступна через шлюз `192.168.0.1`, пакет уходит через интерфейс `enp0s3`.

## Важно: runtime против netplan

- `sudo ip route add ...` работает сразу, но это **временный** маршрут. После перезагрузки он пропадает.
- Маршрут в `/etc/netplan/50-cloud-init.yaml` применяется после `sudo netplan apply` и возвращается после перезагрузки.

## Постоянный маршрут в netplan

```yaml
network:
  version: 2
  ethernets:
    enp0s3:
      addresses: [192.168.0.10/24]
      routes:
        - to: default
          via: 192.168.0.1
        - to: 172.16.0.0/16
          via: 192.168.0.1
```

После правки:

```bash
sudo netplan apply
ip r
```

Старый вариант `gateway4: 192.168.0.1` ещё встречается, но считается устаревшим; в новых конфигурациях используй `routes:`.

## Частые ошибки

- Ошибка `route must include both a 'to' and 'via' IP`: у маршрута нет сети `to` или шлюза `via`.
- Ошибка `invalid IPv4 address`: в адресе октет больше 255 или опечатка.
- `Error: Nexthop has invalid gateway`: шлюз не находится ни в одной подключённой сети.
- Маршрут добавлен через `ip route add`, но после перезагрузки исчез: он не был записан в netplan.

## Как читать `route -n`

```text
Kernel IP routing table
Destination     Gateway         Genmask         Flags Metric Ref    Use Iface
0.0.0.0         192.168.0.1     0.0.0.0         UG    0      0        0 enp0s3
172.16.0.0      192.168.0.1     255.255.0.0     UG    0      0        0 enp0s3
```

`Destination 0.0.0.0` — маршрут по умолчанию. `Genmask` — маска сети. `UG` означает, что маршрут активен и ведёт через шлюз.
