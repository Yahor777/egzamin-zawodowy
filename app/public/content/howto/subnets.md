# Подсети: быстро и без ошибок

## Главная таблица (последний октет)

| префикс | маска (последний октет) | размер блока | хостов |
|---|---|---|---|
| /24 | 0 | 256 | 254 |
| /25 | 128 | 128 | 126 |
| /26 | 192 | 64 | 62 |
| /27 | 224 | 32 | 30 |
| /28 | 240 | 16 | 14 |
| /29 | 248 | 8 | 6 |
| /30 | 252 | 4 | 2 |

Размер блока = 256 − последний октет маски.

## Алгоритм

1. Размер блока **B** по префиксу.
2. Подсети начинаются с 0, B, 2B, 3B…
3. Для подсети, начинающейся с **N**:
   - адрес сети (*adres sieci*) = N;
   - первый хост (*pierwszy adres hosta*) = N + 1;
   - broadcast (*adres rozgłoszeniowy*) = N + B − 1;
   - последний хост (*ostatni adres hosta*) = N + B − 2.

## Пример

`192.168.10.77/27` → B = 32 → подсети 0, 32, **64**, 96… → 77 лежит в подсети **64**.
Сеть `192.168.10.64`, хосты `.65`–`.94`, broadcast `.95`, маска `255.255.255.224`.

«**Druga podsieć** /26 сети 10.0.0.0/24» → подсети 0, 64, 128, 192 → вторая = `10.0.0.64/26`, первый хост `10.0.0.65`, последний `10.0.0.126`.

## Ловушки

- «Первая подсеть» — та, что начинается с 0.
- Адрес сети и broadcast **нельзя** давать хостам.
- Шлюз обязан быть в той же подсети, что и хост.
- /30 — канал точка-точка: ровно 2 адреса (часто WAN роутера в листах CKE).

Потренируйся: Теория → Задачи на вычисления → Подсети.
