# Как распознать железо, порты и маркировку (identyfikacja sprzętu)

Эта страница — для ситуации: в листе CKE написано `DDR4-3200`, `SATA III`, `PCIe x16`, `U/UTP kat. 6`, а ты не понимаешь, что это и где искать. Сначала читай маркировку, потом заполняй таблицу.

## Как читать строку из cennika

```
Pamięć RAM Kingston 16GB, 1x16GB, 3200MHz, DDR4
│         │   │        │     │       │        └─ тип памяти: DDR4
│         │   │        │     │       └─ скорость модуля
│         │   │        │     └─ один модуль по 16 GB
│         │   │        └─ общий объём комплекта
│         │   └─ производитель
│         └─ вид компонента: оперативная память
└─ pozycja w cenniku
```

В скобках часто пишут короче: `(DIMM DDR4, 2666 MHz)` или `DDR4-2666 (PC4-21333)`. Это тот же параметр, просто другой формат.

## Маркировка → что значит → как отвечать в задании

| Маркировка в листе | Что значит простыми словами | Как отвечать в задании |
|---|---|---|
| `DDR3`, `DDR4`, `DDR5` | поколение оперативной памяти; они **не взаимозаменяемы**, вырез на модуле в другом месте | в «typ pamięci» пиши именно `DDR4`; при подборе платы проверяй, что она поддерживает тот же DDR |
| `DIMM` | длинный модуль RAM для настольного ПК | не путать с `SO-DIMM` для ноутбука |
| `SO-DIMM` | короткий модуль RAM для ноутбука | в стационарный DIMM-слот не встанет |
| `8 GB (1x8GB)` | один модуль 8 GB | `liczba modułów: 1`, объём 8 GB |
| `16 GB (2x8GB)` | два модуля по 8 GB | dual channel обычно возможен, если воткнуть в правильные слоты |
| `3200 MHz`, `3200 MT/s` | эффективная скорость памяти | в CPU-Z `DRAM Frequency` около 1600 MHz — умножай на 2 |
| `DDR4-3200` | DDR4 со скоростью 3200 MT/s | выбирай плату/процессор с поддержкой DDR4 и этой частоты |
| `PC4-25600` | другое обозначение DDR4-3200: 25600 MB/s | `PC4` = DDR4; не DDR5 |
| `PC3-12800` | DDR3-1600 | `PC3` = DDR3 |
| `CL16` | задержка CAS latency, чем меньше, тем быстрее реакция | обычно достаточно переписать `CL16`; не путать с частотой |
| `1,2 V` | напряжение памяти | если вопрос про совместимость, сверяй с типом DDR |
| `SATA III` | разъём/интерфейс диска 6 Gb/s | HDD/SSD 2,5" и 3,5" подключаются кабелем SATA data + питанием SATA |
| `SATA II` | старый SATA 3 Gb/s | совместим с SATA III, но медленнее |
| `HDD` | механический диск с пластинами | в параметрах ищи `5400/7200 obr./min`, объём, SATA |
| `SSD` | твердотельный диск без движущихся частей | быстрее HDD; бывает SATA или M.2/NVMe |
| `M.2` | маленький разъём/формат диска на плате | внимание: M.2 бывает SATA и NVMe — читай следующее слово |
| `M.2 PCIe NVMe` | быстрый SSD по линиям PCIe | в ответах пиши интерфейс `NVMe/PCIe`, не SATA |
| `NVMe 3.0 x4` | протокол NVMe, PCIe поколение 3, 4 линии | чем больше `x`, тем шире канал |
| `PCIe x16` | длинный слот/интерфейс с 16 линиями; основной для видеокарты | видеокарту ставь в первый длинный PCIe x16 |
| `PCIe x1` | короткий слот для сетевой/звуковой карты | карту x1 можно ставить и в более длинный слот |
| `PCI-E 8-pin (6+2)` | дополнительное питание видеокарты | не путать с `EPS 8-pin` для процессора |
| `ATX 24-pin (20+4)` | главный кабель питания материнской платы | вставляется в самый широкий разъём платы |
| `EPS 12V 4/8-pin` | питание процессора около CPU-сокета | не втыкай вместо PCIe 6+2 |
| `Molex` | старый разъём питания 4-pin | в новых сборках редко, бывает для переходников/вентиляторов |
| `USB 2.0` | медленный USB 480 Mb/s, часто чёрный | клавиатура/мышь — нормально |
| `USB 3.0 / 3.1 Gen 1 / 3.2 Gen 1` | USB 5 Gb/s, часто синий | это разные названия похожей скорости |
| `USB 3.1 Gen 2 / 3.2 Gen 2` | USB 10 Gb/s | быстрее Gen 1 |
| `USB-C` | форма разъёма, **не гарантия скорости** | смотри рядом `Gen 1/Gen 2/Thunderbolt` |
| `Thunderbolt` | быстрый универсальный порт, часто USB-C | не то же самое, что обычный USB-C |
| `RJ45` | гнездо сети Ethernet | к нему подходит вилка `8P8C`; в быту оба называют RJ45 |
| `8P8C` | вилка с 8 контактами для витой пары | для обжима сетевого кабеля |
| `U/UTP` | витая пара без экрана | обычный сетевой кабель на экзамене |
| `kat. 5e` | категория кабеля до 1 Gb/s | подходит для Gigabit Ethernet |
| `kat. 6` | категория выше, лучше для 1/10 Gb/s | если требуют kat. 6, не бери kat. 5e |
| `linka` | многожильный гибкий кабель | используется для patchcord |
| `drut` | одножильный жёсткий кабель | используется для Keystone и patch panel |
| `T568A`, `T568B` | два стандарта порядка цветов | если написано B — на модуле смотри строку/столбец `B`; `T586B` в листе — опечатка, читай как `T568B` |
| `HDMI` | видео+звук в монитор/ТВ | цифровой выход видеокарты/платы |
| `DisplayPort`, `DP` | цифровой видеовыход, часто лучше для мониторов | не путать с USB-C, хотя бывает DP через USB-C |
| `DVI-D` | старый цифровой видеовыход | без звука |
| `VGA` | старый аналоговый синий видеоразъём | самое низкое качество |
| `PS/2` | круглый разъём клавиатуры/мыши | фиолетовый — клавиатура, зелёный — мышь |
| `s-1700`, `socket 1700`, `LGA1700` | сокет процессора Intel | процессор и плата должны иметь одинаковый socket |
| `AM4`, `s-AM4` | сокет AMD Ryzen | AM4 не совместим с Intel LGA |
| `ATX`, `micro-ATX`, `Mini-ITX` | размеры платы/корпуса | корпус ATX обычно принимает micro-ATX и ITX; корпус ITX — только маленькую плату |
| `80 PLUS Bronze` | сертификат КПД блока питания | не мощность; мощность смотри в ваттах `600 W` |
| `TDP 95 W`, `pobór mocy` | сколько тепла/энергии потребляет компонент | для расчёта БП суммируй мощности и добавляй запас |

## Как узнавать компоненты глазами

| Компонент | Как выглядит | Что проверить перед установкой |
|---|---|---|
| Płyta główna | большая плата со слотами RAM, PCIe, SATA | socket процессора, тип DDR, формат ATX/mATX/ITX |
| Procesor CPU | квадратная металлическая крышка, без вентилятора снизу контакты/ножки | socket, направляющие метки, не трогать контакты |
| Pamięć RAM | длинная узкая планка с чипами | DDR3/4/5, вырез-klucz, количество модулей |
| Karta graficzna | большая карта с вентилятором и разъёмами HDMI/DP | PCIe x16, дополнительное питание 6/8-pin |
| Karta sieciowa | маленькая карта с RJ45 или антеннами | PCIe x1 обычно; драйвер после запуска |
| HDD 3,5" | тяжёлая металлическая коробка | SATA data + SATA power |
| SSD 2,5" | тонкая лёгкая коробка | те же SATA-кабели, крепление в отсек 2,5" |
| SSD M.2 | маленькая планка, как жвачка | ключ/тип SATA или NVMe, винт фиксации |
| Zasilacz | металлический блок с жгутом кабелей | мощность W, ATX 24-pin, EPS CPU, PCIe GPU, SATA power |
| Obudowa | корпус | поддержка размера платы, места для дисков, длина видеокарты |

## Порты на задней панели: что чем является

- `PS/2` — круглый старый разъём клавиатуры/мыши.
- `USB 2.0/3.x` — прямоугольные USB; синий часто USB 3.x.
- `USB-C` — маленький симметричный овал; скорость зависит от спецификации.
- `HDMI`, `DisplayPort`, `DVI`, `VGA` — видеовыходы. Если есть дискретная видеокарта, монитор обычно подключают **к видеокарте**, а не к плате.
- `RJ45` — сетевое гнездо с двумя лампочками.
- `Audio` — круглые 3,5 мм гнёзда: зелёное — колонки/наушники, розовое — микрофон.
- `S/PDIF` — цифровой звук, часто оптический.

## Где смотреть параметры в системе

Правило экзамена: если лист требует скриншот, значение в таблице должно быть видно на скриншоте. Нет значения — пиши `brak danych`, а не выдумывай.

| Параметр | Windows | Linux |
|---|---|---|
| процессор: model, rdzenie, procesory logiczne | `Menedżer zadań → Wydajność → Procesor CPU` или `msinfo32` | `lscpu` |
| базовая частота CPU | `Menedżer zadań → Szybkość podstawowa` | `sudo dmidecode -t processor` |
| RAM: rozmiar, szybkość, gniazda | `Menedżer zadań → Pamięć` | `free -h`, `sudo dmidecode -t memory` |
| płyta główna, BIOS | `msinfo32` | `sudo dmidecode -t baseboard`, `-t bios` |
| karta graficzna, VRAM | `dxdiag → Ekran` | `lspci \| grep -i vga` |
| dysk: model, pojemność, typ | `Menedżer zadań → Dysk`, `diskmgmt.msc` | `lsblk -d -o NAME,MODEL,SIZE,ROTA` |
| karta sieciowa, MAC | `ipconfig /all` | `ip link` |
| wersja systemu | `winver`, `msinfo32` | `cat /etc/os-release`, `uname -r` |

Ловушка: `free -h` и Windows иногда показывают GiB, поэтому 16 GB может выглядеть как 15,6 GiB. Переписывай значение как на экране и не «округляй от себя», если в таблице просят точный параметр.

## Как отвечать на «spełnia / nie spełnia wymagań»

1. Выпиши каждое требование из листа.
2. Сравни его с параметром из системы/наклейки.
3. Если **все** требования выполнены — `spełnia wymagania`.
4. Если хоть одно не выполнено — `nie spełnia wymagań` и коротко почему.

Пример записи:

```
Procesor: 6 rdzeni, 3,6 GHz — spełnia (wymagane min. 4 rdzenie, 3,0 GHz).
RAM: 8 GB — nie spełnia (wymagane 16 GB).
Wniosek: komputer nie spełnia wymagań, konieczna rozbudowa RAM do 16 GB.
```

Сравнивай одинаковые величины: базовую частоту с базовой, GB с GB, тип DDR с типом DDR. `Turbo` — не базовая частота.
