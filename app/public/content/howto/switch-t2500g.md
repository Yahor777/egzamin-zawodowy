# Свитч TP-Link JetStream T2500G-10TS (коммутатор из школьной лаборатории ZSE)

Управляемый L2-коммутатор, на котором идут занятия PSK (уроки 1–3 и 8): 8 портов 1 Gb/s + 2 SFP (в меню это порты 9 и 10). Интерфейс: тёмная шапка, слева светлое меню (System, Switching, **VLAN**, Spanning Tree, … Save Config, Logout), сверху тёмно-зелёные вкладки страницы. В тренажёре включается на странице *Настройки → Оборудование* («Как в моей школе») и в заданиях со стендом.

С завода: адрес **`192.168.0.1`**, маска `255.255.255.0`, логин и пароль **`admin` / `admin`**. **DHCP-сервера у свитча нет** — ПК нужен статический адрес из той же сети: `192.168.0.10+x`, маска `255.255.255.0`, остальное пустое. Управление живёт в **Management VLAN** (с завода — VLAN 1).

## Урок 1 — IP-адрес свитча: System → System Info → System IP

1. ПК: статический `192.168.0.10+x / 255.255.255.0`; в браузере `192.168.0.1`, *User Name* / *Password*: `admin` / `admin` → **Login**.
2. *System* → *System Info* → вкладка **System IP**: *IP Address Mode* **Static IP**, **IP Address** (например `192.168.1.201`), **Subnet Mask** `255.255.255.0`, при необходимости *Default Gateway* → **Apply**.
3. Поставь ПК обратно на «Uzyskaj adres IP automatycznie» (если новая сеть — сеть роутера с DHCP) и открой **новый адрес** свитча.

## Режимы портов — VLAN → 802.1Q VLAN → Port Config

| Link Type | когда | что делает |
|---|---|---|
| **ACCESS** | компьютер, принтер | порт — Untagged участник **одного** VLAN; при добавлении в VLAN его **PVID меняется сам**, из остальных VLAN (в т. ч. из VLAN 1) он выходит |
| **GENERAL** | порт с Интернетом, особые случаи | можно добавить в несколько VLAN, у каждого свой **Egress Rule** (UNTAG / TAG); PVID сам **не** меняется |
| **TRUNK** | связь со свитчем или роутером | в добавленных VLAN идёт **с меткой (TAG)** |

Порядок: отметь порты (или впиши в поле *Port* `1-3,8` → **Select**), выбери *Link Type* в верхней строке → **Apply**. Ссылка **Detail** справа показывает, в каких VLAN состоит порт.

## Урок 2 — создание VLAN: VLAN → 802.1Q VLAN → VLAN Config → Create

1. Порт с Интернетом (в уроке порт 8) → **GENERAL**, чтобы при добавлении в VLAN его PVID не менялся. Остальные порты оставь **ACCESS**.
2. *VLAN Config* → **Create** → **VLAN ID** (например `11`), *Description*, отметь порты (`1`, `2`, `8`; у GENERAL-порта Egress Rule **UNTAG**) → **Apply**.
3. **Не паникуй:** если ты подключён к порту, который ушёл в новый VLAN, страница свитча пропадёт — он управляется из Management VLAN (VLAN 1). Переткни кабель в порт, оставшийся в VLAN 1 (например в 5).
4. Чтобы такого не повторялось, создай VLAN для управления: ID `22`, Description `Management`, порт `3` → **Apply**; затем *System → System Info → System IP* → **Management VLAN** `22` → **Apply**. Теперь свитч открывается **только** с порта 3. ПК в этом порту не получит адрес по DHCP — задай IP вручную: `192.168.1.100+x / 255.255.255.0`, шлюз, DNS `8.8.8.8`.
5. Создай остальные VLAN (33, 44…). В конце можно перевести все порты в **GENERAL** (Port Config): порты возвращаются и в VLAN 1, PVID остаются.

## Урок 3 и 8 — trunk

1. Порт, идущий ко второму свитчу или к роутеру (в уроке 3 порт 7, в уроке 8 порт 2) → **TRUNK** (Port Config → Apply).
2. В *VLAN Config → Edit* каждого VLAN добавь этот порт (Egress Rule станет **TAG**).
3. **ID VLAN на свитче = VID на роутере** (урок 8: 11, 222, 333, 444).
4. Management VLAN вместе с trunk даёт управление обоими свитчами через один порт.

## Остальное, что нужно знать

- *System → User Management → Edit* — смена пароля admin (Password + Confirm Password → **Apply**).
- *System → System Tools*: **System Reboot**; **System Reset** (сброс: 192.168.0.1, admin/admin, все порты в VLAN 1).
- *Switching → Port → Port Config*: выключение порта (Status → Disable).
- **Save Config** — сохраняет конфигурацию в память свитча (на реальном устройстве без этого настройки пропадают после перезагрузки; в тренажёре состояние сохраняется само).
- Ссылка *Help* на странице открывает подсказку тренажёра (русский текст).

## Типичные ошибки

- Порт с Интернетом оставили ACCESS — после добавления в VLAN его PVID поменялся, Интернет пропал.
- Management VLAN указали раньше, чем создали такой VLAN — свитч не примет.
- Management VLAN поменяли, а ПК остался в другом порту — «Nie udało się nawiązać połączenia».
- Trunk-порт не добавили в какой-то VLAN — этот VLAN не проходит по trunk.
- ID VLAN на свитче не совпадает с VID на роутере.
