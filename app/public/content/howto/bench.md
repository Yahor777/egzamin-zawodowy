# Стенд: кабели, адреса, вход на устройство

На экзамене никто не подключит тебе устройства. Ты сам: соединяешь кабели, даёшь компьютеру адрес, вписываешь адрес устройства в браузер.

## 1. Узнать адрес и логин устройства

- Переверни устройство: на наклейке снизу (**naklejka**) написано *Default Access* / *Default IP*, *Username*, *Password*.
- TP-Link с завода: роутер `192.168.0.1` (или `tplinkwifi.net`), свитч Easy Smart тоже `192.168.0.1`, логин `admin` / `admin`.
- Школа (ZSE): роутер DrayTek Vigor2927 — `192.168.1.1`, свитч JetStream T2500G — `192.168.0.1`, логин у обоих `admin` / `admin`. Сброс DrayTek: *System Maintenance → Reboot System → Using factory default configuration*; JetStream: *System → System Tools → System Reset*.
- Забыл, что настроил, или устройство «чужое» — **RESET**: держать кнопку ~5 с на включённом устройстве → заводские настройки.

## 2. Соединить компьютер с устройством

- Роутер: кабель от ПК в порт **LAN** (TP-Link: жёлтые, 1–4; DrayTek: **P1–P5**, а P6 — это WAN2, LAN-портом он становится, только если выключить WAN2). Порт **WAN** (TP-Link: синий, Internet; DrayTek: **WAN1**) — для провайдера, через него страница настройки не открывается.
- Свитч: любой порт, который находится во VLAN 1 (с завода — все).
- Лампочка порта горит — есть линк. Не горит — кабель не там или устройство выключено.

## 3. Дать компьютеру адрес из той же сети

| Устройство | Раздаёт адреса (DHCP)? | Что сделать на ПК |
|---|---|---|
| Роутер с завода | да | ничего: ПК получит `192.168.0.100` (TP-Link) или `192.168.1.10` (DrayTek) и т. п. Проверка: `ipconfig` |
| Свитч | **нет** | вручную: `192.168.0.10`, маска `255.255.255.0`, шлюз можно не указывать |

Адрес `169.254.x.x` (APIPA) = DHCP никто не ответил.

## 4. Открыть страницу

Windows → *Przeglądarka* → в адресной строке `http://192.168.0.1` (DrayTek: `http://192.168.1.1`) → логин.

## 5. Ловушки

- **Конфликт адресов.** У роутера и свитча TP-Link с завода один и тот же `192.168.0.1` (у школьной пары DrayTek `192.168.1.1` + JetStream `192.168.0.1` конфликта нет, но они в разных сетях). Если оба в одной сети — браузер открывает то одно, то другое. Порядок: подключить к ПК **только свитч** → сменить ему адрес (например `192.168.0.2`) → потом подключать роутер.
- **Сменил адрес LAN роутера** — он перезагружается, старый адрес больше не открывается. ПК со статическим адресом надо перевести в новую сеть; ПК на DHCP — `ipconfig /release`, `ipconfig /renew`.
- **Сменил IP свитча** на адрес из другой сети — до него больше не достучаться, пока ПК в старой сети.
- **VLAN.** Если порт, в котором стоит ПК, перевести в другой VLAN, связь со страницей свитча пропадёт (управление живёт во VLAN 1; у JetStream это *Management VLAN* на вкладке *System IP*).
- **JetStream:** после изменений нажми **Save Config**, иначе после перезагрузки настройки пропадут.
- Схему из листа собирай **в конце**, когда устройства настроены.

## 6. Проверка связи

- Windows: `ping 192.168.0.1` (cmd). Ответов нет, но адрес верный — проверь брандмауэр той стороны.
- Linux: `ping -c 4 192.168.0.1` (без `-c` — остановить Ctrl+C).
