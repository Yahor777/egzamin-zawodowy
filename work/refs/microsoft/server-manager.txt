					Menedżer serwera
				 Dotyczy: ✅ Windows Server 2025, ✅ Windows Server 2022, ✅ Windows Server 2019, ✅ Windows Server 2016, ✅ Windows 11, ✅ Windows 10
			Opinia
				W tym artykule
	 Menedżer serwera to scentralizowana konsola zarządzania w systemie Windows Server, która umożliwia specjalistom IT aprowizację lokalnych i zdalnych serwerów opartych na systemie Windows oraz zarządzanie nimi na komputerach stacjonarnych. Za pomocą Menedżera serwera można efektywnie administrować wieloma serwerami bez konieczności fizycznego dostępu lub włączania połączeń protokołu RDP (Remote Desktop Protocol). Menedżer serwera obsługuje zdalne, wieloserwerowe zarządzanie i pomaga zwiększyć liczbę serwerów, którymi administrator może zarządzać.
Ten artykuł zawiera omówienie funkcji Menedżera serwera, obsługiwanych zadań i wskazówek dotyczących zarządzania serwerami w danym środowisku. Ten artykuł zawiera następujące sekcje:

              ponowne uruchamianie serwerów zdalnych

Zarządzanie komputerami zdalnymi z komputera klienckiego
Konsola Menedżera serwera jest dołączona do narzędzi administracji zdalnej serwera dla systemów Windows 10 i Windows 11. Gdy narzędzia administracji zdalnej serwera są zainstalowane na komputerze klienckim, nie można zarządzać komputerem lokalnym przy użyciu Menedżera serwera; Menedżera serwera nie można używać do zarządzania komputerami lub urządzeniami z systemem operacyjnym Windows. Menedżera serwera można używać tylko do zarządzania serwerami z systemem Windows.
Uruchamianie Menedżera serwera na komputerze klienckim
Postępuj zgodnie z instrukcjami w narzędziach administracji zdalnej serwera, aby zainstalować narzędzia administracji zdalnej serwera dla systemu Windows.
Na ekranie startowym kliknij pozycję Menedżer serwera. Kafelek Menedżer serwera jest dostępny po zainstalowaniu narzędzi administracji zdalnej serwera.
Jeśli ani narzędzia administracyjne , ani kafelki Menedżera serwera nie są wyświetlane na ekranie startowym po zainstalowaniu narzędzi administracji zdalnej serwera i wyszukiwanie Menedżera serwera na ekranie startowym nie wyświetla wyników, sprawdź, czy ustawienie Pokaż narzędzia administracyjne jest włączone. Aby wyświetlić to ustawienie, umieść kursor myszy na prawym górnym rogu ekranu startowego , a następnie kliknij pozycję Ustawienia. Jeśli Pokaż narzędzia administracyjne jest wyłączone, włącz ustawienie , aby wyświetlić narzędzia zainstalowane w ramach narzędzi administracji zdalnej serwera.
Aby uzyskać więcej informacji na temat uruchamiania narzędzi administracji zdalnej serwera dla systemu Windows 10 do zarządzania serwerami zdalnymi, zobacz Narzędzia administracji zdalnej serwera w witrynie TechNet Wiki.
Konfigurowanie zdalnego zarządzania na serwerach, którymi chcesz zarządzać
Aby wykonywać zadania zarządzania na serwerach zdalnych przy użyciu Menedżera serwera, serwery zdalne, którymi chcesz zarządzać, muszą być skonfigurowane tak, aby umożliwić zdalne zarządzanie przy użyciu Menedżera serwera i programu Windows PowerShell. Jeśli zdalne zarządzanie zostało wyłączone w systemie Windows Server i chcesz włączyć je ponownie, wykonaj następujące kroki.
Konfigurowanie zdalnego zarządzania Menedżera serwera
Wykonaj jedną z następujących czynności, aby otworzyć Menedżera serwera, jeśli nie jest jeszcze otwarty.
Na pasku zadań systemu Windows kliknij przycisk Menedżer serwera.
Na ekranie startowym kliknij pozycję Menedżer serwera.
W obszarze Właściwości na stronie Serwery lokalne kliknij wartość hiperlinku dla właściwości zarządzania zdalnego .
Wykonaj jedną z następujących czynności, a następnie kliknij przycisk OK.
Aby zapobiec zdalnemu zarządzaniu tym komputerem za pomocą Menedżera serwera lub programu Windows PowerShell, jeśli jest zainstalowany, wyczyść pole wyboru Włącz zdalne zarządzanie tym serwerem z innych komputerów .
Aby umożliwić zdalne zarządzanie tym komputerem przy użyciu Menedżera serwera lub programu Windows PowerShell, wybierz Włącz zdalne zarządzanie tym serwerem z innych komputerów.
Włączanie zdalnego zarządzania Menedżera serwera w systemie Windows Server przy użyciu programu Windows PowerShell
Wykonaj jedną z następujących czynności.
Aby uruchomić program Windows PowerShell jako administrator na ekranie startowym , kliknij prawym przyciskiem myszy kafelek programu Windows PowerShell , a następnie kliknij polecenie Uruchom jako administrator.
Aby uruchomić program Windows PowerShell jako administrator z pulpitu, kliknij prawym przyciskiem myszy skrót programu Windows PowerShell na pasku zadań, a następnie kliknij polecenie Uruchom jako administrator.
Wpisz następujące polecenie, a następnie naciśnij Enter , aby włączyć wszystkie wymagane wyjątki reguły zapory.
              Configure-SMremoting.exe — włączanie
Note
To polecenie działa również w wierszu polecenia, który został otwarty z podwyższonym poziomem uprawnień użytkownika (Uruchom jako administrator).
Jeśli włączanie zdalnego zarządzania nie powiedzie się, zobacz about_remote_Troubleshooting w witrynie Microsoft TechNet, aby uzyskać porady i najlepsze rozwiązania dotyczące rozwiązywania problemów.
Zadania, które można wykonać w Menedżerze serwera
Menedżer serwera sprawia, że administracja serwerem jest wydajniejsza, umożliwiając administratorom wykonywanie zadań w poniższej tabeli przy użyciu jednego narzędzia. Zarówno użytkownicy standardowi serwera, jak i członkowie grupy Administratorzy mogą wykonywać zadania zarządzania w Menedżerze serwera, ale domyślnie użytkownicy standardowi nie mogą wykonywać niektórych zadań, jak pokazano w poniższej tabeli.
Administratorzy mogą używać dwóch poleceń cmdlet programu Windows PowerShell w module poleceń cmdlet Menedżera serwera , Enable-ServerManagerStandardUserremoting i Disable-ServerManagerStandardUserremoting, aby dokładniej kontrolować dostęp użytkownika standardowego do niektórych dodatkowych danych. Polecenie cmdlet Enable-ServerManagerStandardUserremoting może zapewnić jeden lub więcej standardowych użytkowników niebędących administratorami dostępu do danych spisu zdarzeń, usług, licznika wydajności oraz roli i funkcji.

Uruchom Menedżera serwera
Menedżer serwera jest domyślnie uruchamiany automatycznie w systemie Windows Server, gdy członek grupy Administratorzy loguje się do serwera. Jeśli zamkniesz Menedżera serwera, uruchom go ponownie w jeden z następujących sposobów. Ta sekcja zawiera również kroki zmiany zachowania domyślnego i uniemożliwianie automatycznego uruchamiania Menedżera serwera.
Uruchamianie Menedżera serwera z poziomu ekranu startowego
Na ekranie startowym systemu Windows kliknij kafelek Menedżer serwera .
Uruchamianie Menedżera serwera z poziomu pulpitu systemu Windows
Na pasku zadań systemu Windows kliknij pozycję Menedżer serwera.
Zapobiegaj automatycznemu uruchamianiu Menedżera serwera
W konsoli Menedżera serwera w menu Zarządzanie kliknij pozycję Właściwości Menedżera serwera.
W oknie dialogowym właściwości menedżera serwera  wypełnij pole wyboru Nie uruchamiaj Menedżera serwera automatycznie przy logowaniu. Kliknij przycisk OK.
Alternatywnie można zapobiec automatycznemu uruchamianiu Menedżera serwera, włączając ustawienie zasad grupy, Nie uruchamiaj Menedżera serwera automatycznie przy logowaniu. Ścieżka do tego ustawienia zasad, w konsoli Edytora lokalnych zasad grupy, to konfiguracja komputera\Szablony administracyjne\System\Menedżer serwera.
Ponowne uruchamianie serwerów zdalnych
Serwer zdalny można uruchomić ponownie na kafelku Serwery strony roli lub grupy w Menedżerze serwera.
Ponowne uruchomienie serwera zdalnego wymusza ponowne uruchomienie serwera, nawet jeśli użytkownicy są nadal zalogowani do serwera zdalnego, a nawet jeśli programy z niezapisanymi danymi są nadal otwarte. To zachowanie różni się od zamykania lub ponownego uruchamiania komputera lokalnego, na którym zostanie wyświetlony monit o zapisanie niezapisanych danych programu i sprawdzenie, czy chcesz wymusić wylogowanie zalogowanych użytkowników. Upewnij się, że możesz wymusić wylogowanie innych użytkowników z serwerów zdalnych i odrzucić niezapisane dane w programach uruchomionych na serwerach zdalnych.
Jeśli w Menedżerze serwera wystąpi automatyczne odświeżanie podczas zamykania i ponownego uruchamiania serwera zarządzanego, mogą wystąpić błędy stanu odświeżania i możliwości zarządzania dla serwera zarządzanego, ponieważ Menedżer serwera nie może połączyć się z serwerem zdalnym, dopóki nie zakończy się ponowne uruchomienie.
Ponowne uruchamianie serwerów zdalnych w Menedżerze serwera
Otwórz stronę główną roli lub grupy serwerów w Menedżerze serwera.
Wybierz co najmniej jeden serwer zdalny dodany do Menedżera serwera. Naciśnij i przytrzymaj Ctrl , klikając, aby jednocześnie wybrać wiele serwerów. Aby uzyskać więcej informacji na temat dodawania serwerów do puli serwerów Menedżera serwera, zobacz dodawanie serwerów do Menedżera serwera.
Kliknij prawym przyciskiem myszy wybrane serwery, a następnie kliknij przycisk Uruchom ponownie serwer.
Eksportowanie ustawień Menedżera serwera na innych komputerach
W Menedżerze serwera lista serwerów zarządzanych, zmiany w ustawieniach konsoli Menedżera serwera i utworzone grupy niestandardowe są przechowywane w następujących dwóch plikach. Te ustawienia można ponownie użyć na innych komputerach z tą samą wersją Menedżera serwera. Narzędzia administracji zdalnej serwera muszą być uruchomione na komputerach klienckich z systemem Windows, aby wyeksportować ustawienia Menedżera serwera do tych komputerów.
              %%\Microsoft\Windows\ServerManager\Serverlist.xml appdata
              %%\Local\Microsoft_Corporation\ServerManager.exe_StrongName_GUID\6.2.0.0\user.config appdata
Note
Poświadczenia "Zarządzaj jako" (lub alternatywne) dla serwerów w puli serwerów nie są przechowywane w profilu mobilnym. Użytkownicy Menedżera serwera muszą dodawać je na każdym komputerze, z którego chcą zarządzać.
Profil roamingu udziału sieciowego nie zostanie utworzony, dopóki użytkownik nie zaloguje się do sieci, a następnie po raz pierwszy się wyloguje. Plik Serverlist.xml jest tworzony w tej chwili.
Możesz wyeksportować ustawienia Menedżera serwera, ustawić ustawienia Menedżera serwera przenośne lub użyć ich na innych komputerach na jeden z następujących dwóch sposobów.
Aby wyeksportować ustawienia do innego komputera przyłączonego do domeny, skonfiguruj użytkownika Menedżera serwera, aby miał profil mobilny w usłudze Active Directory Użytkownicy i komputery. Aby zmienić właściwości użytkownika w usłudze Active Directory Użytkownicy i komputery, musisz być administratorem domeny.
Aby wyeksportować ustawienia do innego komputera w grupie roboczej, skopiuj poprzednie dwa pliki do tej samej lokalizacji na komputerze, z którego chcesz zarządzać za pomocą Menedżera serwera.
Eksportowanie ustawień Menedżera serwera do innych komputerów przyłączonych do domeny
W usłudze Active Directory Użytkownicy i komputery otwórz okno dialogowe Właściwości dla użytkownika Menedżera serwera.
Na karcie Profil dodaj ścieżkę do udziału sieciowego w celu przechowywania profilu użytkownika.
Wykonaj jedną z następujących czynności.
W kompilacjach us English (en-us) zmiany w pliku Serverlist.xml są automatycznie zapisywane w profilu. Przejdź do następnego kroku.
W innych kompilacjach skopiuj następujące dwa pliki z komputera z uruchomionym Menedżerem serwera do udziału sieciowego, który jest częścią profilu mobilnego użytkownika.
              %%\Microsoft\Windows\ServerManager\Serverlist.xml appdata
              %
              localappdata%\Microsoft_Corporation\ServerManager.exe_StrongName_GUID\6.2.0.0\user.config
Kliknij przycisk OK , aby zapisać zmiany i zamknąć okno dialogowe Właściwości .
Eksportowanie ustawień Menedżera serwera do komputerów w grupach roboczych
Na komputerze, z którego chcesz zarządzać serwerami zdalnymi, zastąp następujące dwa pliki tymi samymi plikami z innego komputera, na którym jest uruchomiony Menedżer serwera i który ma żądane ustawienia.
              %%\Microsoft\Windows\ServerManager\Serverlist.xml appdata
              %
              localappdata%\Microsoft_Corporation\ServerManager.exe_StrongName_GUID\6.2.0.0\user.config
