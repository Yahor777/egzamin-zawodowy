					Szybki start: instalowanie i konfigurowanie serwera DHCP
				 Dotyczy: ✅ Windows Server 2025, ✅ Windows Server 2022, ✅ Windows Server 2019, ✅ Windows Server 2016, ✅ Azure Local 2311.2 and later
			Opinia
				W tym artykule
	 W tym przewodniku Szybki start zainstalujesz serwer protokołu DHCP (Dynamic Host Configuration Protocol) w systemie Windows Server. Najpierw należy zainstalować rolę serwera DHCP, a następnie autoryzować serwer w domenie usługi Active Directory, a następnie skonfigurować zakres, aby automatycznie przypisywać adresy IP i opcje DHCP do klientów DHCP IPv4.
Prerequisites
Przed zainstalowaniem serwera DHCP należy spełnić następujące wymagania wstępne:
Komputer z obsługiwaną wersją systemu Windows Server.
Statyczny adres IPv4.
Zakres adresów IP dla obszaru DHCP.
Konto, które jest członkiem grupy Administratorzy lub równoważne.
Instalowanie serwera DHCP
Zainstalowanie serwera DHCP obejmuje dodanie roli serwera DHCP do istniejącego serwera z systemem Windows Server.
Instalowanie roli serwera DHCP
Zainstaluj rolę serwera DHCP jako serwer autonomiczny przy użyciu programu PowerShell lub Menedżera serwera. Wybierz metodę i wykonaj kroki opisane w tej sekcji, aby zainstalować rolę.
              PowerShell
              GUI
Poniżej przedstawiono sposób instalowania protokołu DHCP przy użyciu polecenia Install-WindowsFeature .
Uruchom program PowerShell na komputerze w sesji z podwyższonym poziomem uprawnień.
Uruchom następujące polecenie:
Install-WindowsFeature DHCP -IncludeManagementTools
Instalacja nie wymaga ponownego uruchomienia.
Poniżej przedstawiono sposób instalowania roli serwera DHCP przy użyciu Menedżera serwera z poziomu pulpitu systemu Windows:
Na pulpicie systemu Windows otwórz menu Start , a następnie wybierz pozycję Menedżer serwera.
W menu przejdź do pozycji Zarządzaj, a następnie wybierz pozycję Dodaj role i funkcje.
Na stronie Przed rozpoczęciem wybierz pozycję Dalej.
Na stronie Wybieranie typu instalacji wybierz opcję Instalacja oparta na rolach lub oparta na funkcjach , a następnie wybierz przycisk Dalej.
Na stronie Wybierz serwer docelowy pozostaw opcje domyślne, a następnie wybierz pozycję Dalej.
Na stronie Wybieranie ról serwera zaznacz pole wyboru Serwer DHCP , a następnie wybierz przycisk Dalej.
Zostanie wyświetlony monit o dodanie funkcji wymaganych dla serwera DHCP. Jeśli jesteś zadowolony z ustawień domyślnych, wybierz pozycję Dodaj funkcje.
Na stronie Wybieranie funkcji pozostaw domyślne opcje as-is, a następnie wybierz pozycję Dalej.
Na stronie Serwer DHCP przejrzyj opis roli i elementy do zanotowania. Po zakończeniu wybierz pozycję Dalej.
Na stronie Potwierdzanie wyboru instalacji przejrzyj wybrane role i funkcje. Po zakończeniu wybierz pozycję Zainstaluj , aby rozpocząć proces instalacji.
Po zakończeniu instalacji wybierz pozycję Zamknij. Instalacja nie wymaga ponownego uruchomienia.
Konfigurowanie serwera DHCP
Po pomyślnym zainstalowaniu roli serwera DHCP należy autoryzować i skonfigurować serwer DHCP.
Autoryzowanie serwera DHCP w usłudze Active Directory
Jeśli instalujesz protokół DHCP w środowisku domeny, należy wykonać następujące kroki, aby autoryzować serwer DHCP do działania w domenie.
Note
Nieautoryzowane serwery DHCP zainstalowane w domenach usługi Active Directory nie mogą działać prawidłowo i nie dzierżawią adresów IP klientom DHCP. Automatyczne wyłączanie nieautoryzowanych serwerów DHCP to funkcja zabezpieczeń, która uniemożliwia nieautoryzowanym serwerom DHCP przypisywanie nieprawidłowych adresów IP dla klientów w twojej sieci.
Aby autoryzować serwer DHCP w środowisku domeny:
              PowerShell
              GUI
Uruchom następujące polecenie, aby dodać serwer DHCP do listy autoryzowanych serwerów DHCP w usłudze Active Directory.
Note
Jeśli nie masz środowiska domeny, nie uruchamiaj tego polecenia.
Add-DhcpServerInDC -DnsName DHCP1.corp.contoso.com -IPAddress 10.0.0.3
Aby sprawdzić, czy serwer DHCP jest autoryzowany w usłudze Active Directory, uruchom następujące polecenie:
Get-DhcpServerInDC
W poniższym przykładzie przedstawiono dane wyjściowe, które powinny zostać wyświetlone w programie Windows PowerShell.
IPAddress     DnsName
---------     -------
10.0.0.3      DHCP1.corp.contoso.com
Aby uzyskać więcej informacji na temat tych poleceń, zobacz następujące artykuły:
              Add-DhcpServerInDC
              Get-DhcpServerInDC
Aby autoryzować serwer DHCP przy użyciu usługi Active Directory:
Na pulpicie systemu Windows otwórz menu Start, wybierz pozycję Narzędzia> administracyjne systemu WindowsDHCP.
Rozwiń nazwę serwera DHCP, kliknij prawym przyciskiem myszy, a następnie wybierz pozycję Autoryzuj.
Rozwiązanie problemu z autoryzacją może potrwać kilka sekund. Odśwież listę serwerów, aby potwierdzić, że serwer DHCP jest teraz autoryzowany. Jeśli jest to autoryzowane, w każdym zakresie powinna pojawić się zielona ikona.
Konfigurowanie zakresu IPv4
Po pomyślnym autoryzowaniu serwera DHCP możesz przystąpić do tworzenia nowego zakresu DHCP. Zakresy służą do wskazywania zakresu adresów IP serwera DHCP i jego klientów.
Aby dowiedzieć się więcej na temat planowania zakresów zakresów, zobacz Zakresy DHCP, aby uzyskać wskazówki.
Aby utworzyć nowy zakres PROTOKOŁU IPv4 DHCP, wybierz odpowiednią metodę i wykonaj kroki.
              PowerShell
              GUI
Poniżej przedstawiono sposób tworzenia nowego zakresu przy użyciu polecenia Add-DhcpServerv4Scope programu PowerShell.
Uruchom program PowerShell na komputerze w sesji z podwyższonym poziomem uprawnień.
Aby skonfigurować nowy zakres DHCP o nazwie Contoso network z zakresem od 10.10.10.100 do 10.10.10.200 i maską podsieci 255.255.255.0, uruchom następujące polecenie.
Add-DhcpServerv4Scope -Name "Contoso network" -StartRange 10.10.10.100 -EndRange 10.10.10.200 -SubnetMask 255.255.255.0
Poniżej przedstawiono sposób tworzenia nowego zakresu DHCP przy użyciu konsoli DHCP.
Na pulpicie systemu Windows otwórz menu Start, wybierz pozycję Narzędzia> administracyjne systemu WindowsDHCP.
Rozwiń nazwę serwera DHCP, wybierz prawym przyciskiem pozycję IPv4, a następnie wybierz pozycję Nowy zakres.
Na stronie powitalnej Kreatora nowego zakresu wybierz opcję Dalej.
Na stronie Nazwa zakresu w polu Nazwa wpisz nazwę nowego zakresu i wybierz przycisk Dalej.
Na stronie Zakres adresów IP określ zakres adresów IP dla klientów DHCP i określ maskę podsieci, używając preferowanej metody, wybierz przycisk Dalej.
Na stronie Dodawanie wykluczeń i opóźnień określ wszystkie adresy lub zakres adresów, które nie mają być dystrybuowane przez serwer, wybierz przycisk Dalej.
Na stronie Czas trwania dzierżawy określ cykl życia adresów IP przypisanych do każdego klienta DHCP, wybierz przycisk Dalej.
Na stronie Konfigurowanie opcji DHCP wybierz pozycję Tak, chcę skonfigurować te opcje teraz, a następnie wybierz przycisk Dalej.
Tip
Strona Konfigurowanie opcji DHCP umożliwia skonfigurowanie typowych opcji DHCP, w tym adresów IP routerów (bram domyślnych), serwerów DNS i ustawień WIN dla nowego zakresu. Przed kontynuowaniem należy skonfigurować routery i serwery DNS.
Na stronie Router (brama domyślna) wprowadź adres IP bramy, która powinna być używana przez klientów DHCP, a następnie wybierz pozycję Dodaj.
Na stronie Nazwa domeny i serwery DNS określ nazwę domeny używaną przez klientów na potrzeby rozpoznawania nazw DNS. Określ serwery DNS, wpisując nazwę hosta lub adres IP w poprawnym polu. Wybierz Dalej.
Na stronie Serwery WINS wprowadź nazwy i adresy IP wszystkich serwerów WINS używanych we wdrożeniu. Jeśli serwery WINS nie są obecne we wdrożeniu, możesz wybrać przycisk Dalej , aby pominąć ten krok.
Użyj strony Aktywowanie zakresu , aby aktywować zakres DHCP. Wybierz pozycję Tak. Chcę aktywować ten zakres, aby umożliwić serwerowi DHCP natychmiastowe rozpoczęcie przypisywania adresów IP do klientów. Możesz również aktywować nowy zakres w późniejszym czasie, wybierając pozycję Nie, uaktywnię ten zakres później.
Wybierz przycisk Zakończ , aby zamknąć Kreatora nowego zakresu.
Zarządzanie opcjami zakresu
Po skonfigurowaniu nowego zakresu można zarządzać opcjami zakresu przy użyciu konsoli DHCP lub programu PowerShell.
              PowerShell
              GUI
Opcje zakresu DHCP można modyfikować przy użyciu programu PowerShell za pomocą polecenia cmdlet Set-DhcpServerv4OptionValue . Aby na przykład ustawić opcję serwera DNS dla zakresu 192.168.15.0 i ustawić serwery DNS na 192.168.15.10 i 192.168.15.11, uruchom następujące polecenie:
Set-DhcpServerv4OptionValue -ScopeId 192.168.15.0 -OptionId 6 -Value "192.168.15.10", "192.168.15.11"
Aby zmodyfikować opcje zakresu w konsoli DHCP:
W konsoli DHCP po nawiązaniu połączenia z serwerem DHCP, którym chcesz zarządzać, rozwiń węzeł IPv4, a następnie rozwiń zakres z opcjami, które chcesz zmodyfikować.
Wybierz węzeł Opcje zakresu .
Kliknij prawym przyciskiem myszy pozycję Opcje zakresu, a następnie wybierz polecenie Konfiguruj opcje.
Wybierz opcję, którą chcesz skonfigurować z listy opcji.
Aby włączyć lub wyłączyć ustawienie, zaznacz pole wyboru i skonfiguruj tę opcję.
Aby skonfigurować właściwości istniejącej opcji, kliknij prawym przyciskiem myszy opcję, a następnie wybierz pozycję Właściwości.
Zarządzanie rezerwacjami
W przypadku rezerwacji klientów można zarezerwować adres IP do stałego użycia przez klienta DHCP. Rezerwacje są przechowywane przy użyciu adresu MAC karty sieciowej (NIC), co zapewnia, że serwer DHCP wydzierżawia wyłącznie określony adres IP do określonego adresu MAC.
              PowerShell
              GUI
Rezerwacje można tworzyć przy użyciu polecenia cmdlet Add-DhcpServerv4Reservation programu PowerShell. Aby na przykład dodać rezerwację do zakresu DHCP z identyfikatorem zakresu 192.168.15.0, adresem IP 192.168.15.100 i adresem MAC 00-11-22-33-44-55, uruchom następujące polecenie programu PowerShell:
Add-DhcpServerv4Reservation -ScopeId 192.168.15.0 -IPAddress 192.168.15.100 -ClientId "00-11-22-33-44-55" 
Aby przekonwertować istniejącą dzierżawę DHCP na rezerwację przy użyciu konsoli DHCP, kliknij prawym przyciskiem myszy dzierżawę w węźle Dzierżawy adresów określonego zakresu, a następnie wybierz polecenie Dodaj do rezerwacji.
Aby utworzyć nową rezerwację dla określonego zakresu, kliknij prawym przyciskiem myszy węzeł Rezerwacje zakresu, a następnie wybierz pozycję Nowa rezerwacja. Następnie należy podać nazwę rezerwacji, adresu IP i adresu MAC skojarzonego z kartą sieciową hosta.
Zarządzanie wykluczeniami
Oto jak zarządzać zakresami wykluczeń na serwerze DHCP.
              PowerShell
              GUI
Możesz uruchomić polecenie cmdlet Add-DhcpServerv4ExclusionRange , aby dodać zakres wykluczeń do zakresu DHCP przy użyciu programu PowerShell. Aby dodać na przykład zakres wykluczeń 192.168.15.1 do zakresu 192.168.15.10 w ramach 192.168.15.0, uruchom następujące polecenie:
Add-DhcpServerv4ExclusionRange -ScopeId 192.168.15.0 -StartRange 192.168.15.1 -EndRange 192.168.15.10
Aby zarządzać wykluczeniami przy użyciu konsoli DHCP:
Otwórz konsolę DHCP.
W drzewie konsoli wybierz pozycję Pula adresów.
W menu Akcja wybierz pozycję Nowy zakres wykluczeń.
W oknie dialogowym Dodawanie wykluczenia w obszarze Początkowy adres IP wprowadź pierwszy adres w zakresie, który chcesz wykluczyć z tego zakresu.
Aby wykluczyć zakres więcej niż jednego adresu IP, wprowadź ostatni adres w zakresie w polu Końcowy adres IP.
Wybierz Dodaj.
