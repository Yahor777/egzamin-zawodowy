					Dodawanie lub usuwanie ról i funkcji w systemie Windows Server
				 Dotyczy: ✅ Windows Server 2025, ✅ Windows Server 2022, ✅ Windows Server 2019, ✅ Windows Server 2016, ✅ Windows 11, ✅ Windows 10
			Opinia
				W tym artykule
	 W systemie Windows Server konsola Menedżera serwera i polecenia cmdlet programu Windows PowerShell dla Menedżera serwera umożliwiają dodawanie ról i funkcji do lokalnego lub zdalnego serwera lub wirtualnego dysku twardego w trybie offline (VHD). Jednocześnie można dodać wiele ról i funkcji. W tym artykule opisano sposób dodawania lub usuwania ról i funkcji w systemie Windows Server, w tym wielu serwerów jednocześnie.
Aby uzyskać więcej informacji na temat ról i funkcji dostępnych w systemie Windows Server, zobacz Porównanie wersji systemu Windows Server.
Prerequisites
Przed dodaniem lub usunięciem ról, usług ról i funkcji upewnij się, że spełnisz następujące wymagania wstępne:
Użyj konta użytkownika, które jest administratorem. Musisz również być administratorem na wszystkich zdalnych serwerach, którymi zarządzasz, używając Menedżera serwera, lub na dyskach VHD w trybie offline, które montujesz.
Przejrzyj i zapoznaj się z wszelkimi zależnościami lub wymaganiami wstępnymi specyficznymi dla ról lub funkcji, które chcesz dodać, ponieważ niektóre role mogą wymagać dodatkowej konfiguracji lub usług do poprawnego działania. Aby uzyskać więcej informacji, zobacz Konfigurowanie funkcji na żądanie w systemie Windows Server.
Podaj nośnik instalacyjny lub alternatywną ścieżkę źródłową dla plików wymaganych do dodania niektórych funkcji, takich jak .NET Framework 3.5.
Aby dodać role i funkcje na serwerach zdalnych, dodaj je do Menedżera serwera. Aby uzyskać więcej informacji na temat dodawania serwerów do Menedżera serwera, zobacz Dodawanie serwerów do Menedżera serwera.
Aby dodać role i funkcje na wirtualny dysk twardy (VHD) w trybie offline, docelowy dysk VHD musi spełniać następujące wymagania:
Dysk VHD musi mieć uruchomioną wersję systemu Windows Server zgodną z wersją serwera, do którego jest zainstalowany dysk VHD.
Upewnij się, że pliki VHD nie są używane przez inne procesy ani zainstalowane w innym miejscu.
Dysk VHD nie może mieć więcej niż jednego woluminu systemowego ani partycji.
W przypadku wirtualnego dysku twardego przechowywanego w folderze udostępnionym sieci należy przyznać uprawnienia odczyt i zapis do konta komputera (lub systemu lokalnego) serwera wybranego do zainstalowania dysku VHD. Dostęp tylko do konta użytkownika nie jest wystarczający.
Note
Role i funkcje można dodawać na serwerach zdalnych za pomocą Menedżera serwera w tej samej wersji systemu Windows Server lub starszej. To wymaganie obejmuje używanie równoważnej wersji klienta systemu Windows z narzędziami administracji zdalnej serwera (RSAT). Na przykład system Windows Server 2025 może również dodawać role i funkcje w systemie Windows Server 2022, ale system Windows Server 2022 nie może dodawać ról i funkcji w systemie Windows Server 2025.
W tym artykule nie opisano dodawania ról usług pulpitu zdalnego (RDS), które mają inny proces instalacji w Menedżerze serwera. Aby uzyskać więcej informacji na temat dodawania ról Usług Pulpitu Zdalnego, zobacz Wdrażanie środowiska Usług Pulpitu Zdalnego.
Dodawanie ról i funkcji do systemu Windows Server
Role i funkcje można dodawać na serwerze lokalnym, serwerze zdalnym dodanym do Menedżera serwera lub dysku VHD w trybie offline przy użyciu Kreatora dodawania ról i funkcji w Menedżerze serwera lub poleceń cmdlet programu Windows PowerShell.
Wybierz odpowiednią kartę.
              Kreator ról i funkcji
              Windows PowerShell
Aby dodać role i funkcje za pomocą Kreatora ról i funkcji w Menedżerze serwera, wykonaj następujące kroki:
Otwórz menu Start, wpisz Menedżer serwera, a następnie otwórz Menedżera serwera.
Wybierz pozycję Zarządzaj w prawym górnym rogu, a następnie wybierz pozycję Dodaj role i funkcje. Zostanie otwarty Kreator dodawania ról i funkcji .
W obszarze Przed rozpoczęciem przejrzyj informacje, a następnie wybierz pozycję Dalej.
W polu Typ instalacji wybierz pozycję Instalacja oparta na rolach lub oparta na funkcjach, a następnie wybierz przycisk Dalej. Użyj tej opcji, aby dodać wszystkie role i funkcję z wyjątkiem usług pulpitu zdalnego. Aby uzyskać więcej informacji na temat dodawania ról Usług Pulpitu Zdalnego, zobacz Wdrażanie środowiska Usług Pulpitu Zdalnego.
W obszarze Wybór serwera wybierz serwer, na którym chcesz dodać role i funkcje. Możesz wybrać serwer lokalny lub serwer zdalny, który jest dodawany do Menedżera serwera. Jeśli chcesz dodać role i funkcje na wirtualnym dysku twardym w trybie offline, wybierz pozycję Wybierz wirtualny dysk twardy, wybierz serwer, na którym chcesz zainstalować dysk VHD, a następnie przeglądaj lub wprowadź jego ścieżkę pliku. Wybierz Dalej.
W obszarze Role serwera wybierz role, które chcesz dodać. Nie musisz wybierać żadnych ról, jeśli chcesz dodać tylko funkcję. Po wybraniu ról wybierz pozycję Dalej.
Gdy kontynuujesz, kreator automatycznie informuje o wykryciu konfliktów na serwerze docelowym, które mogą uniemożliwić dodanie wybranych ról lub funkcji albo zakłócić normalne funkcjonowanie. Zostaniesz również poproszony o dodanie wszelkich dodatkowych ról i funkcji, które są wymagane przez wybrane role lub funkcje.
Jeśli planujesz zdalnie zarządzać rolą z innego serwera lub z komputera klienckiego z systemem Windows z uruchomionymi narzędziami administracji zdalnej serwera (RSAT), nie możesz instalować narzędzi do zarządzania i przystawek dla ról na serwerze docelowym. Domyślnie dodawane są narzędzia do zarządzania.
W obszarze Funkcje wybierz role, które chcesz dodać. Nie musisz wybierać żadnych funkcji, jeśli chcesz tylko dodać rolę. Po wybraniu funkcji wybierz pozycję Dalej.
W obszarze Potwierdzenie przejrzyj wybrane role i funkcje. Gdy wszystko będzie gotowe, wybierz pozycję Zainstaluj. Niektóre role i funkcje wymagają ponownego uruchomienia serwera po instalacji. Zaznacz pole wyboru Uruchom ponownie serwer docelowy automatycznie, jeśli jest to wymagane , jeśli chcesz, aby serwer był automatycznie uruchamiany ponownie po instalacji.
Tip
Jeśli chcesz określić pliki źródłowe instalacji, wybierz pozycję Określ alternatywną ścieżkę źródłową. Można również określić plik Windows Imaging (WIM) w następującym formacie, z prefiksem WIM i indeksem, w którym znajdują się pliki funkcji, jako sufiks, na przykład WIM:e:\sources\install.wim:4. Nie można jednak używać pliku WIM bezpośrednio jako źródła do dodawania ról i funkcji systemowych do offline VHD. Musisz albo zamontować wirtualny dysk twardy w trybie offline i wskazać jego ścieżkę montowania dla plików źródłowych, albo wskazać folder zawierający kopię zawartości pliku WIM. Ścieżka źródłowa lub udział plików musi przyznać uprawnienia odczyt do konta komputera serwera docelowego; udzielanie dostępu do konta użytkownika nie jest wystarczające. Aby uzyskać więcej informacji na temat wyświetlania listy indeksów w pliku WIM, zobacz Wyświetlanie listy obrazów zawartych w pliku WIM lub VHD.
Możesz również wyeksportować wybrane opcje do pliku konfiguracji opartego na formacie XML, którego można użyć do instalacji nienadzorowanych za pomocą programu Windows PowerShell. Aby wyeksportować określoną konfigurację, wybierz pozycję Eksportuj ustawienia konfiguracji, a następnie zapisz plik XML w dogodnej lokalizacji. Kroki korzystania z tego pliku konfiguracji można znaleźć w sekcji Dodawanie ról i funkcji na wielu serwerach.
Po zakończeniu instalacji wybierz pozycję Zamknij.
Aby dodać role i funkcje przy użyciu modułu Windows PowerShell dla Menedżera serwera, wykonaj następujące kroki. Pamiętaj, aby zastąpić wszystkie <placeholder> wartości własnymi.
Otwórz sesję programu PowerShell jako administrator.
Uruchom następujące polecenie, aby uzyskać listę wszystkich ról i funkcji dostępnych w systemie Windows Server:
Get-WindowsFeature
Jeśli chcesz sprawdzić role i funkcje na serwerze zdalnym, użyj parametru -ComputerName . Tego parametru można użyć nawet wtedy, gdy serwer zdalny nie został dodany do Menedżera serwera.
Get-WindowsFeature -ComputerName <ComputerName>
Uruchom następujące polecenia, aby dodać rolę lub funkcję przy użyciu polecenia cmdlet Install-WindowsFeature. Musisz określić nazwę co najmniej jednej roli lub funkcji, które chcesz dodać, jak pokazano w poniższych przykładach. Pełną dokumentację polecenia cmdlet można znaleźć w sekcji Install-WindowsFeature.
Tip
Narzędzia do zarządzania i dodatki dla roli nie są domyślnie w zestawie. Aby uwzględnić narzędzia zarządzania podczas instalacji roli, dodaj parametr -IncludeManagementTools do polecenia cmdlet. Jeśli dodasz role i funkcje na serwerze z uruchomioną opcją instalacji Server Core systemu Windows Server, możesz dodać narzędzia do zarządzania rolą do instalacji, ale narzędzia do zarządzania oparte na graficznym interfejsie użytkownika i przystawki nie są zainstalowane. Instalowane są tylko narzędzia wiersza polecenia i narzędzia do zarządzania programu Windows PowerShell.
Jeśli dodana rola lub funkcja wymaga ponownego uruchomienia serwera w celu ukończenia instalacji, dodaj -Restart parametr do automatycznego ponownego uruchomienia bez monitowania.
Aby dodać role DNS i DHCP na serwerze lokalnym, w tym narzędzia do zarządzania, uruchom następujące polecenie:
Install-WindowsFeature -Name DNS,DHCP -IncludeManagementTools
Dodaj -Vhd parametr, aby dodać role i funkcje DNS i DHCP na wirtualnym dysku twardym offline. Polecenie cmdlet zakłada, że chcesz zainstalować dysk VHD na komputerze lokalnym. Alternatywnie, dodaj również parametr -ComputerName oraz nazwę serwera, na którym ma zostać zamontowany dysk VHD. Należy dodać parametr, -ComputerName jeśli uruchamiasz polecenie cmdlet z komputera, na którym jest uruchomiony system operacyjny klienta systemu Windows.
Install-WindowsFeature -Name DNS,DHCP -Vhd <Path> -ComputerName <ComputerName>
Dane wyjściowe polecenia cmdlet pokazują wynik instalacji, jak pokazano w poniższym przykładzie. Jeśli wartość parametru Restart Needed to Yes, uruchom ponownie serwer, aby ukończyć instalację.
Success Restart Needed Exit Code      Feature Result
------- -------------- ---------      --------------
True    No             Success        {DHCP Server, DNS Server}
Listę wszystkich zainstalowanych ról i funkcji można uzyskać, uruchamiając następujące polecenie:
Get-WindowsFeature | ? Installed -eq $true
Dodawanie ról i funkcji na wielu serwerach
Nie można użyć Kreatora dodawania ról i funkcji na więcej niż jednym serwerze docelowym w jednej sesji kreatora. Można jednak używać programu Windows PowerShell do dodawania ról i funkcji na wielu serwerach docelowych jednocześnie. Należy już dodać te serwery do Menedżera serwera.
Za pomocą polecenia cmdlet Install-WindowsFeature można określić plik konfiguracji XML zawierający role i funkcje, które mają być zainstalowane na wielu serwerach. Ten plik konfiguracji jest tworzony przy użyciu Kreatora dodawania ról i funkcji
Important
Wszystkie określone serwery docelowe muszą mieć uruchomioną tę samą wersję systemu Windows Server lub powiązanego systemu operacyjnego Klienta systemu Windows, na którym jest uruchomiony Menedżer serwera.
Aby dodać role i funkcje na wielu serwerach:
Utwórz plik konfiguracji XML zawierający role i funkcje, które mają być zainstalowane na wielu serwerach, jak pokazano na karcie Kreatora ról i funkcji. Postępuj zgodnie ze wskazówkami w kroku 8, aby wyeksportować wybrane opcje do pliku konfiguracji opartego na formacie XML.
Otwórz sesję programu PowerShell jako administrator.
Uruchom następujące polecenia w poniższym przykładzie, aby dodać role i funkcje na określonych serwerach, użyć pliku konfiguracji i uruchomić ponownie każdy serwer w razie potrzeby. Pamiętaj, aby zastąpić wszystkie <placeholder> wartości własnymi. W tym przykładzie każde polecenie jest uruchamiane w osobnym zadaniu, aby polecenia działały współbieżnie na każdym serwerze. Aby uzyskać więcej informacji na temat uruchamiania poleceń w zadaniach, zobacz Uruchamianie zadania.
$serverNames = '<server01>','<server02>','<server03>'
$configurationFilepath = '<filePath to DeploymentConfigTemplate.xml>'
$jobs = @()
foreach($serverName in $serverNames) {
    $jobs += Start-Job -Command {
        Install-WindowsFeature -ConfigurationFilepath $configurationFilepath -ComputerName $serverName -Restart
    }
}
Receive-Job -Job $jobs -Wait | Select-Object Success, RestartNeeded, exitCode, FeatureResult
Jeśli wartość parametru Restart Needed to Yes, uruchom ponownie serwer, aby ukończyć instalację.
Zweryfikuj, czy role i funkcje, które określiłeś w konfiguracji, są ukończone w wynikach wyjściowych każdego zadania.
Usuwanie ról i funkcji z systemu Windows Server
Role i funkcje można usunąć na serwerze lokalnym, serwerze zdalnym dodanym do Menedżera serwera lub dysku VHD w trybie offline przy użyciu Kreatora usuwania ról i funkcji w Menedżerze serwera lub za pomocą poleceń cmdlet programu Windows PowerShell.

Aby usunąć role i funkcje przy użyciu Kreatora ról i funkcji w Menedżerze serwera, wykonaj następujące kroki:
Otwórz menu Start, wpisz Menedżer serwera, a następnie otwórz Menedżera serwera.
Wybierz pozycję Zarządzaj w prawym górnym rogu, a następnie wybierz pozycję Usuń role i funkcje. Otwiera się Przewodnik usuwania ról i funkcji.
W obszarze Przed rozpoczęciem przejrzyj informacje, a następnie wybierz pozycję Dalej.
W obszarze Wybór serwera wybierz serwer, na którym chcesz usunąć role i funkcje. Możesz wybrać serwer lokalny lub serwer zdalny, który jest dodawany do Menedżera serwera. Jeśli chcesz usunąć role i funkcje na wirtualnym dysku twardym w trybie offline, wybierz pozycję Wybierz wirtualny dysk twardy, wybierz serwer, na którym chcesz zainstalować dysk VHD, a następnie przeglądaj lub wprowadź jego ścieżkę pliku. Wybierz Dalej.
W obszarze Role serwera wybierz role, które chcesz usunąć. Nie musisz wybierać żadnych ról, jeśli chcesz usunąć tylko funkcję. Po wybraniu ról wybierz pozycję Dalej.
Po kontynuowaniu kreator automatycznie wyświetla monit o usunięcie innych ról i funkcji, które są wymagane przez wybrane role lub funkcje.
W obszarze Funkcje wybierz role, które chcesz usunąć. Nie musisz wybierać żadnych funkcji, jeśli chcesz tylko usunąć rolę. Po wybraniu funkcji wybierz pozycję Dalej.
W obszarze Potwierdzenie przejrzyj wybrane role i funkcje. Gdy wszystko będzie gotowe, wybierz pozycję Usuń. Niektóre role i funkcje wymagają ponownego uruchomienia serwera po usunięciu. Zaznacz pole wyboru Uruchom ponownie serwer docelowy automatycznie, jeśli jest to wymagane , jeśli chcesz, aby serwer był automatycznie uruchamiany ponownie po usunięciu.
Po zakończeniu usuwania wybierz pozycję Zamknij.

Otwórz sesję programu PowerShell jako administrator.
Pobierz listę wszystkich ról i funkcji zainstalowanych na serwerze, uruchamiając następujące polecenie:
Get-WindowsFeature | ? Installed -eq $true
Jeśli chcesz sprawdzić role i funkcje na serwerze zdalnym, użyj parametru -ComputerName . Tego parametru można użyć nawet wtedy, gdy serwer zdalny nie został dodany do Menedżera serwera.
Get-WindowsFeature -ComputerName <ComputerName> | ? Installed -eq $true

Tip
