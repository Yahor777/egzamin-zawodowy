Windows Server - Lista Ćwiczeń

Wróć na stronę główną

Materiały dotyczące Windows Server 2022, w porównaniu z wcześniejszymi wersjami zostały nieco zmodyfikowane i ponownie zredagowane. Tym razem zajął się tym Kamil Nieścior - uczeń Zespołu Szkół Elektronicznych w Rzeszowie. Wprowadzono kilka nowych rozwiązań, a w szczególności ze względu na kiepską wydajność zrezygnowano z oprogramowania VirtualBox. Wszystkie ćwiczenia wykonane zostały na VMware Workstation.
